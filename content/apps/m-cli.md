### What it does in plain English
m-cli acts as a central control panel for your Mac, allowing you to quickly change system settings without clicking through menus. It provides a simple way to manage hardware features like Bluetooth, Wi-Fi, and battery settings using short text commands. This tool is designed to be lightweight and safe, ensuring your system remains stable while giving you faster control over your computer.

### Who it's for
* Power users who want to speed up their workflow by managing system settings without using a mouse.
* People who prefer a clean, minimalist environment and want to avoid navigating deep into system menus.

### Key features
* **System Control:** Easily toggle settings like Wi-Fi, Bluetooth, and AirDrop with simple commands.
* **Hardware Management:** Quickly check battery status, manage display settings, or control your fan speed.
* **No Extra Bloat:** The tool is lightweight and does not install unnecessary background software on your Mac.
* **Safe Operation:** It is built to be non-intrusive, meaning it won't change your system files unless you specifically tell it to.

### How to install (Download)
The easiest way to install m-cli is via [Homebrew](https://brew.sh/). Once Homebrew is installed, run the following command in your terminal:
`brew install m-cli`

Alternatively, you can perform a manual installation by running this command in your terminal:
`curl -fsSL https://raw.githubusercontent.com/rgcr/m-cli/main/install.sh | bash`

### Pros and Cons
* **Pros:** Completely free and open-source, very fast for quick system adjustments, and no third-party dependencies.
* **Cons:** Requires basic comfort with typing commands in a terminal window, and some advanced features may require administrative permission.
