### What it does in plain English
Umka is a compact programming language that allows you to add custom logic and interactive features to existing software. It is designed to be small and fast, making it perfect for embedding into larger projects without adding unnecessary bulk. Because it checks for errors while you write, it helps you create stable and reliable scripts with ease.

### Who it's for
* Software creators who want to add a scripting layer to their custom applications.
* Hobbyists and students looking for a clean, readable language to learn the basics of programming and logic.

### Key features
* **Clean Design:** Uses a simple, readable structure that is easy to pick up and understand.
* **Lightweight:** Designed to be small and fast, ensuring it doesn't slow down the programs it is added to.
* **Safe and Reliable:** Catches common mistakes early, which helps prevent errors while your program is running.
* **Versatile:** Works across different computer systems, making your scripts portable.
* **Flexible:** Includes modern features like multitasking, which allows your programs to handle multiple tasks at once.
