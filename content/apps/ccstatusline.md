### What it does in plain English
ccstatusline adds a professional, informative status bar to your Claude Code terminal window. It lets you see important details like your current project's git branch, how many tokens you are using, and how much time is left in your usage block. You can easily design your own layout using a simple visual menu to ensure you always have the data you need right where you want it.

### Who it's for
* Software developers who use Claude Code and want to keep an eye on their usage limits and project status without leaving the terminal.
* Power users who enjoy customizing their workspace with themes, colors, and specific data widgets to improve their workflow efficiency.

### Key features
* **Real-time Metrics:** Track token usage, session costs, and block timers at a glance.
* **Visual Customization:** Use a built-in menu to pick colors, add icons, and arrange widgets exactly how you like.
* **Powerline Support:** Create elegant, professional-looking status lines with arrow separators and custom fonts.
* **Multi-line Layouts:** Configure as many separate status lines as you need to organize your information.
* **Portable Settings:** Easily export and import your configurations to share them or back them up.

### How to install (Download)
No traditional installation is required. You can launch the configuration tool directly using your preferred package runner:

* **Using npm:** `npx -y ccstatusline@latest`
* **Using Bun:** `bunx -y ccstatusline@latest`

Follow the on-screen prompts in the terminal to set up your status line and integrate it with your Claude Code settings.

### Pros and Cons
* **Pros:** Completely free and open-source, highly customizable, no complex setup required, and works with both Node.js and Bun.
* **Cons:** Requires a basic understanding of terminal usage, and some advanced visual features may require specific fonts (Nerd Fonts) to display correctly.
