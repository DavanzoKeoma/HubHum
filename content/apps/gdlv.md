### What it does in plain English
Gdlv provides a clear, visual window that connects to your existing command-line debugger to help you examine how your Go computer code runs. Instead of typing text commands blindly, you can click through your files, watch variables change color in real-time, and pause execution right when something unexpected happens. It makes tracking down hidden issues in software projects much faster and less stressful.

### Who it's for
* Software creators writing programs in the Go language who prefer visual controls over text commands.
* Developers trying to understand complex code execution paths and concurrent tasks.
* Engineers who need a straightforward way to inspect variables and memory states during software testing.

### Key features
* Graphical view for inspecting code lines, stack traces, and active tasks simultaneously.
* Real-time color highlighting when variable values change during program steps.
* Custom script support using Starlark for advanced automated inspections.
* Searchable command history and easy font scaling for comfortable viewing.
* Multi-target debugging support where available.

### How to install (Download)
Make sure you have the underlying debugging engine installed first by following the [Delve Installation Guide](https://github.com/go-delve/delve/tree/master/Documentation/installation). 

Once that is ready, you can install the application directly using your terminal if you have Go installed on your computer:
```bash
go install github.com/aarzilli/gdlv@latest
```
Visit the [Official Source Page](https://github.com/aarzilli/gdlv) for complete instructions and Linux system dependencies.

### Pros and Cons
* **Pros:** Free and open-source, lightweight interface, makes complex debugging much easier to follow visually.
* **Cons:** Requires a command-line Go environment and underlying debugger installed on your system first.
