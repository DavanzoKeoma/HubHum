### What it does in plain English
iPlug2 provides a powerful toolkit for developers who want to create music effects and virtual instruments. Instead of rewriting code for every different audio program, creators write their core audio code once. The system automatically adapts your creations to work across various computer setups, mobile phones, tablets, and web browsers.

### Who it's for
* Music software developers building virtual instruments and audio effects.
* Independent audio engineers looking to distribute plugins across multiple formats.
* Students and hobbyists learning C++ audio programming for digital audio workstations.

### Key features
* Write your core code once and target multiple major audio plugin formats.
* Built-in graphics tools support high-performance vector and bitmap drawing.
* Compile your audio applications directly for desktop computers, mobile devices, and web browsers.
* Includes support for standalone applications, virtual instruments, and audio effects.
* Completely free to use in closed-source commercial and personal projects under a friendly license.

### How to install (Download)
To get started with development, visit the official website and documentation portal at the [iPlug2 Official Website](https://iplug2.github.io). You can also explore the recommended starting project structure directly from the [iPlug2 Out-Of-Source GitHub official project page](https://github.com/iPlug2/iPlug2OOS).

### Pros and Cons
* **Pros:** Free to use for commercial projects, highly flexible graphics options, supports a huge variety of audio plugin formats.
* **Cons:** Requires programming experience in C++, setting up a development environment takes initial configuration time.
