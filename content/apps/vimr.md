### What it does in plain English
VimR lets you use Neovim inside a friendly macOS window.  
It adds helpful features like file previews and a fuzzy finder.  
It keeps your workflow fast and enjoyable.

### Who it's for
- Developers who love Neovim but want a GUI.  
- Mac users who prefer a native app over terminal editors.  
- Anyone who wants a clean, fast coding environment.

### Key features
- Markdown preview with live updates.  
- Fuzzy file finder similar to Xcode's Open Quickly.  
- Trackpad support: pinch to zoom, two‑finger scroll.  
- Ligatures can be toggled in preferences.  
- Command‑line tool for quick launches.
