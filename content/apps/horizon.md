### What it does in plain English
Horizon replaces cluttered terminal tabs with an infinite, GPU-accelerated workspace where you can freely arrange commands, code editors, and live previews. Color-coded workspaces group related tasks together, letting you zoom in on details or view your entire project layout at a glance. Your complete board saves automatically, so you can close the app and pick up right where you left off tomorrow.

### Who it's for
* Software developers managing multiple concurrent coding agents and servers
* System administrators monitoring remote machines and logs simultaneously
* Power users who want a visual, infinite workspace instead of messy terminal tabs

### Key features
* Infinite 2D surface to pan, zoom, and organize terminal and web panels freely
* Color-coded workspaces with flexible auto-arranging layouts (rows, columns, or grids)
* Fast command palette to instantly jump between tools, files, and workspaces
* Built-in support for coding assistants, live browser windows, and git status tracking
* Automatic session saving to restore your exact layout and terminal history on restart
