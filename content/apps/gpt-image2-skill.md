### What it does in plain English
GPT-Image2-Skill lets you create, edit, and tweak high-quality AI images directly from your command line or coding assistant. It features an extensive prompt gallery alongside smart tools that can even reverse-engineer prompts from existing reference pictures. Whether you want to generate stunning visual art or transform existing sketches into polished designs, this utility handles the workflow smoothly.

### Who it's for
* Creators and designers looking to streamline their AI image generation workflows.
* Developers who prefer managing image creation directly from their terminal or coding environment.
* Hobbyists wanting to experiment with advanced prompt galleries and reference-based image editing.

### Key features
* Built-in support for multiple advanced image generation models.
* Command-line tool to quickly create and edit images with simple text commands.
* Reverse-engineering feature to extract reusable prompts from any reference image.
* Ready-to-use skill integrations for popular coding assistants and agent runtimes.
* Extensive prompt library covering dozens of creative categories and styles.
