### What it does in plain English
Piranha CMS provides a clean, user-friendly dashboard for creating and organizing content on websites built with the .NET platform. It allows you to manage pages, posts, and media files without needing to write complex code for every update. Because it is modular, you can use it as a standalone website manager or connect it to other applications as a data source.

### Who it's for
* Web developers who want a lightweight content management system for their .NET projects.
* Content editors who need a simple, distraction-free interface to update website text and images.

### Key features
* **Intuitive Editor:** A clean, modern interface designed to make writing and organizing content straightforward.
* **Flexible Architecture:** Can be used as a traditional website manager or as a data source for other applications.
* **Modular Design:** Add or remove features based on the specific needs of your project.
* **Cross-Platform:** Built to run smoothly on modern .NET environments, ensuring high performance.
* **Developer Friendly:** Designed to integrate easily into existing projects without forcing a specific site structure.

### How to install (Download)
To get started, you will need the [.NET 8.0 SDK](https://dotnet.microsoft.com/en-us/download) installed on your computer. You can then install the project templates using your command terminal:

1. Install the templates: `dotnet new install Piranha.Templates`
2. Create your project: `dotnet new piranha.razor`
3. For full documentation and setup guides, visit the [Official Piranha CMS Website](https://piranhacms.org).

### Pros and Cons
* **Pros:** Lightweight and fast, highly customizable, and provides a great experience for content editors.
* **Cons:** Requires familiarity with .NET development to set up and configure initially.
