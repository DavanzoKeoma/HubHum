### What it does in plain English
DreamCoder is a desktop workspace that brings your AI coding tools, chat sessions, and terminal into one centralized place. It lets you connect multiple artificial intelligence providers—such as Anthropic, OpenAI, or local setups—so you can build apps, write code, and review changes easily. The app also features a built-in browser and project management boards to keep track of all your tasks without switching windows.

### Who it's for
* Software developers who want a centralized desktop interface for managing AI coding assistants.
* Freelancers and creators who need to quickly prototype web pages and user interfaces using templates.
* Local privacy-conscious coders who prefer running model configurations and file workflows directly on their machines.

### Key features
* **Multi-Provider Support:** Easily configure and switch between major cloud intelligence models or local endpoints.
* **Interactive Pages & Previews:** Generate live charts, diagrams, and step-by-step app prototypes right inside your chat window.
* **Integrated Project Board:** Organize tasks, sub-tasks, and review criteria that stay synchronized across your working sessions.
* **Local File and Terminal Integration:** Monitor file edits, run terminal commands, and use a built-in development browser seamlessly.
* **Mobile LAN Access:** Check or continue your desktop coding sessions from a phone browser on the same network.
