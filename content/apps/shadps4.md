### What it does in plain English
shadPS4 is an open-source software project that translates PlayStation 4 games so they can run directly on modern desktop computers. It acts as a bridge between the console's game files and your computer's hardware. While still growing and receiving regular updates, it can already run several well-known titles successfully.

### Who it's for
* Video game enthusiasts who want to experiment with running console software on desktop operating systems.
* Developers and researchers interested in how modern gaming hardware and operating systems function.
* Open-source contributors looking to help improve compatibility for various software titles.

### Key features
* Runs natively on Windows, Linux, and macOS systems.
* Fully compatible with standard Xbox and PlayStation controllers right out of the box.
* Custom keyboard and mouse controls that can be mapped per game.
* Built-in support for capturing screenshots and monitoring performance with frame-rate counters.

### How to install (Download)
To get started as a user, you will need the user-friendly interface launcher. You can download the interface application directly from the [QtLauncher Releases Page](https://github.com/shadps4-emu/shadps4-qtlauncher/releases). For further instructions and help getting started, check out the official [Quickstart Guide](https://github.com/shadps4-emu/shadPS4/wiki/I.-Quick-start-%5BUsers%5D).

### Pros and Cons
* **Pros:** Free and open-source software, active community development, and supports standard game controllers.
* **Cons:** Still early in development so many games may not work perfectly yet, and requires users to provide their own legally obtained game files and system files.
