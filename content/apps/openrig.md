### What it does in plain English
OpenRig organizes multiple artificial intelligence coding assistants into a unified, communicative team rather than leaving them trapped in separate windows. It allows you to assign specific roles—such as builders, reviewers, and quality testers—so they can collaborate smoothly on your project files. You can easily boot up, pause, restore, or monitor your virtual agent crews using a simple dashboard and everyday command tools.

### Who it's for
* Software creators and solo developers looking to delegate routine coding tasks to specialized virtual assistants.
* Project leads wanting to coordinate multiple AI models within the same workspace without manual supervision.
* Tech enthusiasts experimenting with multi-agent workflows and automated development pipelines.

### Key features
* **Team Topologies:** Define custom agent teams and roles using simple configuration files.
* **Unified Dashboard:** Inspect active agent seats, runtime status, and communication feeds in a clear visual interface.
* **Session Recovery:** Save your entire agent team's state and restore it instantly whenever you return to work.
* **Cross-Agent Chat:** Send instructions and coordinate messages across different assistant models seamlessly.

### How to install (Download)
You can visit the [Official Website](https://openrig.dev) or install the command-line helper using Node.js. 

To set up the toolkit on supported systems (macOS, Linux, or WSL2 on Windows with Node.js 22 or 24 installed), run:
```bash
npm install -g @openrig/cli
rig setup
```
For complete getting started steps, check out the [Official Quickstart Guide](https://github.com/mvschwarz/openrig/blob/main/docs/reference/quickstart.md).

### Pros and Cons
* **Pros:** Keeps multiple coding agents coordinated, saves workspace context across reboots, open-source and highly configurable.
* **Cons:** Requires Node.js and terminal familiarity, depends on external AI provider accounts being signed in.
