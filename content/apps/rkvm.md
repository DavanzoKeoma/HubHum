### What it does in plain English
rkvm lets you use one keyboard and mouse to control several Linux computers.  
You switch from one computer to another by pressing a shortcut you choose.  
It works even if the computers are using different display systems.

### Who it's for
- Anyone who works with multiple Linux desktops at home or in an office.  
- Developers and testers who need to move quickly between several machines without swapping peripherals.

### Key features
- Control many Linux PCs with a single keyboard and mouse.  
- Switch between machines using a custom shortcut.  
- All traffic is encrypted automatically.  
- Works without any graphical desktop (X, Wayland, etc.).  
- Very low impact on system performance.

### How to install (Download)
- **Arch Linux users:** install the AUR package – [AUR package (for Arch Linux)](https://aur.archlinux.org/packages/rkvm)  
- **All other Linux users:** download the latest release page and follow the build instructions – [Release page](https://github.com/htrefil/rkvm/releases)

### Pros and Cons
* **Pros:** free forever, open‑source, works without a display server, encrypted traffic, low overhead.  
* **Cons:** works only on Linux, requires a few manual setup steps (install kernel module, compile from source if not using AUR).
