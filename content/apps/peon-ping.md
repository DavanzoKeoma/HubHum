### What it does in plain English
AI coding tools often work in the background without telling you when they are finished or need your input. This app solves that by playing classic game-inspired sound effects and showing on-screen banners when your agent completes a task or hits a roadblock. It keeps you in your flow state by letting you know exactly when it is time to look at your code again.

### Who it's for
* Software developers who use AI coding assistants and want to stop manually checking if a task is finished.
* Anyone who gets distracted easily and needs a gentle, nostalgic nudge to return to their work.

### Key features
* **Customizable Sound Packs:** Choose from classic voice lines from games like Warcraft, StarCraft, and Portal.
* **Visual Overlays:** Bold on-screen banners that appear even if you are working in a different application.
* **Smart Notifications:** Automatically detects when a task is finished, requires permission, or encounters an error.
* **Focus-Friendly:** Integrates with system settings to mute sounds during meetings or when you are in "Do Not Disturb" mode.
* **Broad Compatibility:** Works with popular coding tools like Claude Code, GitHub Copilot, Cursor, Windsurf, and many others.

### How to install (Download)
* **macOS/Linux (Recommended):** Open your terminal and run `brew install PeonPing/tap/peon-ping`.
* **Windows:** Use the official PowerShell installer by running the command provided in the [official documentation](https://github.com/PeonPing/peon-ping#option-3-installer-for-windows).
* **Manual/Source:** You can view the full installation guide and verify files via the [Official Source](https://github.com/PeonPing/peon-ping).

### Pros and Cons
* **Pros:** Keeps you focused, highly customizable, supports many different AI tools, and adds a fun personality to your terminal.
* **Cons:** Requires a quick setup process to link with your specific coding tools, and some advanced features may require a brief learning curve.
