### What it does in plain English
Intercooler-js is a lightweight helper tool that brings dynamic server communication directly into everyday website markup. Instead of writing complex scripts to handle button clicks or form updates, developers simply add descriptive tags to existing elements. It handles background requests, updates page sections seamlessly, and even manages browser history with minimal effort.

### Who it's for
* Web designers looking to add dynamic page updates without heavy software foundation
* Front-end developers aiming to simplify existing web projects
* Programmers who want clean, readable markup powered by simple server interactions

### Key features
* Trigger background server requests straight from standard HTML elements
* Update specific sections of a webpage automatically upon server response
* Support custom triggers, progress indicators, and client-side redirection
* Add back-button and navigation history support seamlessly
* Retrofit easily into existing web projects piece by piece

### How to install (Download)
You can download or link the library directly from the [Official Intercooler Downloads Page](http://intercoolerjs.org/download.html).

### Pros and Cons
* **Pros:** Extremely lightweight, simple tag-based syntax, easy to integrate into older projects.
* **Cons:** Requires a supporting JavaScript library like jQuery or zepto.js to function properly.
