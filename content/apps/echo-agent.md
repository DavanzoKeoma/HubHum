### What it does in plain English
Echo Agent is a smart companion that runs directly on your computer to help with everyday digital tasks, coding, and file management. Unlike standard chat windows, it remembers your preferences across sessions and turns successful work steps into reusable skills. You can interact with it through a modern desktop workspace or run its background engine to automate repetitive workflows.

### Who it's for
* Software developers looking for an autonomous coding helper that understands local project context.
* Writers, researchers, and professionals who want a private assistant to organize notes and documents.
* Anyone seeking a self-hosted automation tool to handle routine computer tasks without sharing data with third parties.

### Key features
* **Long-term memory:** Organizes facts, user preferences, and past conversations into searchable layers so you never have to repeat background information.
* **Skill evolution:** Automatically turns successful task trajectories into reusable skills that improve over time.
* **Desktop workspace:** Combines a built-in code editor, file manager, and tool execution window in one clean interface.
* **Local control:** Runs securely on your personal hardware with flexible connection options for popular language models.
* **Flexible cloud setup:** Can be used as a standalone desktop application or run as a background service via command line.
