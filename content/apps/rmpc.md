### What it does in plain English
Rmpc is a modern music player controller designed to run right inside your command-line terminal window. It connects to your existing music server to let you browse your library, manage queues, and control playback using intuitive keyboard shortcuts. It even displays album cover art and moving visualizers directly in compatible terminal windows.

### Who it's for
* Command-line power users who want a lightning-fast, keyboard-driven music player interface.
* Audiophiles who love organizing local music libraries with multi-column file browsers and clean layouts.
* Minimalists looking to ditch heavy desktop music apps in favor of a resource-friendly terminal tool.

### Key features
* Displays album cover artwork directly within supported terminal environments.
* Includes music visualizer integration to watch your audio move in real time.
* Supports synchronized lyrics so you can follow along with your favorite tracks.
* Offers a multi-column file browser inspired by classic terminal file managers.
* Fully customizable color themes, layouts, and keyboard shortcuts.

### How to install (Download)
You can find setup guides, configuration examples, and installation methods for your operating system by visiting the [Official rmpc Website](https://rmpc.mierak.dev).

### Pros and Cons
* **Pros:** Extremely fast and lightweight, beautiful terminal visual presentation, highly customizable keyboard controls.
* **Cons:** Requires a running music server backend to function, advanced visual features require a modern compatible terminal emulator.
