### What it does in plain English
frpmgr is a user-friendly desktop application designed to handle network tunneling and reverse proxy connections on Windows. It replaces complicated manual text configuration files with a clear, visual dashboard. You can easily start, stop, track, and update your connections in real time without needing deep technical knowledge.

### Who it's for
* Home server enthusiasts who want to access local projects from outside their home network.
* Developers needing a reliable way to expose local test environments to the internet.
* System administrators managing multiple remote connections on Windows machines.

### Key features
* **Visual Dashboard:** Configure and manage all network tunnels through a clean graphical interface.
* **Background Operation:** Services run independently in the background so you can safely close the main window.
* **Automatic Startup:** Registers your configurations to start automatically when your computer boots up.
* **Hot Reload:** Apply changes to active connections instantly without restarting services or dropping state.
* **Status Tracking:** Monitor connection health and traffic directly within a straightforward table view.
