### What it does in plain English
Nasiko acts as a central control center for all the AI coding tools you use on your computer. It tracks exactly how much each tool costs and lets you choose which AI models they use, regardless of the original provider. You can also use it to safely cloud setup your own custom AI agents with built-in security and approval steps.

### Who it's for
*   **Software Developers:** Professionals who use multiple AI coding assistants and want to see their total usage and spending in one place.
*   **Team Leads:** Managers who need to govern which AI tools their team uses and ensure they stay within budget and security policies.

### Key features
*   **Unified Dashboard:** See all your AI coding sessions, token usage, and costs in a single, easy-to-read interface.
*   **Model Routing:** Switch the underlying AI model for your coding tools, allowing you to use your preferred keys for different tasks.
*   **Security & Governance:** Set strict rules for what your agents can do, including human-in-the-loop approvals for sensitive actions.
*   **Easy cloud setup:** Build and run your own custom agents without needing complex software development kits.
*   **Privacy-Focused:** Keeps your credentials secure by using short-lived tokens instead of sharing your main API keys with every agent.

### How to install (Download)
Nasiko is designed to run locally using Docker. To get started, follow the official setup guide:
*   [Visit the Nasiko Documentation](https://docs.nasiko.com) for step-by-step installation instructions.
*   The CLI can be installed on macOS and Linux by running: `curl -fsSL https://registry.nasiko.com/r/nasiko/install | bash`
*   For Windows users, use PowerShell: `irm https://registry.nasiko.com/r/nasiko/install-ps1 | iex`

### Pros and Cons
*   **Pros:** Provides total visibility into AI spending, works with popular coding tools, and offers powerful security controls.
*   **Cons:** Requires Docker to be installed and running on your machine, and initial setup involves configuring environment variables.
