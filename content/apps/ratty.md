### What it does in plain English
Ratty is a modern terminal emulator that uses your computer's graphics hardware to display text and 3D objects. It allows you to transform your standard command-line window into a 3D space where you can warp, rotate, and interact with your terminal content. Beyond basic text, it supports custom 3D cursors and inline graphics to make your daily tasks more visually engaging.

### Who it's for
* Power users who want to customize their command-line environment with unique visual flair.
* Developers and hobbyists interested in experimenting with 3D-rendered interfaces and terminal-based graphics.

### Key features
* **GPU-Powered Rendering:** Uses your graphics card for smooth text and 3D object display.
* **Interactive 3D Modes:** Toggle between flat, orthographic, perspective, and Mobius views.
* **Customizable Cursors:** Replace your standard cursor with animated 3D models.
* **Inline Graphics:** Supports displaying 3D objects directly within the terminal window.
* **Agent Control:** Includes an optional server to control your terminal window using external automation tools.

### How to install (Download)
Ratty is available for most major operating systems via the [official GitHub releases page](https://github.com/orhun/ratty/releases). 

* **Arch Linux:** You can install it directly via the terminal using `sudo pacman -S ratty`.
* **Rust Users:** If you have Rust installed, you can use `cargo install ratty`.
* **Nix:** Use `nix run github:orhun/ratty` to launch it directly.

### Pros and Cons
* **Pros:** Completely free and open-source, highly customizable, and offers a unique 3D experience not found in standard terminals.
* **Cons:** Requires a modern graphics card to function properly, and some advanced 3D features may have a learning curve.
