### What it does in plain English
GDB Dashboard turns the standard text-based debugger into a helpful, organized visual workspace. It automatically displays the status of your program every time it pauses, so you don't have to manually request updates. By keeping all your essential data on one screen, it lets you focus on finding and fixing errors rather than managing the tool itself.

### Who it's for
* Software developers who want to speed up their troubleshooting process.
* Students or learners who find the standard debugger interface difficult to read.

### Key features
* **Automatic Updates:** The dashboard refreshes every time your program stops, ensuring you always see the latest state.
* **Modular Layout:** You can see exactly what you need, such as code snippets, variable values, and memory status, all in one view.
* **No Command Overrides:** It works alongside your existing tools without changing how you normally use your debugger.
* **Syntax Highlighting:** Supports color-coded text to make your code easier to read and understand at a glance.

### How to install (Download)
To install the dashboard, download the [official configuration file](https://raw.githubusercontent.com/cyrus-and/gdb-dashboard/master/.gdbinit) and save it as `.gdbinit` in your home directory. For a better visual experience, it is recommended to install [Pygments](http://pygments.org/) using your system's package manager or Python's installer.

### Pros and Cons
* **Pros:** Completely free, lightweight, and does not require a complex setup process.
* **Cons:** Requires a basic understanding of how to manage files in your home directory.
