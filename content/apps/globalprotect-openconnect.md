### What it does in plain English
This application helps you connect securely to your workplace or organizational network from any computer. It handles secure logins, including modern sign-in methods like security keys and single sign-on web pages. You can run it through a simple desktop window or via the command line depending on your workflow preferences.

### Who it's for
* Remote employees and contractors needing reliable access to corporate network resources.
* System administrators managing secure connections across different operating systems.
* Power users who prefer lightweight or command-line tools for managing virtual private networks.

### Key features
* Supports browser-based single sign-on and multi-factor authentication methods.
* Runs natively across Windows, macOS, Linux, FreeBSD, and OpenBSD.
* Allows saving multiple portals and direct gateway connections for quick switching.
* Includes system tray controls and automatic connection options upon app launch.
* Offers both a graphical interface and a flexible command-line tool.
