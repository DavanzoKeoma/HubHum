### What it does in plain English
This helpful utility lets you transform plain programming text into gorgeous, magazine-quality graphic snapshots. Instead of taking messy screen captures or manually formatting designs, you simply point the tool at your file or paste your text. It instantly generates a crisp, beautifully styled image complete with syntax highlighting, custom themes, and window decorations.

### Who it's for
* Software developers who frequently share code snippets on social media or in documentation
* Technical writers who need consistent, high-resolution code graphics for articles
* Presenters and educators looking to display clean, easy-to-read code blocks in slides

### Key features
* Generates high-quality image exports directly from text files, copied text, or direct input
* Automatically recognizes programming languages and applies correct styling
* Offers an interactive mode to fine-tune colors, fonts, windows, and padding visually
* Saves custom styling combinations as reusable presets for future projects
* Copies finished images straight to your system clipboard for instant pasting

### How to install (Download)
To use this tool, make sure you have Node.js installed on your computer. You can install the package globally using your preferred package manager:

* **Using npm:** Run `npm i -g carbon-now-cli` in your terminal.
* **Using Yarn:** Run `yarn global add carbon-now-cli` in your terminal.
* **Using pnpm:** Run `pnpm i -g carbon-now-cli` in your terminal.
* **Using Bun:** Run `bun i -g carbon-now-cli` in your terminal.
* **Instant execution:** Run `npx carbon-now-cli <file>` without permanent installation.

### Pros and Cons
* **Pros:** Free and open source, supports custom themes and saved presets, works with clipboard and direct input streams.
* **Cons:** Requires a command-line environment and Node.js setup to get started.
