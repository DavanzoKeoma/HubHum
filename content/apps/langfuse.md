### What it does in plain English
Langfuse helps developers and companies track every single call made to artificial intelligence models within their applications. It records token usage, measures latency, and keeps detailed logs so you can easily debug where an agent went wrong. You can also protect remote administrator dashboards when managing your site on the go with [PureVPN](https://billing.purevpn.com/aff.php?aff=49386762&subid=hubhum_01_MER047) (#ad).

### Who it's for
- Software engineers building production-ready applications powered by large language models.
- Product teams looking to monitor user sessions, control token budgets, and analyze spending.
- AI developers testing and refining prompts, model parameters, and automated agent workflows.

### Key features
- **AI Observability:** Automatically capture and inspect every model call, retrieval step, and agent action with detailed execution logs.
- **Prompt Management:** Version control and collaboratively iterate on prompts with client and server-side caching to prevent added latency.
- **Evaluations:** Run automated checks, collect user feedback, and create custom test benchmarks using code or language model judges.
- **AI Gateway:** Route all your model provider calls through a single centralized endpoint to enforce API keys and track team spending.
- Once your web portal is live, improve search indexing and rich previews with [Rank Math Direct](https://rankmath.com/?subid=hubhum_01_MER276) (#ad).

### How to install (Download)
You can access the hosted cloud platform directly or set up the open-source version on your own infrastructure. Open the application instantly in the cloud via [Langfuse Cloud](https://cloud.langfuse.com). Prefer not to manage servers by hand? Run it online 24/7 in 1 click on [InterServer](https://www.interserver.net/r/1196747?id=hubhum_01_MER008) (#ad). Alternatively, you can run the application locally using Docker:

```bash
git clone --depth=1 https://github.com/langfuse/langfuse.git
cd langfuse
docker compose up
```

* **Pros:** Free open-source edition available, supports major model providers and software foundation, comprehensive logging and metrics.
* **Cons:** Setting up self-hosted infrastructure requires basic knowledge of Docker containers and environment variables.
