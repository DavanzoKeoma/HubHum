### What it does in plain English
LlamaGPT lets you chat with an advanced artificial intelligence assistant directly from your computer or home server. Because everything runs locally on your device, your conversations stay completely private and secure. It offers a familiar chat interface similar to popular cloud-based assistants, but without requiring an internet connection or exposing your data to external companies.

### Who it's for
* Privacy-conscious individuals who want to experiment with advanced language models without sharing personal data.
* Developers and hobbyists looking to test code generation models or run a local AI server.
* Home server enthusiasts using platforms like Umbrel who want a local alternative to commercial AI chats.

### Key features
* 100% offline functionality ensuring zero data leaves your personal device.
* Support for multiple chat models including Llama 2 and Code Llama variants.
* Familiar, easy-to-use chat interface styled after modern web assistants.
* Compatible with OpenAI API endpoints for seamless integration with other tools.
* Optional hardware acceleration for modern Mac computers and Nvidia graphics cards.

### How to install (Download)
You can easily install LlamaGPT on your home server through the [Umbrel App Store](https://apps.umbrel.com/app/llama-gpt). For advanced setups on Mac, Linux, or Windows using Docker and Kubernetes, check out the instructions on the [Official Source / Credits](https://github.com/getumbrel/llama-gpt).

### Pros and Cons
* **Pros:** Complete data privacy, runs entirely offline, free and open-source.
* **Cons:** Requires a computer with decent memory and processing power to run smoothly.
