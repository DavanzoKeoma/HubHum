### What it does in plain English
Kanata allows you to change what any key on your keyboard does, turning standard keys into powerful shortcuts. You can create multiple "layers" of functionality, similar to how the Shift key changes lowercase letters to uppercase. This helps you work more efficiently and reduces strain by keeping your most-used commands within easy reach.

### Who it's for
*   **Office professionals** who want to create custom shortcuts for repetitive tasks.
*   **People with repetitive strain injuries** looking to reduce finger travel and improve typing ergonomics.

### Key features
*   **Custom Layers:** Switch between different keyboard layouts instantly to access symbols, numbers, or macros.
*   **Advanced Key Behavior:** Use features like "tap-hold" to perform different actions depending on whether you tap a key or hold it down.
*   **Live Reloading:** Test your configuration changes immediately without needing to restart the program.
*   **Universal Compatibility:** Works on Windows, macOS, and Linux to provide a consistent experience across all your devices.
*   **Macro Support:** Create complex sequences of key presses that trigger with a single button.

### How to install (Download)

### Pros and Cons
*   **Pros:** Completely free and open-source, highly customizable, and works on any keyboard hardware.
*   **Cons:** Requires manual configuration via text files, which may take some time to learn for beginners.
