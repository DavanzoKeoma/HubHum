### What it does in plain English
This tool acts as a dashboard for your AI coding sessions, keeping a close eye on how many tokens you have used. It provides clear, real-time updates so you can see exactly how close you are to your service limits. By tracking your usage patterns, it helps you plan your work sessions more effectively and prevents you from being suddenly locked out of your tools.

### Who it's for
*   Developers who use AI-assisted coding tools and want to avoid hitting usage caps.
*   Power users who need to track their costs and token consumption across multiple sessions.

### Key features
*   **Real-time Monitoring:** Watch your token and message usage update live in your terminal.
*   **Smart Forecasting:** Predicts when you might hit your limits based on your past activity.
*   **Customizable Plans:** Supports various subscription levels and allows for custom limit settings.
*   **Data Persistence:** Keeps a local history of your usage so you can review your trends over time.
*   **Clean Interface:** Displays information clearly with helpful charts and status updates.

### How to install (Download)
The recommended way to install this tool is using `uv`, which handles everything automatically:

1.  **Install `uv`** (if you don't have it):
    *   **macOS/Linux:** `curl -LsSf https://astral.sh/uv/install.sh | sh`
    *   **Windows:** `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
2.  **Install the monitor:**
    *   Run: `uv tool install claude-monitor`
3.  **Run the tool:**
    *   Simply type `claude-monitor` in your terminal to start.

*Alternatively, if you have Python installed, you can use `pip install claude-monitor`.*
