### What it does in plain English
Dev-Janitor helps you clean up the hidden clutter, temporary files, and heavy caches that pile up on your computer while you work on software projects. It lets you monitor installed coding tools and updates from a single, organized window without needing to use complicated command screens. Plus, it runs quick safety checks to ensure your private configuration files and network ports remain secure.

### Who it's for
* Software developers and programmers who want to reclaim valuable storage space taken up by hidden project caches.
* Anyone who uses multiple coding assistance tools and needs a simple dashboard to keep them updated.

### Key features
* Scans computer directories to find and clear out heavy temporary files, old logs, and forgotten project folders.
* Cleans up leftover chat histories and cache files created by automated coding assistants without deleting your personal preferences.
* Organizes and tracks updates for numerous popular developer tools from one central place.
* Checks system settings and local ports to help prevent accidental exposure of private passwords and security keys.
* Helps you inspect running background processes and figure out which program is using a specific port.
