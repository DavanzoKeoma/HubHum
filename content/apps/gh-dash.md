### What it does in plain English
gh-dash is a tool that lets you view and manage your GitHub work without leaving your command line. It organizes your tasks into clear lists so you can quickly see what needs your attention. You can perform common actions like reviewing code or updating issues using simple keyboard shortcuts.

### Who it's for
This tool is perfect for software developers and project managers who prefer working in a text-based environment. It is ideal for anyone who wants to speed up their daily workflow by reducing the need to switch between their code editor and a web browser.

### Key features
* **Keyboard-First Navigation:** Use customizable shortcuts to move through your tasks instantly.
* **Customizable Views:** Create personalized sections for specific projects or task types.
* **Full GitHub Integration:** Perform essential tasks like checking code differences, adding comments, and updating status.
* **Highly Configurable:** Adjust every setting to match your personal workflow using a simple text file.
