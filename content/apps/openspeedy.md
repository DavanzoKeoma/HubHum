### What it does in plain English
OpenSpeedy changes how fast a game runs on your computer. You pick the game, move a slider, and the speed changes instantly. It works with most Windows games without touching the system core.

### Who it's for
- Casual gamers who want to breeze through long missions.  
- Speedrunners looking to practice sections faster.  
- Parents who wish to slow down games for younger children.

### Key features
- Simple slider to set the speed multiplier.  
- Works with both 32‑bit and 64‑bit games.  
- No need to modify game files or install extra drivers.  
- Runs as a regular program, not a system service.  
- Shows real‑time speed changes while you play.

### How to install (Download)

* **Pros:** free forever, easy slider interface, works with many Windows games, no system‑level changes.  
* **Cons:** Windows‑only, may trigger antivirus warnings, not allowed in competitive online games.
