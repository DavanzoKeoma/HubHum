### What it does in plain English
Tuios is a modern window manager designed specifically for your command-line interface. It splits your screen into clean, tiled panes that stay active even if your main connection drops or your computer restarts. It also includes a centralized inbox that monitors automated coding assistants running in your background sessions so you never miss an important prompt or approval request.

### Who it's for
* Software developers and engineers who juggle multiple long-running terminal tasks simultaneously.
* Power users who want advanced screen splitting and session recovery without complex configurations.
* Anyone utilizing AI coding agents who needs a unified way to review changes and grant permissions.

### Key features
* **Tiled Workspace Layouts:** Automatically arrange your terminal panes using flexible split modes and master-stack views.
* **Persistent Sessions:** Keep background sessions running safely so you can detach and reattach whenever needed.
* **Centralized Agent Inbox:** Track every automated coding assistant, approval request, and question from a single list.
* **Vim-Inspired Navigation:** Move across windows and browse thousands of lines of scrollback history effortlessly using keyboard shortcuts.
* **High-Performance Rendering:** Built with efficient event-driven technology to keep computer processor usage practically zero when idle.

### How to install (Download)
* **Homebrew (macOS/Linux):** Run `brew install tuios` in your terminal.
* **Arch Linux (AUR):** Run `yay -S tuios-bin` to install the package.
* **Quick Install Script:** Run `curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash` in your shell.
* **Go Package Installation:** Run `go install github.com/Gaurav-Gosain/tuios/cmd/tuios@latest` if you have Go set up.
* **Official Checksums:** Review official verification files via [Download (checksums.txt)](https://github.com/Gaurav-Gosain/tuios/releases/download/v0.13.3/checksums.txt).

### Pros and Cons
* **Pros:** Completely open-source, highly responsive modal keyboard shortcuts, near-zero idle resource consumption, built-in session resurrection.
* **Cons:** Requires familiarity with command-line environments, takes a short while to master the keyboard commands.
