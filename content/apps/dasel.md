### What it does in plain English
Dasel is a versatile utility that lets you inspect, search, and edit structured text files regardless of their underlying format. Whether your information is stored in JSON, YAML, TOML, XML, or CSV, you can use the exact same commands to find or change values. It also lets you effortlessly convert files from one format to another on the fly.

### Who it's for
* Software creators working across multiple configuration formats daily.
* System administrators and automation engineers parsing logs and settings files.
* Data wranglers cleaning and converting datasets for analysis scripts.

### Key features
* **Universal Format Support:** Read and write JSON, YAML, TOML, XML, CSV, INI, HCL, and KDL files.
* **Unified Query Language:** Use the identical selector patterns across every supported file type.
* **Inline Modifications:** Update, insert, or delete specific values directly inside existing files.
* **Format Conversion:** Instantly translate documents from one data structure format into another.
* **Script Automation:** Easily embed commands inside shell scripts and automated data processing pipelines.

* **Cons:** Operates via the command line interface rather than a graphical window, requires learning basic selector rules.
