### What it does in plain English
Compressor is a lightweight utility library built for Android developers to effortlessly shrink large photo files. It reduces image footprints significantly while keeping visual quality remarkably intact. Developers can quickly integrate it into their apps to save precious device storage and speed up upload times.

### Who it's for
* Android application developers looking to optimize image storage and network uploads.
* Creators building mobile tools that handle heavy camera rolls or user-uploaded photos.
* Developers wanting a simple, customizable way to manage image resolutions and formats on mobile.

### Key features
* Shrinks large photo files drastically with negligible visual quality loss.
* Fully customizable settings for custom dimensions, image quality percentages, and target file sizes.
* Converts images smoothly into modern formats like WebP.
* Built using Kotlin coroutines for smooth background processing without freezing screens.
* Supports custom rules and extensions tailored to unique app requirements.

### How to install (Download)
To use this library in your mobile application, add the following dependency line to your project setup:
```groovy
implementation 'id.zelory:compressor:3.0.1'
```
You can inspect the source code and documentation directly via the [Official GitHub Releases Page](https://github.com/zetbaitsu/Compressor/releases).

### Pros and Cons
* **Pros:** Free and open source, lightweight footprint, integrates smoothly with modern Kotlin coroutines.
* **Cons:** Requires programming knowledge to implement inside Android projects, not a standalone end-user app.
