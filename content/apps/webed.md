### What it does in plain English
WebEd is an open-source tool designed to help creators and developers build structured websites and manage digital content efficiently. It provides a modular workspace where you can organize blogs, static pages, and contact forms without starting from scratch. With built-in features for user permissions and file management, it streamlines the publishing workflow.

### Who it's for
* Web developers looking for a modular backend software foundation to build custom client sites.
* Small business owners wanting to manage blogs, landing pages, and contact forms in one place.
* Content administrators who need drag-and-drop menu structuring and straightforward file management.

### Key features
* Modular package architecture that lets you enable only the features you need.
* Visual file manager for handling images, documents, and media assets easily.
* Drag-and-drop menu management for simple site navigation changes.
* Comprehensive user access control system for managing roles and permissions.
* Built-in support for custom fields, blog posts, static pages, and themes.

* **Pros:** Free and open-source project, highly modular architecture, built-in file manager and caching.
* **Cons:** Project has been officially discontinued by its creator, requires developer knowledge for setup.
