### What it does in plain English
This tool hides sensitive information like passwords and connection keys inside your software configuration files. It automatically reads encrypted text, unlocks it in the background, and feeds the correct unencrypted values to your application. This prevents private credentials from being accidentally exposed in public code sharing spaces.

### Who it's for
* Software developers who need to store database passwords and access tokens securely in code settings.
* System administrators managing backend applications across multiple cloud environments.
* Security-conscious teams looking to meet compliance standards without altering their existing code structure.

### Key features
* Seamless integration with standard project configuration files and system properties.
* Support for strong, industry-standard encryption algorithms out of the box.
* Companion helper tools for command-line text encryption and decryption.
* Flexible setup options ranging from automatic classpath scanning to manual custom property mapping.
* Automatic caching and event listeners to refresh keys dynamically when updates occur.

### How to install (Download)
To use this library in your project, add the official package dependency to your project manager file or visit the [Releases Page](https://github.com/ulisesbocchio/jasypt-spring-boot/releases) for additional updates and source files.

### Pros and Cons
* **Pros:** Completely open source, easy to plug into existing setups, and requires minimal configuration for secure defaults.
* **Cons:** Requires a master password to be passed safely via system variables or secure environment setups.
