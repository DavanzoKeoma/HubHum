### What it does in plain English
OkHttp is a tool that helps software programs talk to servers over the internet smoothly and securely. It automatically reuses connections and saves temporary copies of data so your device uses less battery and data. When internet connections act up, it quietly fixes common errors and tries alternate pathways to keep things working.

### Who it's for
* Mobile app creators building software for phones and tablets
* Java software developers working on server or desktop applications
* Anyone looking to make their networked programs load pages and data faster

### Key features
* Shares a single connection socket across multiple requests to reduce lag
* Automatically compresses downloads to save your mobile data allowance
* Saves previous responses locally to completely skip repeat network downloads
* Quietly recovers from common connection problems and switches addresses if servers fail
* Keeps data secure using modern web security standards and encryption features
