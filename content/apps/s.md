### What it does in plain English
This tool lets you type a quick search command straight into your computer terminal, instantly opening the results in your web browser. Instead of opening a browser window, navigating to a search engine, and typing your query, you can do it all in a single keystroke. It supports dozens of popular websites and online services, allowing you to find what you need without breaking your workflow.

### Who it's for
* Software developers and system administrators who spend their day working inside a terminal window.
* Power users who love keyboard-driven workflows and want to cut down on mouse clicks.
* Anyone looking for a lightning-fast way to query reference sites, shopping portals, or video platforms.

### Key features
* **Extensive website support:** Search across hundreds of popular providers like general search engines, encyclopedias, developer hubs, and shopping sites.
* **Custom shortcuts:** Easily create your own search shortcuts or configure custom websites with simple text rules.
* **Flexible output options:** Send search results directly to your standard browser, specialized text-based browsers, or export lists as machine-readable data.
* **Autocompletion support:** Enjoy built-in command completion for popular command shells so you never have to remember provider names.
* **Optional web interface:** Run the built-in server mode to host your own local search page.

### How to install (Download)
* **Go Users:** Ensure your environment variables are set up, then run `go install github.com/zquestz/s@latest` in your terminal.
* **Homebrew Users (macOS/Linux):** Run `brew install s-search` in your terminal.
* **Arch Linux Users:** Install directly from the AUR using `yay -S s`.
* **Official Releases & Setup:** Visit the [Official GitHub Releases Page](https://github.com/zquestz/s/releases) for more details.

### Pros and Cons
* **Pros:** Extremely fast, free forever, supports a massive list of built-in search destinations, and requires no complicated setup.
* **Cons:** Requires basic familiarity with using a computer terminal or command line interface.
