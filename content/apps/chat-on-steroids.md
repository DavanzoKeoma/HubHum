### What it does in plain English
Chat On Steroids bridges your everyday chat assistant directly with your computer files and local terminal tools. It allows you to select specific folders that the assistant can safely read and edit, while keeping you fully in control of sensitive commands. You can split large tasks across multiple workers, monitor live tool progress, and receive instant updates on your phone when tasks finish or need your attention.

### Who it's for
* Software developers looking to let chat assistants interact directly with local project code and test runners.
* Power users who want to organize multi-step digital projects into structured, resumable tasks.
* Anyone wishing to monitor long-running automated tasks away from their desk using phone notifications.

### Key features
* **Local File Interaction:** Connect specific project folders so your assistant can directly read and modify your documents and code.
* **Multi-Worker Delegation:** Split independent tasks across multiple background workers to get more done in less time.
* **Interactive Control Steps:** Receive clear, precise commands for actions that require your manual confirmation before running.
* **Phone Notifications:** Stay informed via messaging apps or push alerts when a chat task finishes, fails, or needs user input.
* **Secure Permissions:** Strictly control what folders the workspace can touch and what actions it is allowed to perform.
