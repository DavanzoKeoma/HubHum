### What it does in plain English
BurpGPT adds a smart layer to your web security checks by using artificial intelligence to look for hidden problems. It helps you spot specific risks in how your website handles data that traditional tools might overlook. This tool creates a clear report so you can understand and fix these issues more easily.

### Who it's for
*   Security professionals who need to dig deeper into specific web application behaviors.
*   Developers who want to verify that their code handles sensitive data safely.
*   IT managers who want a higher-level overview of their website's security posture.

### Key features
*   Uses AI to analyze web traffic for unique security risks.
*   Allows you to customize what the AI looks for using simple text prompts.
*   Integrates directly into the Burp Suite interface for easy viewing.
*   Generates automated reports summarizing potential security issues.
*   Supports various AI models to fit different analysis needs.

*   **Pros:** Finds unique vulnerabilities that standard scanners miss; highly customizable analysis; integrates seamlessly with existing security tools.
*   **Cons:** Requires a valid API key for the AI service; sends data to external servers for analysis; the free community version is no longer maintained.
