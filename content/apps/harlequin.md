### What it does in plain English
Harlequin provides a clean, visual workspace for writing and executing database queries without leaving your command-line interface. It connects to popular database systems seamlessly, offering features like code completion, schema exploration, and custom color themes. Whether you are analyzing local files or querying remote servers, it keeps your workflow lightning-fast and focused.

### Who it's for
* **Data analysts and developers** who spend their day inside terminal windows and want a fast interface for checking database tables.
* **System administrators** who need a lightweight tool to query production or staging databases securely via secure shells.
* **Automation engineers** looking for a companion command-line utility to run headless queries and inspect catalogs.

### Key features
* Runs entirely inside your terminal with an intuitive layout and keyboard shortcuts.
* Connects to dozens of different database systems using flexible plug-in adapters.
* Includes a companion helper command for automated tasks, script execution, and headless queries.
* Fully customizable appearance with adjustable color themes and key bindings.
* Safely enforces read-only connection limits to prevent accidental data modifications.
