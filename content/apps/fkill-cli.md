### What it does in plain English
Sometimes a program stops responding or hogs your computer’s resources.  
fkill‑cli lets you pick the program you want to stop and ends it instantly.  
It works the same way on Windows, macOS and Linux.

### Who it's for
* Anyone who needs to close a frozen or slow‑moving app.  
* Developers who want a fast way to stop test processes.  
* Users who like a simple tool to free up memory and CPU.

### Key features
- Choose a program by typing part of its name, its number, or the port it uses.  
- Shows CPU and memory usage next to each program.  
- Option to force‑close a stubborn program.  
- Quiet mode that stops the program without extra messages.  
- Interactive screen with fuzzy search for quick selection.
