### What it does in plain English
coisas acts as a simple, online writing desk for your GitHub files. It allows you to open, edit, and save text documents directly in your web browser, removing the need to use complex coding tools. You can also browse your folder structure and drag-and-drop images into your documents with ease.

### Who it's for
* **Bloggers and writers** who store their articles in GitHub and want a quick, visual way to update text without opening a code editor.
* **Website owners** who use GitHub Pages and need a straightforward interface to manage their site's content files.
* **Developers** who prefer a lightweight, no-nonsense tool for making small text changes to their projects.

### Key features
* **Direct File Editing:** Open and save Markdown and HTML files directly from your GitHub official project page.
* **Visual File Browser:** See your folder structure clearly to find and organize your documents.
* **Image Management:** View all images in your official project page and drag them directly into your text editor.
* **Customizable Interface:** Adjust the look and behavior of the tool by adding a simple configuration file to your project.
* **No Installation Required:** Runs entirely in your web browser, so there is nothing to download or set up on your computer.

### How to install (Download)
Since this is a web-based tool, you do not need to download or install any software. You can start using it immediately by visiting the official site:

[Open coisas in your browser](https://coisas.fiatjaf.com/)

### Pros and Cons
* **Pros:** Completely free to use, runs in any modern web browser, and offers a clean, distraction-free editing experience.
* **Cons:** Only text files can be edited (binary files like images can be viewed but not modified), and the visual design is very basic compared to commercial tools.
