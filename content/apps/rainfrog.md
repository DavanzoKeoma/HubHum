### What it does in plain English
Rainfrog provides a clean, text-based interface for interacting with your databases without needing heavy graphical software. It allows you to browse tables, run queries, and view data properties using simple keyboard shortcuts. By running directly in your terminal, it keeps your workflow fast and focused on the data you need.

### Who it's for
*   Software developers who prefer staying inside their terminal environment.
*   Data analysts who need a quick, lightweight way to inspect database tables without launching complex management programs.

### Key features
*   **Keyboard-focused navigation:** Uses familiar shortcuts to move between menus, tables, and query results quickly.
*   **Built-in query editor:** Includes helpful features like keyword highlighting and a history of your past searches.
*   **Flexible data viewing:** Easily filter tables, copy specific data, and switch between different database schemas.
*   **Wide compatibility:** Works across various operating systems, including macOS, Linux, Windows, and mobile devices via terminal emulators.

### How to install (Download)
Rainfrog is best installed via your system's package manager (such as `brew install rainfrog` on macOS or `pacman -S rainfrog` on Arch Linux). If you prefer manual installation, you can download the latest binary for your system from the [Official Releases Page](https://github.com/achristmascarl/rainfrog/releases).

### Pros and Cons
*   **Pros:** Extremely lightweight, no heavy graphical interface, and free to use.
*   **Cons:** Requires some comfort with terminal commands and is currently under active development, so it is not recommended for critical production database modifications.
