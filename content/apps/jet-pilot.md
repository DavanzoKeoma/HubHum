### What it does in plain English
JET Pilot is a lightweight desktop application that brings all your cloud server clusters together into one clean screen. It reads your existing configuration files safely on your computer without sending any telemetry data or requiring an account. You can quickly view resource usage, inspect logs, edit configuration details, and manage multi-cloud environments seamlessly.

### Who it's for
* Cloud infrastructure administrators and software engineers managing distributed server environments.
* Developers who want a clean graphical interface to inspect containers and server logs without typing complex commands.
* Teams looking for a lightweight tool to monitor multiple cloud accounts and cluster deployments in one place.

### Key features
* **Unified Cluster Hub:** Bring together every server cluster from multiple cloud providers into one organized list with custom colors and labels.
* **Production Guardrails:** Prevent accidental mistakes by requiring manual confirmation before running destructive actions on critical production clusters.
* **Structured Log Viewer:** Inspect server logs across multiple containers easily with powerful search filters and visual time ranges.
* **Built-In Terminal:** Open a preconfigured terminal window instantly for any active server context without modifying your local computer setup.
* **Built with Privacy First:** Operates entirely offline using your local credentials with zero data collection, accounts, or tracking.
