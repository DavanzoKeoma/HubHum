### What it does in plain English
Grocy is a digital organizer for your home that keeps track of what food you have in your fridge, pantry, and freezer. It alerts you when items are about to expire so you can reduce food waste and avoid buying duplicates. Beyond groceries, it helps you coordinate household chores, plan weekly meals, and manage shopping lists effortlessly.

### Who it's for
* Home cooks and meal planners looking to reduce food waste and track pantry inventory
* Families or roommates who want to share shopping lists and divide household chores
* Privacy-conscious individuals who prefer hosting their own household data on a private server

### Key features
* Tracks expiration dates and quantities for all your household food items
* Automatically builds shopping lists based on missing items and stock thresholds
* Organizes weekly meal plans and recipe ingredients in a single dashboard
* Assigns, schedules, and tracks recurring household chores and tasks
* Supports barcode scanning using USB scanners or device cameras for quick entry

### How to install (Download)
To run Grocy as a standalone desktop application on Windows without setting up a web server, you can use [Grocy Desktop via Microsoft Store](https://apps.microsoft.com/detail/9NWB1TRNNKSF) or download the setup directly from the [Grocy Desktop Releases page](https://github.com/grocy/grocy-desktop). 

If you prefer to host it yourself on a web server or Docker, download the archive from the [Official Grocy Website](https://grocy.info). You can also view a live demo version on the [Grocy Public Demo](https://demo.grocy.info).

### Pros and Cons
* **Pros:** Free and open source forever, robust feature set beyond basic pantry tracking, built-in barcode lookup.
* **Cons:** Requires a web server setup or technical knowledge if self-hosted manually, mobile apps rely on the web interface or browser shortcuts.
