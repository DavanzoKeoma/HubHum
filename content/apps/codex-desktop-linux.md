### What it does in plain English
This app brings the official desktop artificial intelligence experience right to your Linux computer. It wraps the verified official release into a native package format while unlocking helpful optional additions. You can seamlessly chat, manage projects, and use various custom tweaks tailored specifically for Linux environments.

### Who it's for
* Linux users who want a dedicated desktop application for interacting with advanced artificial intelligence models.
* Power users looking to customize their setup with optional workspace enhancements and window management tools.
* Developers and enthusiasts preferring native package integration across Debian, Fedora, Arch, and Nix distributions.

### Key features
* Built directly from official upstream application payloads to maintain absolute compatibility.
* Supports popular Linux package managers including Debian, RPM, pacman, and Nix.
* Includes an optional feature software foundation for advanced tweaks, shortcuts, and themes.
* Works smoothly across both modern Wayland and traditional X11 window display servers.
* Features a distinct visual identity with a custom application name and colored icon.

### How to install (Download)
To build and install a native package for your distribution, clone the project files and run the setup command in your terminal:

```bash
git clone https://github.com/ilysenko/codex-desktop-linux.git
cd codex-desktop-linux
make bootstrap-native
```

For alternative installation formats, configuration details, or updates, please visit the [Official Releases and official project page Page](https://github.com/ilysenko/codex-desktop-linux).

### Pros and Cons
* **Pros:** Free and open-source, brings official capabilities natively to Linux, and includes optional feature toggles.
* **Cons:** Requires a quick terminal build step for native installation, and shares user profiles with official packages by default.
