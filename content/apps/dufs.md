### What it does in plain English
It lets you share any folder on your computer as a web page that anyone can open in a browser.  
Visitors can look at files, download them, upload new ones, or search for specific items.  

### Who it's for
* People who want to quickly give friends access to a collection of photos, documents, or software.  
* Small teams that need a temporary place to exchange files without signing up for cloud services.

### Key features
- Turn any local folder into a shareable web page with one command.  
- Allow visitors to upload files by dragging and dropping them.  
- Search inside the shared folder to find a file instantly.  
- Download an entire folder as a zip archive.  

### How to install (Download)
* Download the ready‑made program for Windows, macOS or Linux from the official releases page: [Download binaries (Windows, macOS, Linux)](https://github.com/sigoden/dufs/releases).  
* After downloading, unzip the file and place the program in a folder that’s on your system’s PATH, then run `dufs` from a terminal.  

### Pros and Cons
* **Pros:** Free forever, works on all major operating systems, no subscription needed.  
* **Cons:** Advanced settings require reading the documentation, and you need to keep the program running while sharing.
