### What it does in plain English
The Grav Admin Plugin provides a clean visual browser interface for managing your file-based website. It lets you create, edit, move, and delete pages without touching raw code or configuration files manually. You can also monitor your website activity, update your core system, and upload media files using simple drag-and-drop controls.

### Who it's for
* Content creators who prefer editing pages through visual forms rather than raw text files
* Website administrators looking to monitor updates, logs, and system health in one place
* Designers and developers who want a quick interface to manage site content on the go

### Key features
* Clean visual dashboard showing site activity, maintenance status, and quick page updates
* Full page management allowing you to create, edit, move, copy, and delete pages effortlessly
* Built-in syntax highlighting code editor with instant live previews and distraction-free fullscreen mode
* Drag-and-drop media uploading and placement directly inside your page editor
* One-click updates for your core system, themes, and installed plugins

### How to install (Download)
To set up this administration panel, visit the [Official Website](https://getgrav.org) for full platform guides, or install it directly through your system terminal using the built-in package manager:

```
$ bin/gpm install admin
```

### Pros and Cons
* **Pros:** Completely optional interface, keeps file management simple, includes a powerful built-in code editor.
* **Cons:** Requires a few prerequisite plugins to function properly, advanced configuration tasks may still require manual text edits.
