### What it does in plain English
AngelSword is a lightweight digital utility designed to check popular website content management systems for known safety weaknesses. It streamlines the testing process so security professionals can verify platform integrity within minutes. Although the original creator has stopped active updates, it remains a helpful reference tool for authorized system audits.

### Who it's for
* Information security professionals conducting authorized site audits
* Web administrators testing their own platforms for forgotten vulnerabilities
* Researchers studying historical website software flaws

### Key features
* Scans popular website content systems for known flaws
* Written in a lightweight scripting language for easy reading
* Designed for fast execution on standard operating systems
* Helps map out potential safety gaps during authorized checks
