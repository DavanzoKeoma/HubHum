### What it does in plain English
YunoHost turns a standard computer or virtual machine into a personal server that you can control yourself. It provides a friendly, visual dashboard to install and manage various web applications like email, chat, or file storage. By keeping your data on your own hardware, you regain control over your digital life and privacy.

### Who it's for
* Individuals who want to host their own email or websites without relying on big tech companies.
* Small organizations or families looking for a private, shared space to store files and communicate securely.

### Key features
* **Simple Dashboard:** Manage your entire server through a clean, easy-to-use web interface.
* **One-Click Apps:** Install popular web tools and services with a single click.
* **User Management:** Easily create and manage accounts for friends, family, or team members.
* **Built-in Security:** Includes automatic tools to handle security certificates and keep your server safe.
* **Privacy Focused:** Keep your data on your own hardware rather than storing it on third-party servers.

### How to install (Download)
To get started, visit the [official installation guide](https://doc.yunohost.org/admin/get_started/install_on/) on the YunoHost website. You can find general information and download options at [yunohost.org](https://yunohost.org).

### Pros and Cons
* **Pros:** Completely free and open-source, puts you in full control of your data, and simplifies complex server tasks.
* **Cons:** Requires your own hardware or a cloud server to run, and basic knowledge of how to set up a computer is helpful.
