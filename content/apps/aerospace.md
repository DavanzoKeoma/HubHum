### What it does in plain English
AeroSpace automatically arranges your open application windows into tidy, non-overlapping grids so you can see everything at once. You switch between different sets of windows using only your keyboard, which is much faster than clicking with a mouse. It works smoothly on modern Macs without requiring you to change any of your computer's core security settings.

### Who it's for
* **Developers and coders** who need to keep multiple code editors, terminals, and browser tabs visible simultaneously without clutter.
* **Power users** who prefer navigating their computer entirely through keyboard shortcuts for maximum speed and efficiency.
* **Productivity enthusiasts** who want a clean, organized desktop where every window has a specific, predictable place.

### Key features
* **Automatic Tiling:** Windows snap into a grid layout automatically, eliminating the need to manually resize or move them.
* **Keyboard-First Control:** Switch between workspaces and adjust window layouts using simple key combinations.
* **Fast Workspace Switching:** Change between different sets of apps instantly without any lag or visual animations.
* **Multi-Monitor Support:** Manage windows across multiple screens with the same logical, organized approach.
* **Simple Configuration:** Customize the tool by editing a simple text file, making it easy to back up and share your settings.

### How to install (Download)
The recommended way to install AeroSpace is through Homebrew, a popular tool for managing software on Mac. If you already have Homebrew installed, you can install AeroSpace by opening your terminal and typing the command provided in the official guide.

* [Read the Official Installation Guide](https://nikitabobko.github.io/AeroSpace/guide)
* [View the Official Project Page](https://github.com/nikitabobko/AeroSpace)

### Pros and Cons
* **Pros:** Completely free to use, highly customizable via text files, works without disabling system security features, and offers very fast workspace switching.
* **Cons:** It is currently in "Beta" status, meaning it may change or have bugs before the final version. It is designed for advanced users and does not have a visual settings menu, so you must be comfortable editing text files.
