### What it does in plain English
macOS‑Simple‑KVM lets you run macOS on a Linux computer. It uses QEMU and KVM to create a fast virtual machine. No Mac hardware is required.

### Who it's for
Linux users who need macOS for testing or development.  
Developers who want to run macOS apps without owning a Mac.  
Hobbyists wanting to explore macOS on a non‑Apple machine.

### Key features
- Fast setup with a single script.  
- Supports multiple macOS versions (High Sierra, Mojave, Catalina).  
- Easy integration with Virt‑Manager for advanced configuration.  
- Headless mode with VNC for cloud servers.  
- Customizable memory, CPU, and storage options.

### How to install (Download)
Download the latest release from the GitHub releases page: [Download from GitHub releases](https://github.com/foxlet/macOS-Simple-KVM/releases).

### Pros and Cons
* **Pros:** Free and open source, no subscription required, runs on any Linux distribution with QEMU.  
* **Cons:** Requires command‑line usage and some Linux knowledge, initial download of macOS image can be large, performance depends on host hardware.
