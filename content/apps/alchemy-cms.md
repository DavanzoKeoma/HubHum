### What it does in plain English
Alchemy CMS is a flexible content management system designed to integrate smoothly into Ruby on Rails websites. It separates your content from visual design so you can easily manage pages, images, and text through an intuitive dashboard. Whether you need a standard website or a headless content hub, it gives you complete control over your publishing workflow.

### Who it's for
* Ruby on Rails developers looking for a reliable, customizable content management tool for client websites.
* Content editors and writers who want a clean, user-friendly dashboard with live page previews.
* Growing businesses that need multi-language support, user access control, and SEO-friendly web pages.

### Key features
* Intuitive admin interface featuring real-time page previews and flexible editing blocks.
* Multi-language and multi-domain management to handle global audiences effortlessly.
* Built-in security with user access control and role-based permissions.
* On-the-fly image resizing and cropping for optimal media delivery.
* Flexible templating system that keeps content entirely separate from design code.

### How to install (Download)
You can explore the live system or install the software directly into your Rails environment:
* Test out the interface immediately on the [Alchemy CMS Live Demo](https://demo.alchemy-cms.com/) (use username `demo` and password `demo123`).
* Check out the step-by-step instructions and project guides on the [Official Alchemy CMS Website](https://www.alchemy-cms.com).
* Read detailed configuration documentation in the [Alchemy CMS Guidelines](https://guides.alchemy-cms.com).

### Pros and Cons
* **Pros:** Free and open-source, highly extensible through Rails engines, built-in SEO-friendly URL structuring, and intuitive live previews.
* **Cons:** Requires familiarity with Ruby on Rails to set up and configure properly.
