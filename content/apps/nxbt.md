### What it does in plain English
NXBT lets your computer pretend to be a wireless game controller so you can play on your Nintendo Switch console. You can connect through a visual web page, a terminal screen, or automated macro scripts. It translates standard keyboard presses and gamepad inputs into Bluetooth signals your console understands instantly.

### Who it's for
* Gamers who want to use alternative controllers or standard keyboards on their console.
* Automation enthusiasts looking to run repeating action macros for games.
* Developers creating custom Python tools to interact with video game hardware.

### Key features
* Control your console using any modern web browser and a standard keyboard or gamepad.
* Run a terminal interface for lightweight text-based device control.
* Create and replay automated button macros using simple text commands or Python scripts.
* Emulate multiple controllers simultaneously across available Bluetooth hardware.
* Connect and reconnect quickly using built-in Bluetooth integration.

### How to install (Download)
To download and install the software, visit the official [GitHub Releases Page](https://github.com/Brikwerk/nxbt/releases) or use your system's package manager as outlined in the official setup guides.

### Pros and Cons
* **Pros:** Free and open source, offers multiple control methods including a browser interface, supports custom automation macros.
* **Cons:** Requires a compatible Bluetooth adapter and some initial terminal setup on certain operating systems.
