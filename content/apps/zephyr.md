### What it does in plain English
Zephyr is a lightweight desktop program that helps you control network routing and proxy connections with a clean, modern interface. It lets you organize connection settings, switch between automated routing rules, and monitor your live internet traffic in real-time. Built with a focus on personal privacy and digital security, it keeps your connection details protected while running quietly in your computer's system tray.

### Who it's for
* Remote workers and digital nomads needing reliable control over international routing and connection paths.
* Privacy-conscious individuals looking for a sleek, straightforward program to manage secure network traffic.
* Advanced users who want customizable routing rules and automated failover options without complicated terminal setups.

### Key features
* **Simple Dashboard:** Manage your proxy connections and routing settings through a clean, easy-to-navigate interface.
* **Smart Routing Rules:** Automatically route traffic using custom rules, filter lists, and automated node selection.
* **System Integration:** Runs quietly in your system tray with support for global keyboard shortcuts and quick mode switching.
* **Resource Monitoring:** View live connection lists, track data speeds, and inspect network traffic trends at a glance.
* **Built-in Security:** Includes safeguards against unsafe web links, script sandboxing, and strict permission controls.
