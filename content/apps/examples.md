### What it does in plain English
These examples show how to build desktop apps with Python and Qt.  
You can run them on Windows, Mac, or Linux.  
They cover widgets, layouts, signals, and more.  

### Who it's for
Beginners learning Python GUI development.  
Hobbyists building small desktop tools.  
Educators teaching GUI programming.  

### Key features
- Ready‑made example projects.  
- Cross‑platform compatibility.  
- Clear code and screenshots.  
- Easy to run with a virtual environment.  
- Includes official PyQt demos.  

### How to install (Download)
[Download ZIP archive](https://github.com/pyqt/examples/archive/_.zip)  

### Pros and Cons
* **Pros:** free, open source, cross‑platform, many examples.  
* **Cons:** requires Python 3, needs a virtual environment, some examples use older PyQt5, may need manual dependency installation.
