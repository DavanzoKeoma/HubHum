### What it does in plain English
jscpd scans your programming projects to find blocks of code that have been needlessly copied and pasted across files. It understands the specific grammar rules of over 220 different programming languages, ensuring accurate detection without getting confused by simple name changes. Beyond duplication, it helps you identify unused dead code, track complexity, and generate clear health reports for your software.

### Who it's for
* Software developers looking to clean up messy codebases and reduce technical debt.
* Development teams wanting automated checks in their daily workflow to prevent copy-pasting.
* Project maintainers tracking code health and duplication trends over time.

### Key features
* Language-aware detection that understands comments, strings, and syntax rules across 220+ formats.
* Identifies exact matches, renamed variables, near-miss copies, and semantically similar functions.
* Pinpoints dead code, unused files, and structural complexity hotspots.
* Integrates smoothly into continuous integration pipelines and automated workflows.
* Fast performance powered by a robust backend engine requiring minimal setup.

### How to install (Download)
You can install jscpd easily using your preferred package manager or command-line tool:

* **macOS / Linux:** Run `curl -fsSL https://jscpd.dev/install.sh | bash` in your terminal.
* **Windows (PowerShell):** Run `irm https://jscpd.dev/install.ps1 | iex`.
* **Node.js (npx):** Run `npx jscpd .` to try it immediately without a permanent installation.
* **Other methods:** Available via npm (`npm install -g jscpd`), PyPI (`pip install jscpd`), Homebrew (`brew install jscpd`), and Docker.

### Pros and Cons
* **Pros:** Supports a massive variety of programming languages, runs quickly, and offers flexible reporting options.
* **Cons:** Advanced semantic analysis features require additional configuration or local model downloads.
