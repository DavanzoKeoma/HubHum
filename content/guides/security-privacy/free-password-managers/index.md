### All Qualifying Software in This Topic

- **[Gitleaks](/HubHum/apps/gitleaks/)** — Scan your code repositories and directories to find accidentally exposed passwords, API keys, and sensitive tokens before they leak. *(CLI Tool · License: Open Source (MIT))*
- **[KeePassXC](/HubHum/apps/keepassxc/)** — Store all your logins, PINs, and recovery codes in an encrypted local vault on your device with zero monthly fees. *(Desktop App · License: Open Source (GPL v3))*
- **[HackBrowserData](/HubHum/apps/hackbrowserdata/)** — This tool helps you securely extract and view saved passwords, history, and cookies from various web browsers on your computer. *(Desktop App · License: Open Source (MIT))*
- **[Bitwarden](/HubHum/apps/clients/)** — Bitwarden is a secure digital vault that remembers your passwords and sensitive information across all your devices. *(Desktop App · License: Custom Open License)*
- **[Pocket ID](/HubHum/apps/pocket-id/)** — Pocket ID provides a secure and easy way to manage user logins for your applications using modern passkey technology instead of passwords. *(Self-Hosted Web App · License: Open Source (BSD))*
- **[Git Credential Manager](/HubHum/apps/git-credential-manager/)** — Git Credential Manager simplifies how you sign in to your coding accounts by securely storing your access details across all your devices. *(Desktop App · License: Custom Open License)*
- **[pdfcpu](/HubHum/apps/pdfcpu/)** — A powerful utility that lets you merge, split, encrypt, and modify PDF documents directly from your computer setup. *(Desktop App · License: Open Source (Apache 2.0))*
- **[KeePassDX](/HubHum/apps/keepassdx/)** — Manage all your passwords securely on your mobile device using a single encrypted file with top-tier protection. *(Desktop App · License: Open Source (GPL v3))*
- **[MacPass](/HubHum/apps/macpass/)** — MacPass is a free, open-source password manager for Mac that securely stores and organizes all your login credentials in one encrypted place. *(Desktop App · License: Custom Open License)*
- **[Cloud Torrent](/HubHum/apps/cloud-torrent/)** — Cloud Torrent lets you manage your file downloads from any web browser and stream your media directly from your own server. *(Self-Hosted Web App · License: Custom Open License)*
- **[LessPass](/HubHum/apps/lesspass/)** — LessPass creates unique passwords on the fly using a master password, eliminating the need to sync or store your sensitive data. *(Self-Hosted Web App · License: Open Source (GPL v3))*
- **[dotenvx](/HubHum/apps/dotenvx/)** — Encrypt sensitive settings files so you can safely store them alongside your code in version control without risking leaks. *(Desktop App · License: Open Source (BSD))*
