### What it does in plain English
Gobang is a lightweight terminal tool that lets you connect to and browse your databases without leaving the command line. It supports popular database engines and lets you move around tables, view records, and copy cell values entirely through your keyboard. By keeping everything inside a text interface, it offers a distraction-free environment for inspecting data quickly.

### Who it's for
* Developers and data analysts who spend their day inside terminal windows.
* System administrators needing a fast way to check database contents on remote servers.
* Power users who prefer lightweight keyboard-driven utilities over heavy desktop applications.

### Key features
* Cross-platform support for macOS, Linux, and Windows.
* Connects seamlessly with MySQL, PostgreSQL, and SQLite databases.
* Intuitive keyboard navigation for scrolling, filtering, and switching tabs.
* Quick cell value copying and filter tools for rapid data lookup.
* Simple configuration file setup to manage multiple database connections.

### How to install (Download)
You can install gobang using various package managers depending on your operating system:
* **Homebrew (macOS/Linux):** Run `brew install tako8ki/tap/gobang` in your terminal.
* **Scoop (Windows):** Run `scoop install gobang` in your command prompt.
* **AUR (Arch Linux):** Install `gobang-bin` from the Arch User official project page.
* **Cargo (Rust Environment):** Run `cargo install gobang` if you have Rust installed.
* **Direct Binaries:** Download precompiled files directly from the [Official Releases Page](https://github.com/TaKO8Ki/gobang/releases).

### Pros and Cons
* **Pros:** Lightweight and fast, completely keyboard-driven, supports multiple popular database types.
* **Cons:** Still in alpha development, requires manual editing of a configuration file to add connections.
