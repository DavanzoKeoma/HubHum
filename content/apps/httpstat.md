### What it does in plain English
httpstat makes it easy to understand why a website feels slow by breaking down the connection process into simple steps. It shows you exactly how long it takes to find the server, connect to it, and download the content. This tool helps you spot the specific part of the connection that is causing delays.

### Who it's for
*   **Tech-savvy hobbyists** who want to understand their internet connection better without using complicated software.
*   **Web developers** who need to quickly check if a website is responding slowly and identify the cause.
*   **IT support staff** who need a quick, visual way to diagnose connection issues for clients.

### Key features
*   **Clear visual breakdown:** Displays timing for each step of the web connection in an easy-to-read format.
*   **Simple installation:** Works as a single file script with no extra software needed, compatible with Python 3.
*   **Data export:** Can save results as structured data files for later analysis or sharing.
*   **Performance checks:** Allows you to set speed targets and alerts you if the connection is slower than expected.
*   **Flexible output:** Supports different display modes, including plain text and machine-readable formats.
