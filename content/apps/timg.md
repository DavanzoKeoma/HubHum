### What it does in plain English
timg is a handy utility that lets you inspect images, play videos, and scroll through animated GIFs directly inside your text terminal. It automatically adapts to your terminal's capabilities, using advanced graphic protocols for high-resolution output or clever color character blocks as a reliable fallback. You can quickly check photos over remote connections or browse through folders of images in an organized grid view without ever leaving your command prompt.

### Who it's for
* Command-line enthusiasts who want to inspect images and media quickly without leaving the shell
* Developers and system administrators working on remote servers via secure shell connections
* Anyone looking for a lightweight way to preview media files directly inside terminal file managers

### Key features
* Displays static pictures, animated GIFs, and plays full video files in-line
* Organizes multiple files into customizable grid views or contact sheets for quick browsing
* Auto-detects modern terminal graphic capabilities for pristine, full-resolution display
* Falls back to colored text blocks for universal compatibility across standard shells
* Supports automatic cropping, resizing, background color adjustment, and rotation
