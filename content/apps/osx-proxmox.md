### What it does in plain English
OSX‑PROXMOX lets you run macOS on any computer that can run Proxmox VE.  
It works with both AMD and Intel processors.  
The setup is done with a single script and a clear guide.

### Who it's for
- Tech hobbyists who want to experiment with macOS.  
- Developers needing a macOS environment for testing.  
- Students learning about virtualization.

### Key features
- Supports macOS High Sierra through Sequoia.  
- Compatible with Proxmox VE 7 to 9.  
- Easy one‑click installation script.  
- Works on both AMD and Intel hardware.  
- Includes troubleshooting tips and cloud options.

### How to install (Download)
- Visit the official setup page: [Official Setup Page](https://osx-proxmox.com).  
- Run the install script directly: [Run the install script](https://install.osx-proxmox.com).

### Pros and Cons
* **Pros:** free forever, no subscription.  
* **Cons:** requires Proxmox VE, some advanced steps may need technical knowledge, BIOS tweaks may be required.
