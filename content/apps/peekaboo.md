### What it does in plain English
Peekaboo gives your Mac the ability to look at its own display, understand open windows, and interact with buttons and menus like a human would. You can tell it what to do using everyday language, and it will handle repetitive clicking, typing, and navigating across your desktop apps. It runs locally on your computer to keep your personal data and workflows entirely private.

### Who it's for
* Mac power users who want to automate repetitive daily desktop tasks without writing complex scripts from scratch.
* Developers and testers who need to inspect user interface elements and simulate user actions automatically.
* Anyone looking to connect smart assistant tools directly to their desktop environment for hands-free navigation.

### Key features
* **Screen observation:** Captures the entire system or individual application windows instantly for visual analysis.
* **Smart UI inspection:** Maps out buttons, menus, and text fields with unique identifiers for precise targeting.
* **Natural language commands:** Instructs your computer to open apps, search websites, and fill forms using plain text.
* **Background execution:** Performs targeted typing and clicking actions without forcing target apps to the foreground.
* **Menu-bar access:** Provides quick permission onboarding and status monitoring through a lightweight system menu item.

### How to install (Download)
* **Mac App (.dmg):** Download the signed installer directly from the [latest GitHub release](https://github.com/openclaw/Peekaboo/releases/latest).
* **Command Line (Homebrew):** Run `brew install openclaw/tap/peekaboo` in your terminal.
* **Node Package:** Install the toolset and assistant launcher using Node.js via `npx -y @steipete/peekaboo --version`.

### Pros and Cons
* **Pros:** Open-source and privacy-friendly, works in the background, supports natural language workflows.
* **Cons:** Requires macOS 15 or later, initial setup needs explicit system permission approvals for screen recording and accessibility.
