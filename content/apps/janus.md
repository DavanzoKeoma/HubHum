### What it does in plain English
Janus is a handy assistant that lives inside your command-line interface to help you write and update software code without spending any money. It automatically cycles through the smartest free artificial intelligence models available, seamlessly jumping to a backup model if one happens to be busy or reach its usage limits. By routing your programming tasks intelligently behind the scenes, it delivers fast, capable coding help right inside your existing workflow.

### Who it's for
* Software developers looking for a free, reliable terminal-based coding assistant to handle everyday programming tasks.
* Students and hobbyists who want AI-powered code suggestions and debugging help without purchasing expensive monthly subscriptions.
* Command-line power users who prefer keyboard-driven workflows for editing files and managing projects.

### Key features
* Automatically routes your coding requests to the best available free AI model in real time.
* Seamlessly switches to alternative models if the primary choice is busy or hits rate limits.
* Reads, creates, and modifies local project files directly from your terminal.
* Runs shell commands and helps debug failing tests with simple conversational prompts.
* Keeps all data local and private, only communicating with the specific AI service keys you provide.

### How to install (Download)
To install Janus, make sure you have Node.js version 22.19 or newer installed on your computer, then run the following command in your terminal:

```sh
npm install -g @janus-sh/janus
```

After installation, simply type `janus` in any project folder to get started, or visit the [Official GitHub official project page](https://github.com/janus-sh/janus) to learn more.

### Pros and Cons
* **Pros:** Completely free to use, no expensive subscriptions required, automatic fallback across multiple AI providers.
* **Cons:** Requires a command-line interface and manual setup of free API keys from external providers.
