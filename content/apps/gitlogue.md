### What it does in plain English
gitlogue shows the changes you made to your code as a moving story.  
It types out each line, highlights the language, and shows how files appear and disappear.  
You can watch it loop forever or focus on a specific part of the history.

### Who it's for
* Developers who want a fun way to review how a project grew.  
* Teachers and presenters who need a visual aid to explain code evolution.  
* Anyone who likes watching a lively animation on their screen while working.

### Key features
- Realistic typing animation that mimics a person writing code.  
- Colorful syntax highlighting for dozens of programming languages.  
- Visual file‑tree that shows added, changed, and removed files.  
- Screensaver‑style mode that plays random changes endlessly.  
- Multiple themes and fast performance on most computers.

* **Pros:** completely free, works on many operating systems, lightweight, highly visual, customizable themes.  
* **Cons:** requires a command‑line window, no graphical installer, static elements can cause burn‑in on OLED screens if left running for long periods.
