### What it does in plain English
This web tool transforms your local code folders into a single, well-structured text prompt for artificial intelligence models. It runs entirely inside your web browser without sending your source files to external servers or requiring complex software installations. You can easily filter files, save reusable configurations, and clean up extra whitespace to fit massive codebases into tight prompt limits.

### Who it's for
* Software developers who want to share local source code with artificial intelligence assistants safely and efficiently.
* Programmers looking to save time by reusing file selection setups across repeated coding tasks.
* Privacy-conscious creators who refuse to upload proprietary source code to unknown third-party servers.

### Key features
* **100% Local Processing:** Reads folders directly on your computer using secure browser capabilities without uploading data.
* **No Installation Steps:** Operates entirely within any modern web browser as a self-contained page.
* **Preset Management:** Saves your favorite file groupings and custom settings for instant reloading later.
* **Context Size Monitor:** Displays real-time file size and line counts to help you avoid exceeding artificial intelligence limits.
* **Built-in Cleanup:** Optionally trims unnecessary text and compresses code files to maximize available prompt space.

### How to install (Download)
To use this application, visit the [Official Source Page](https://github.com/Dicklesworthstone/your-source-to-prompt.html) and download the single `your-source-to-prompt.html` file to your computer. Then, simply double-click or drag the downloaded file into any modern web browser like Google Chrome to start using it immediately.

### Pros and Cons
* **Pros:** Completely free forever, works offline without installations, and guarantees total data privacy.
* **Cons:** Requires a modern Chromium-based browser to access local folder selection features.
