### What it does in plain English
AIChat acts as a smart bridge between you and various artificial intelligence services directly within your computer's command window. It allows you to chat with AI, ask for help with complex tasks, or even have the computer write commands for you based on simple instructions. You can use it to analyze files, organize your work, and automate repetitive steps without ever leaving your text-based workspace.

### Who it's for
* Software developers who want to speed up their coding and terminal workflows.
* Power users who prefer managing their computer through text commands rather than clicking through menus.

### Key features
* **Universal Access:** Connects to over 20 different AI services, including the most popular models available today.
* **Smart Shell Assistant:** Describe what you want to do in plain language, and the app will generate the exact command needed to perform the task.
* **Interactive Chat:** Use a dedicated mode to hold ongoing conversations with the AI, complete with history and helpful shortcuts.
* **File & Data Handling:** Easily feed local files, folders, or web addresses into the AI to get summaries or specific answers.
* **Customizable Roles:** Set specific behaviors or personalities for the AI to ensure it always gives you the type of help you need.

### How to install (Download)
You can download the latest version for your operating system directly from the [Official GitHub Releases page](https://github.com/sigoden/aichat/releases). 

If you prefer using package managers, you can also install it using:
* **Homebrew/Linuxbrew:** `brew install aichat`
* **Windows Scoop:** `scoop install aichat`
* **Arch Linux:** `pacman -S aichat`
* **Android Termux:** `pkg install aichat`

### Pros and Cons
* **Pros:** Extremely fast, supports a massive range of AI providers, and works entirely within your existing workflow.
* **Cons:** Requires basic familiarity with using a terminal or command prompt to set up and operate.
