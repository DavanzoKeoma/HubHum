### What it does in plain English
Open Apps is a hand-picked directory of real, production-grade applications that you can run, study, and extend. Instead of simple tutorials or starter kits, it focuses on fully functional apps across productivity, finance, developer tools, and more. It helps you discover software worth your time and connects you directly to the underlying source code.

### Who it's for
* Software developers looking to learn from clean, real-world application architectures.
* Tech enthusiasts who want to discover self-hostable alternatives to popular commercial software.
* Open-source contributors searching for active projects worth supporting or extending.

### Key features
* Hand-curated directory organized by clear categories like productivity, finance, and tools.
* Weekly metadata syncs to keep project stats, links, and details fresh.
* Structured catalog format built for easy browsing both on the web and through AI-readable text files.
* Direct links to official source code project pages and dedicated web previews.

### How to install (Download)
To explore the directory online or submit a new project, visit the official website:
[Open App Scout Website](https://openappscout.com)

[Source Code on GitHub](https://github.com/tortuvshin/open-apps)

### Pros and Cons
* **Pros:** Hand-curated high-quality entries, completely open source, regularly updated metadata.
* **Cons:** Requires exploring individual project pages to download or host specific apps.
