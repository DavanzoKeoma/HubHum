### What it does in plain English
Pebrel brings local computer windows, remote server connections, file explorers, and smart text assistant tools into a single, clean desktop workspace. You can split your screen into multiple panels to manage several tasks side by side without losing track of your workflow. It uses your computer's graphics hardware to keep scrolling and typing completely smooth and responsive.

### Who it's for
* Software developers and system administrators managing multiple remote servers and local command windows.
* Power users who work extensively with command-line helpers and coding assistants.
* Anyone looking for a customizable, modern command workspace with built-in file browsing and server management.

### Key features
* GPU-accelerated graphics engine ensuring fluid split-screen navigation and smooth typing.
* Built-in secure remote connection management with integrated file transfers and bookmarking.
* Smart auto-complete suggestions that predict commands based on your current project and system environment.
* Dedicated activity sidebars and reader panels designed specifically for command-line artificial intelligence tools.
* Fully customizable appearance with support for custom color themes, window transparency, and Lua-based configuration settings.
