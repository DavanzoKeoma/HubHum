### All Qualifying Software in This Topic

- **[Gitleaks](/HubHum/apps/gitleaks/)** — Scan your code repositories and directories to find accidentally exposed passwords, API keys, and sensitive tokens before they leak. *(CLI Tool · License: Open Source (MIT))*
- **[KeePassXC](/HubHum/apps/keepassxc/)** — Store all your logins, PINs, and recovery codes in an encrypted local vault on your device with zero monthly fees. *(Desktop App · License: Open Source (GPL v3))*
- **[Pocket ID](/HubHum/apps/pocket-id/)** — Pocket ID provides a secure and easy way to manage user logins for your applications using modern passkey technology instead of passwords. *(Self-Hosted Web App · License: Open Source (BSD))*
- **[Git Credential Manager](/HubHum/apps/git-credential-manager/)** — Git Credential Manager simplifies how you sign in to your coding accounts by securely storing your access details across all your devices. *(Desktop App · License: Custom Open License)*
- **[LessPass](/HubHum/apps/lesspass/)** — LessPass creates unique passwords on the fly using a master password, eliminating the need to sync or store your sensitive data. *(Self-Hosted Web App · License: Open Source (GPL v3))*
- **[Personal Management System](/HubHum/apps/personal-management-system/)** — This web application acts as a central dashboard to store your notes, passwords, finances, and files in one private, secure location. *(Self-Hosted Web App · License: Open Source (MIT))*
- **[NodeWarden](/HubHum/apps/nodewarden/)** — NodeWarden lets you run a Bitwarden‑compatible password manager on Cloudflare Workers, giving you a fast, offline‑ready web vault and full sync across devices. *(Self-Hosted Web App · License: Custom Open License)*
- **[PasswordPusher](/HubHum/apps/passwordpusher/)** — PasswordPusher lets you share sensitive information securely by creating links that automatically delete after they are viewed or expire. *(Self-Hosted Web App · License: Open Source (Apache 2.0))*
- **[Magnetissimo](/HubHum/apps/magnetissimo/)** — Magnetissimo searches multiple torrent sites at once and saves the results to your own private, searchable database. *(Self-Hosted Web App · License: Open Source (MIT))*
- **[GlobalProtect-openconnect](/HubHum/apps/globalprotect-openconnect/)** — Connect securely to corporate networks with browser single sign-on, multi-factor authentication, and multi-platform support. *(Desktop App · License: Open Source (GPL v3))*
- **[Rowel](/HubHum/apps/rowel/)** — Store all your passwords, keys, and private files in a secure vault on your own devices without sharing data with online subscription services. *(Desktop App · License: Open Source (GPL v3))*
- **[encrypted-note](/HubHum/apps/encrypted-note/)** — Store your seed phrases, passwords, and API keys securely in an offline digital vault on your computer. *(Desktop App · License: Open Source (MIT))*
