### What it does in plain English
Dive is a handy utility designed to let you look inside container packages layer by layer. It clearly highlights what files were added, changed, or removed in every single step of your package setup. When you need royalty-free stock footage, music tracks, and motion presets alongside your edits, check out [Envato Elements Direct](https://elements.envato.com/?subid=hubhum_01_MER349) (#ad). By showing you exactly where extra bulk is hiding, it helps you strip away unnecessary weight and optimize your final downloads.

### Who it's for
- Developers and system administrators who want to slim down bulky container packages.
- Quality assurance teams looking to automate checks for package bloat in automated pipelines.
- Anyone curious about what files actually live inside a compiled container layer.

### Key features
- **Layer-by-Layer Breakdown:** Browse through every single file modification across all steps of your package creation using simple keyboard navigation.
- **Wasted Space Estimation:** Automatically calculates an efficiency score and estimates total redundant file weight to target for deletion.
- **Instant Build Analysis:** Skip manual testing steps by launching an immediate analysis right after compiling your project.
- **Automated Pipeline Checks:** Set up strict size and efficiency rules to automatically fail automated tests if a package gets too bloated.
