### What it does in plain English
This utility helps users completely remove the pre-installed Microsoft Edge browser from their Windows computer. It runs a straightforward script that clears out deep system files associated with the browser. You can choose to remove just the web browser or include underlying system components depending on your preferences.

### Who it's for
* Advanced Windows users who prefer a completely customized operating system setup.
* Individuals who want to free up system storage by deleting unneeded default programs.
* People who prefer using alternative web browsers and want to eliminate browser clutter.

### Key features
* Simple executable tool for straightforward removal without technical setup.
* Options to target specific parts of the browser installation.
* Lightweight script design that runs efficiently on Windows.
* Allows reclaiming disk space taken up by unwanted pre-installed software.
