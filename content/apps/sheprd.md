### What it does in plain English
Sheprd brings your command-line terminals, code workspaces, and automated coding assistants into a single high-performance desktop window. You can easily organize multiple projects, chat with coding companions, review uncommitted changes side by side, and securely connect to remote servers. It keeps your sessions running safely in the background even if you close the main user interface.

### Who it's for
* Software developers juggling multiple code project pages and terminal windows.
* Engineers who collaborate with automated coding assistants and need quick review tools.
* Power users managing projects across local computers and remote cloud servers.

### Key features
* Unified sidebar combining your workspaces, Git worktrees, system load monitors, and active helper bots.
* Side-by-side code review tools that let you leave notes on specific lines and send them right back to your assistant.
* Built-in browser tabs with page annotation features for testing local web applications.
* Resource monitors showing live CPU, memory, and graphics card usage for local and remote hosts.
* Customizable layouts and hundreds of built-in color themes to match your personal style.
