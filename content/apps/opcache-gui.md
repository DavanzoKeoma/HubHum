### What it does in plain English
This tool creates a user-friendly dashboard that shows exactly how your website is handling its internal data storage. It allows you to see which files are currently being saved for faster loading and provides a simple way to clear that storage if needed. It is designed to be lightweight and works directly within your existing website setup.

### Who it's for
* Website administrators who want to monitor server performance without using complex command-line tools.
* Developers looking for a quick, visual way to debug or clear cached files during website updates.

### Key features
* **Real-time Monitoring:** Watch your website's performance statistics update automatically every few seconds.
* **File Management:** Easily view, filter, and clear specific cached files or reset the entire cache with one click.
* **Visual Insights:** See memory usage and hit rates through clear, easy-to-read charts and gauges.
* **Customizable:** Adjust settings to hide or show specific information, change refresh rates, or even customize the interface language.
* **Responsive Design:** The interface is clean and works well on both desktop and mobile browsers.

### How to install (Download)
To use this tool, you can download the latest version directly from the official release page:
[Download opcache-gui from GitHub Releases](https://github.com/amnuts/opcache-gui/releases)

Once downloaded, simply place the `index.php` file into a folder on your web server and open it in your browser. Alternatively, if you use Composer, you can add it to your project by running `composer require amnuts/opcache-gui`.

### Pros and Cons
* **Pros:** Completely free and open-source, very lightweight, no complex setup required, and provides a much better experience than reading raw server data.
* **Cons:** Requires a basic understanding of where to place files on your web server; requires PHP 7.1 or newer to function.
