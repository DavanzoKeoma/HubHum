### What it does in plain English
This helpful utility scans your programming project to detect pieces of code that are exported but never actually called or imported anywhere else. It reads your project rules and outputs a neat list of dormant items for you to review.

### Who it's for
* Software developers maintaining large codebases who want to remove dead code and reduce clutter.
* Quality assurance engineers ensuring every exported module serves a live purpose.
* Project maintainers preparing code cleanups before major version updates.

### Key features
* Scans project settings automatically to understand your file structure.
* Reports unused items with exact file names and line numbers for easy tracking.
* Ignores specific files or folders using simple regular expressions.

### How to install (Download)
You can install this tool directly through your favorite package manager by running `npm install --save-dev ts-prune`, `yarn add --dev ts-prune`, or `pnpm add --save-dev ts-prune` in your project folder. You can also view the project source and releases page at [GitHub Releases](https://github.com/nadeesha/ts-prune/releases).

### Pros and Cons
* **Pros:** Free and open source, runs quickly, leaves source files untouched during analysis.
* **Cons:** Cannot automatically detect uses created through complex dynamic imports or software foundation magic.
