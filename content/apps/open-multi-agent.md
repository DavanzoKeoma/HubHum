### What it does in plain English
Open Multi-Agent provides a secure environment where you can organize multiple AI agents to work together on complex tasks. It includes built-in safety features that require human approval before the agents take significant actions. Every step the agents take is recorded in a private journal, allowing you to review exactly what happened and why.

### Who it's for
* Organizations that need to maintain strict control and audit trails over automated AI workflows.
* Developers building custom AI-powered tools who want to ensure their systems remain private and self-hosted.

### Key features
* **Human-in-the-loop:** Set up mandatory approval gates so that agents cannot proceed without your explicit permission.
* **Verifiable records:** Keep a detailed, offline journal of every input, tool usage, and result for complete transparency.
* **Total privacy:** No telemetry or external tracking; you own your data, your models, and your environment.
* **Flexible model support:** Connect to a wide range of local or cloud-based AI models using standard adapters.
* **Offline dashboard:** Use the built-in viewer to replay and inspect past agent runs without needing an internet connection.

### How to install (Download)
This tool is designed for developers and requires [Node.js](https://nodejs.org/) (version 20 or newer). You can start a new project by running the following command in your terminal:

`npm create oma-app@latest my-oma`

For existing projects, you can add the core library via:

`npm install @open-multi-agent/core`

For full setup instructions and documentation, visit the [Official Getting Started Guide](https://open-multi-agent.com/getting-started/introduction/).

### Pros and Cons
* **Pros:** Complete ownership of data, no subscription fees for the software, and high transparency through audit logs.
* **Cons:** Requires basic technical knowledge to set up and manage, and you must provide your own AI model access.
