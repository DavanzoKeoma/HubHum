### What it does in plain English
Pinvou Agent is a desktop workspace that goes far beyond standard chat windows by turning your instructions into real, editable project deliverables. It helps you research documents, design visual posters, or write software code using specialist assistants. You can organize files, manage personal knowledge bases, and connect your favorite intelligence models while keeping your data private.

### Who it's for
* Freelancers and professionals managing research, writing, and file organization tasks in one place.
* Designers who want to turn text descriptions into editable visual layouts and graphics.
* Software developers looking to bring specialized coding assistants directly into local project folders.

### Key features
* Combines multi-session chat, file attachments, and an artifact panel to preview and edit generated files in one place.
* Features a dedicated design mode to turn natural language prompts into editable layouts and graphic elements.
* Integrates coding companions to read, edit, and run commands inside real project workspaces.
* Includes a local knowledge base with vector search and customizable specialist persona cards.
* Supports local model execution for full privacy alongside any OpenAI-compatible cloud service endpoint.
