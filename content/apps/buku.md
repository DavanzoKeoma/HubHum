### What it does in plain English
`buku` is a lightweight command-line tool that lets you collect, organize, and search through your favorite web links. It automatically fetches page titles, descriptions, and tags from the internet while keeping your personal browsing data completely private on your device. You can easily pull in existing links from popular web browsers, export them to various standard document formats, or open them instantly whenever you need them.

### Who it's for
* Power users and keyboard enthusiasts who love fast, text-driven productivity tools.
* Privacy-conscious individuals who want absolute control over their personal link collections without third-party tracking.
* Researchers and developers looking for a lightweight, scriptable way to archive and search web resources.

### Key features
* Automatically gathers titles, descriptions, and custom tags for saved web addresses.
* Imports existing bookmarks from major web browsers effortlessly.
* Supports instant searching using keywords, substrings, tags, and advanced regular expressions.
* Stores everything in a clean, portable database that you can easily back up or sync across devices.
* Integrates smoothly with your preferred text editor for manual entry and editing.

### How to install (Download)
To install `buku` on your system using Python's package manager, open your terminal and run:

```bash
pip3 install buku
```

For alternative installation options, package manager availability for Linux distributions, or source code downloads, visit the official [buku Releases Page](https://github.com/jarun/buku/releases).

### Pros and Cons
* **Pros:** Completely free and open source, lightweight footprint, no mandatory cloud subscriptions or accounts, works entirely offline for stored links.
* **Cons:** Operates primarily via command-line or text interface, which may require a brief learning curve for users unfamiliar with terminal tools.
