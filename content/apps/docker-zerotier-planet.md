### What it does in plain English
You can set up your own ZeroTier root server at home or in the cloud.  
It gives you a web page where you can create and manage private virtual networks.  
It also provides the files your devices need to join that network.

### Who it's for
- Anyone who wants a private virtual network for home‑office devices.  
- Small teams that need a secure LAN without relying on third‑party services.  
- Hobbyists who like to keep full control over their network traffic.

### Key features
- Simple web page to create and manage networks.  
- Generates the “planet” and “moon” files devices need to connect.  
- Runs on any Linux computer with internet access.  
- Keeps all network data on your own server.  
- Optional HTTPS or SSH tunnel for remote management.

### How to install (Download)
- [Project page / Setup instructions](https://github.com/xubiaolin/docker-zerotier-planet/releases)

### Pros and Cons
* **Pros:** free to use, runs on any Linux server, includes a web management interface.  
* **Cons:** requires a Linux server with internet, needs a few command‑line steps to start, works only with ZeroTier clients that accept a custom planet file.
