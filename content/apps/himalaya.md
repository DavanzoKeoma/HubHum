### What it does in plain English
Himalaya is a powerful command-line tool that lets you read, send, and organize your emails without ever leaving your terminal. It connects smoothly with major email providers and local mail folders, giving you instant access to your inbox. Every command can output clean text for daily reading or structured data for scripts and automation tools.

### Who it's for
* Developers and power users who live inside terminal windows and prefer keyboard-driven workflows.
* System administrators who need a lightweight tool to check or send mail notifications from scripts.
* Privacy-conscious users looking for an efficient email manager that integrates with local password managers.

### Key features
* **Unified experience:** Access different mailboxes and accounts using the exact same commands across all supported backends.
* **Flexible output:** View your emails as simple plain text or structured data for easy automation.
* **Local offline sync:** Keep local copies of your messages using standard mail storage formats.
* **Powerful search:** Run quick queries to find specific messages instantly regardless of your email provider.
* **Secure credentials:** Load your account passwords securely from your system's existing password manager.

### How to install (Download)
To install the pre-built binary on Linux or macOS as the root user, run:
```sh
curl -sSL https://raw.githubusercontent.com/pimalaya/himalaya/master/install.sh | sudo sh
```
To install it in your local user directory without root privileges:
```sh
curl -sSL https://raw.githubusercontent.com/pimalaya/himalaya/master/install.sh | PREFIX=~/.local sh
```
You can also install the application from source using [Rust](https://www.rust-lang.org/tools/install) by cloning the official project page and running `cargo build --release --locked`.

### Pros and Cons
* **Pros:** Fast keyboard-driven workflow, completely free and open source, low resource usage.
* **Cons:** Requires familiarity with terminal commands, initial setup involves editing configuration text files.
