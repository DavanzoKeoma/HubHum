### What it does in plain English
Decoy provides a professional dashboard for managing the information displayed on your website. It connects directly to your existing data structures, allowing you to update text, images, and other content through a simple, visual interface. Because it integrates directly into your project, you can manage your site's content without learning complex new systems or languages.

### Who it's for
*   **Web Developers:** Professionals looking to provide their clients with a polished, user-friendly way to edit website content.
*   **Site Administrators:** People who need to update website text and media regularly without needing to touch the underlying code.

### Key features
*   **Intuitive Interface:** A clean, professional design that requires no training to start managing content.
*   **Media Support:** Built-in tools for cropping images, setting focal points, and managing video files.
*   **Flexible Editing:** Includes a visual text editor for easy formatting and drag-and-drop ordering for lists.
*   **Permission Control:** Granular settings to manage who can access or change specific parts of the website.
*   **Customizable Forms:** Easily create and manage forms for content entry using standard web design patterns.

### How to install (Download)
Decoy is designed to be added to your project as a package. You can find the setup instructions and the quick start guide on the official documentation site:
[View Decoy Quick Start Guide](http://docs.decoy.bukwild.com/quick-start)

### Pros and Cons
*   **Pros:** Highly flexible, integrates seamlessly with existing project data, and provides a professional admin interface out of the box.
*   **Cons:** Requires technical knowledge to set up initially, as it is a tool for developers to implement rather than a standalone program for non-technical users.
