### What it does in plain English
Yaaw provides a straightforward browser-based dashboard to monitor and control your active file downloads. It acts as a visual remote control panel that talks directly to your download engine in the background. Since it runs entirely using standard web files, you can open it instantly in any modern browser without installing heavy software.

### Who it's for
* Power users who manage remote downloads on headless servers or home media stations.
* Anyone looking for a lightweight, clutter-free interface to track long-running file transfers.
* Users who prefer a browser-based tool to check download speeds and queue progress.

### Key features
* Pure web-based interface requiring only a modern browser to view and control tasks.
* Real-time progress tracking for download speeds, completed sizes, and active files.
* Direct communication with background download engines using secure connection settings.
* Bookmark support to instantly save and reopen your custom connection paths.
* Zero heavy backend setup needed, operating entirely on standard web technologies.

### How to install (Download)
You can test and use the live interface directly via the [Official Demo Website](https://binux.github.io/yaaw/demo/). To run it locally, grab the source files from the [Official Source / Credits](https://github.com/binux/yaaw) and open the page in your browser.

### Pros and Cons
* **Pros:** Extremely lightweight, no installation required, runs in any browser.
* **Cons:** Requires a background download engine already running and configured properly.
