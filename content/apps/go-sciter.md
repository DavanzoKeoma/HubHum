### What it does in plain English
It lets you turn HTML and CSS designs into native desktop windows.  
You can add interactive behavior using simple scripts.  
The whole engine is tiny, so your program stays fast and lightweight.  

### Who it's for
* Go developers who want to build desktop tools with web‑design skills.  
* Freelancers creating custom internal applications.  
* Small teams needing a lightweight UI without bulky browsers.  

### Key features
- Loads HTML files or strings directly.  
- Lets you change the interface while the program runs.  
- Handles user clicks and other events.  
- Supports custom resources like images or data files.  
- Provides a small library under 5 MB.  

### How to install (Download)
- [Download Sciter SDK (runtime libraries)](http://sciter.com/download/) – contains the tiny engine needed to run programs built with go‑sciter.  

### Pros and Cons
* **Pros:** free to use, tiny size, works smoothly with Go, supports many UI features.  
* **Cons:** you must install the Sciter runtime library separately, requires Go 1.10 or newer, some advanced Sciter features are not available.
