### What it does in plain English
This tool replaces the default symbols on your computer screen with a unified, warm-colored design. It ensures that every app, folder, and file type looks like it belongs to the same family. You can choose between a dark or light version to match your personal taste.

### Who it's for
*   **Linux enthusiasts** who want to personalize their desktop environment with a cohesive aesthetic.
*   **Design-conscious users** who prefer warm, earthy tones over standard cold blue or grey system defaults.
*   **KDE Plasma users** looking for symbolic icons that automatically adapt to their chosen color scheme.

### Key features
*   **Massive Library:** Includes over 8,000 app icons, 3,500 place icons, and 2,400 file type icons.
*   **Dual Themes:** Provides both "Gruvbox Dark" and "Gruvbox Light" variants for different desktop backgrounds.
*   **Customizable Folders:** Allows you to change the color of your folders using a simple script or system settings.
*   **Human-Crafted:** All icons are designed by humans, ensuring a consistent and thoughtful artistic style.
*   **Easy Updates:** Can be installed via package managers on major Linux distributions or manually downloaded.

### How to install (Download)
*   **For Arch Linux users:** Install via the AUR using your preferred helper (e.g., `yay -S gruvbox-plus-icon-theme`).
*   **For openSUSE users:** Add the official project page and install via `zypper install gruvbox-plus-icon-theme`.
*   **Manual Download:** [Download the folder color tool](https://github.com/SylEleuth/gruvbox-plus-icon-pack/releases/download/v6.7.0/folders-color-chooser) or visit the [Releases Page](https://github.com/SylEleuth/gruvbox-plus-icon-pack/releases) to get the full icon archive.
*   **OpenDesktop Store:** Search for "Gruvbox Plus" in your system's icon manager (e.g., KDE System Settings).

### Pros and Cons
*   **Pros:** Free and open-source, extensive icon coverage, consistent color palette, and easy to customize folder colors.
*   **Cons:** Requires manual installation steps on some systems, and the warm color scheme may not suit everyone's preference for neutral tones.
