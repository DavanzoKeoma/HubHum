### What it does in plain English
PhoneBox transforms your old or spare Android phone into a handy desk panel and touch control deck for Windows, Linux, or macOS. It lets you monitor system performance, track coding assistant quotas, manage media playback, and trigger automation shortcuts right from a secondary screen. You can connect your phone using either a standard data cable or your local wireless network without needing any cloud accounts.

### Who it's for
* Software developers and power users who want a dedicated screen to monitor processor loads and coding session quotas.
* Enthusiasts looking to repurpose an old Android device lying in a drawer into a functional desktop accessory.
* Anyone wanting a convenient touch-sensitive macro deck to control media playback, system audio, and smart home tools.

### Key features
* Over 120 widgets and dozens of built-in templates for system stats, AI tools, and media control.
* Visual browser-based layout editor to easily customize pages, widgets, and live previews.
* Secure local communication over USB cable or paired Wi-Fi without cloud service dependencies.
* Support for multiple phone connections and independent layout profiles for different workflows.
* Lightweight design running smoothly on older Android hardware starting from version 5.0.
