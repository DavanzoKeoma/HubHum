### What it does in plain English
Slingcode lets you write small web programs and run them right in your browser.  
You can keep all your work in a single HTML file that works even when you’re offline.  
You can also share your creations directly with friends without needing any extra setup.

### Who it's for
Kids learning to code at home, hobbyists who want a quick way to test ideas, and anyone who needs a portable toolbox for small web utilities.

### Key features
- Write, run, and test code in the same window.  
- Keep everything in one .html file you can copy to a USB stick or phone.  
- No internet or extra programs required to use it.  
- Share your work instantly with a link or by sending the file.  
- Add the page to your phone’s home screen for easy offline access.

### How to install (Download)
- [Download (slingcode.html)](https://github.com/chr15m/slingcode/releases/download/0.2.2/slingcode.html) – right‑click and “save link as” to store the file on your computer, USB drive, or phone.

### Pros and Cons
* **Pros:** free forever, works offline, single portable file, no extra software needed.  
* **Cons:** limited to what runs in a browser, advanced options may need a bit of learning, no built‑in cloud hosting.
