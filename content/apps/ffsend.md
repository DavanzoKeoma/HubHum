### What it does in plain English
This tool allows you to send and receive files securely and privately using a simple command line interface. Every file is completely encrypted on your device before it leaves, ensuring nobody else can read it. You can set download limits and expiration times so your shared items automatically disappear after use.

### Who it's for
* Software developers and system administrators who love working in the terminal.
* Privacy-conscious users who want complete control over how their files are shared online.
* Anyone looking for a fast, hassle-free way to send temporary documents to friends or colleagues.

### Key features
* Fully featured command line client for sending and receiving files.
* Complete client-side encryption so your private data stays hidden from remote servers.
* Custom download limits and expiration timers to control file availability.
* Built-in tools for generating QR codes and shortening share links.
* Support for uploading full folders and directories with automatic archiving.
