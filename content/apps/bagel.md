### What it does in plain English
Bagel helps mobile software creators view all web requests sent and received by their phone applications in real time. Because it works natively over your local Wi-Fi network, you never have to mess around with complicated proxy setups or security certificates. It automatically separates incoming information by individual devices and simulators so you can quickly spot and fix broken web connections.

### Who it's for
* Mobile app developers building software for iPhones and iPads who need to check web requests.
* Quality assurance testers looking to verify that apps send the correct data to servers.

### Key features
* Direct local network communication without any proxy configuration hassles.
* Real-time inspection of web traffic separated cleanly by device and simulator.
* Simple integration code that plugs into your project with a single command.
* Customizable project and device names to keep multiple testing sessions organized.

### How to install (Download)
To use this tool, download the source project and set up the desktop companion application from the official release page. You can integrate the mobile helper library into your software project using popular dependency managers like CocoaPods, Carthage, or Accio.
