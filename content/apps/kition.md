### What it does in plain English
Kition is a unified desktop workspace where every file opens inside a dedicated professional editor called a kit. You can work manually on documents, images, spreadsheets, and videos, or invite an artificial intelligence agent to make edits directly using the same tools. Every modification is clearly previewed and checked so you retain full control over your project drafts before saving.

### Who it's for
* Freelancers and creators who need a single workspace for writing, video editing, and vector design.
* Professionals managing complex projects involving tables, slides, documents, and technical drawings.
* Users looking for an open workspace where artificial intelligence can safely assist with file updates.

### Key features
* Sixteen built-in professional editors handling notes, spreadsheets, vectors, photos, videos, CAD, and 3D scenes.
* AI integration that safely reads, modifies, and previews files through specialized tool commands.
* Draft review mode ensuring updates require your approval before overwriting any important work.
* Workspace scripts and automated assistants that extract data or generate content seamlessly.
* Open architecture designed for extensibility and privacy on your local machine.

### How to install (Download)
Desktop builds for supported operating systems are published on [GitHub Releases](https://github.com/KitionAI/kition/releases). You can also learn more about the project philosophy and development roadmap directly on the [Official Website](https://kition.ai).

### Pros and Cons
* **Pros:** Open-source architecture, huge variety of built-in file editors, safe agent review workflow.
* **Cons:** Early beta software requiring manual backups, advanced scripting options take time to master.
