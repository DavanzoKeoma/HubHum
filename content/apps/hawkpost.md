### What it does in plain English
Hawkpost solves the common problem of receiving sensitive information from people who do not understand complex encryption tools. It lets you generate a customized web link connected to your security key that anyone can use to submit confidential data. The tool automatically scrambles the message right inside the web browser before it is forwarded safely to your email inbox.

### Who it's for
* Freelancers and development agencies needing secure password handovers from clients
* Privacy advocates who want to simplify encrypted communication for everyday contacts
* IT administrators collecting sensitive configuration details safely

### Key features
* Generates unique web links for receiving encrypted messages
* Automatically scrambles data directly on the client side using public keys
* Forwards final encrypted submissions straight to your email address
* Can be easily hosted on your own server or cloud setup via container tools

### How to install (Download)
To use the official live service or host your own instance, visit the [Hawkpost Website](https://hawkpost.co). Complete setup instructions and server configuration files are available on the [Official Source / Credits](https://github.com/whitesmith/hawkpost).

### Pros and Cons
* **Pros:** Simplifies secure communication, client-side scrambling protects privacy, free and open-source software
* **Cons:** Currently maintained only for security patches, requires basic technical knowledge to set up your own server
