### What it does in plain English
Sherloq is an open-source laboratory workspace designed for anyone curious about digital image forensics. It gathers various advanced testing techniques into one interactive interface to help you spot hidden clues, compression inconsistencies, and digital tampering. Instead of giving a simple yes-or-no answer on whether a photo is real, it acts as your personal exploration toolkit for image science.

### Who it's for
* Investigative journalists and hobbyists researching the authenticity of online visual media.
* Students and educators learning about digital signal processing and image forensics.
* Photography enthusiasts interested in understanding how compression and editing leave visible mathematical traces.

### Key features
* Interactive visual workspace built with modern window controls and smooth zooming.
* Deep metadata inspection to reveal file headers, hidden thumbnails, and camera details.
* Advanced color, lighting, and noise analysis tools to uncover spliced or cloned areas.
* JPEG compression testing to highlight inconsistencies, multiple saves, and editing ghosts.
* Export capabilities for both visual inspection maps and textual analysis results.

### How to install (Download)
Because this project is distributed as source code, you can visit the [Official Releases Page](https://github.com/GuidoBartoli/sherloq/releases) to check for updates, or clone the project official project page directly from the [Official Source official project page](https://github.com/GuidoBartoli/sherloq). Setup instructions require Python 3.11 and a package helper like `uv` to configure the environment and install dependencies cleanly.

### Pros and Cons
* **Pros:** Free and open-source, provides dozens of sophisticated forensic tests in one place, highly educational.
* **Cons:** Requires using a command line to set up initial Python dependencies, analysis results require human interpretation rather than automated verdicts.
