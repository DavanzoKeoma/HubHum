### What it does in plain English
Percho is a friendly desktop application that wraps a powerful coding assistant engine into a clean, easy-to-use window. Instead of using a traditional command-line terminal, you get a full visual workspace with sidebars, message history, and formatting. It helps you manage coding tasks, review file changes visually, and approve or block automated actions with a simple click.

### Who it's for
* Software developers looking for a clean, visual interface to run local coding assistants
* Programmers who want multi-session chat history and instant previews of edited files
* Users who prefer graphical approval gates over terminal prompts when managing automated tools

### Key features
* **Visual Workspace:** Clean sidebar navigation to manage multiple projects and chat sessions easily
* **Tool Approvals:** Interactive permission windows that let you review and approve every automated action safely
* **Subagent Support:** Run parallel background tasks and inspect their progress in dedicated read-only cards
* **Custom Appearance:** Switch between light and dark themes, or add custom background images with adjustable dimming
* **Flexible Providers:** Connect your preferred AI subscription or enter custom API keys to power your sessions
