### What it does in plain English
MediaCreationTool.bat is a helpful script that automates the process of downloading and preparing Windows installation files. It allows you to create your own USB drives or disc images with specific settings, such as skipping certain hardware checks or pre-selecting your preferred version. It also includes an automated upgrade feature that helps you keep your files and apps even when moving between different editions of Windows.

### Who it's for
* Home users who want to create a clean installation drive for their computer.
* IT enthusiasts or professionals who need to manage multiple Windows versions and editions across different systems.

### Key features
* **Automated Media Creation:** Automatically downloads and prepares Windows installation files for USB or disc images.
* **Customizable Presets:** Offers different modes to handle upgrades, ISO creation, or USB preparation based on your specific needs.
* **Hardware Check Bypasses:** Includes options to bypass certain system requirements during the installation process.
* **Edition Flexibility:** Allows you to switch between different Windows editions while keeping your personal files and applications intact.
* **Simplified cloud setup:** Generates scripts that make it easy to run unattended upgrades or apply specific configurations to your installation media.
