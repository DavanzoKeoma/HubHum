### What it does in plain English
ANUS is a command-line helper that reads your code, modifies files, and runs commands directly inside your terminal window. Instead of forcing you into expensive monthly subscriptions, it automatically routes your coding tasks to the smartest available free artificial intelligence models. If one service gets busy or reaches its daily limit, the system smoothly switches to the next available free option without interrupting your workflow.

### Who it's for
* Budget-conscious developers and students looking for AI-powered coding assistance without paying recurring monthly fees.
* Command-line power users who want a lightweight assistant that operates directly inside their existing terminal workflow.
* Hobbyists and open-source contributors wanting automated help with debugging, testing, and file editing.

### Key features
* Automatically rotates through top-tier free AI models to ensure uninterrupted assistance.
* Reads existing project files, writes code edits, and executes terminal commands on your behalf.
* Intelligently falls back to alternate services when a provider hits rate limits or experiences downtime.
* Operates locally using your own free keys from providers like OpenRouter, Google Gemini, or Mistral.
* Keeps sensitive workflows secure by avoiding paid service triggers unless explicitly configured.

### How to install (Download)
You can set up the assistant using Node.js or the terminal installation script provided by the project.

Make sure you have Node.js 22.19 or newer installed, then run either command in your terminal:
```sh
npm install -g @anus-dev/anus
anus
```
Or use the automated shell script:
```sh
curl -fsSL https://anus.dev/install | sh
```
For more information, visit the [Official Website](https://anus.dev).

### Pros and Cons
* **Pros:** Completely free to use with zero subscription fees; automatically switches between multiple free intelligence providers; runs directly inside your terminal environment.
* **Cons:** Requires setting up free external API keys before first use; free tiers may occasionally hit request limits during heavy use.
