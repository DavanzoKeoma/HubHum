### What it does in plain English
Komorebi is an automatic window manager that integrates seamlessly into Windows 10 and above. It arranges open application windows into clean, grid-like layouts without cluttering your desktop. You can easily control workspaces and switch between applications using custom keyboard shortcuts.

### Who it's for
* Power users looking to maximize screen workspace efficiency on Windows.
* Developers and writers who prefer keyboard-driven navigation over manual window dragging.
* Anyone who wants a customized window layout without heavy desktop modifications.

### Key features
* Automatic window tiling that eliminates manual window resizing and dragging.
* Support for multiple virtual workspaces and display monitors.
* Customizable keyboard shortcuts via companion tools like command line options.
* Low resource usage that builds directly on top of built-in system features.
* Event subscriptions for developers to build custom status bars and widgets.
