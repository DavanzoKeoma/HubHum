### What it does in plain English
HyprMod lets you change Hyprland settings without editing text files.  
It shows changes instantly so you can see the effect right away.  
You can undo changes, save profiles, and share them with others.

### Who it's for
- Desktop users who run Hyprland and want a quick way to tweak visuals and behavior.  
- Gamers who want to fine‑tune keybinds and monitor layouts.  
- Developers who need to experiment with configuration options safely.

### Key features
- Live preview of every setting.  
- Undo changes with a single key.  
- Save and load named profiles.  
- Edit Lua config directly.  
- Search all options quickly.

### How to install (Download)
- **Linux (install script)** – [Download for Linux (install script)](https://raw.githubusercontent.com/BlueManCZ/hyprmod/main/install.sh)


### Pros and Cons
* **Pros:** free forever, no subscription, live preview, undo support.  
* **Cons:** requires Python 3.12+, GTK4, libadwaita; installation uses a terminal; not packaged for all distributions.
