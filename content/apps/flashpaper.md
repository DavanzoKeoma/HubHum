### What it does in plain English
FlashPaper creates a temporary web page where you can paste a secret. The page encrypts the secret and gives you a unique link. When the link is opened, the secret is shown once and then automatically removed.

### Who it's for
- People who need to share a password with a colleague for a single login.  
- Anyone who wants to send a confidential note without leaving a trace.  
- Small teams that need quick, disposable data exchange.

### Key features
- One‑time link that self‑destructs after viewing.  
- End‑to‑end encryption performed on the server.  
- No long‑term database; old secrets are automatically cleared.  
- Works in any web browser, no special software needed.  
- Optional Docker or simple PHP setup for self‑hosting.

### Pros and Cons
* **Pros:** free forever, self‑hosted, no subscription, zero‑knowledge encryption.  
* **Cons:** requires you to run a web server or Docker, initial setup may need some technical steps.
