### What it does in plain English
Luban is a lightweight toolkit designed for mobile developers to automatically shrink oversized smartphone photos before uploading or saving them. It uses a smart algorithm inspired by popular social media apps to determine the ideal balance between file size and picture clarity. Whether you are dealing with panoramic screenshots or massive camera shots, it prevents blurry results and stops apps from running out of memory.

### Who it's for
* Android application developers looking for a reliable and proven way to compress user photos.
* Mobile software engineers wanting to reduce server upload times and save device bandwidth.
* Developers who need seamless support for both modern Kotlin coroutines and traditional Java codebases.

### Key features
* **Smart resolution management:** Automatically adjusts image dimensions using preset caps to keep files light while looking crisp on modern screens.
* **Adaptive bitrate control:** Applies different compression strengths based on original file characteristics to preserve fine details.
* **Built-in safety checks:** Automatically skips compression if the output file ends up larger than the original input to prevent quality loss.
* **Modern asynchronous support:** Built natively with Kotlin Coroutines for smooth background processing without freezing app interfaces.
* **Flexible integration:** Works smoothly with files, web addresses, and streams through simple modern builders or classic callbacks.
