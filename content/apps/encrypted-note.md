### What it does in plain English
This application creates a secure, offline digital vault where you can store sensitive items like recovery phrases, private keys, passwords, and API keys. It keeps all of your secret information completely on your own machine without connecting to the internet or cloud servers. You can easily retrieve your details whenever you need them while keeping prying eyes completely locked out.

### Who it's for
* Cryptocurrency holders who need a safe place to store wallet recovery seed phrases and private keys offline.
* Software developers and power users who want a secure, local official project page for system login credentials and API access tokens.
* Privacy-focused individuals looking for an independent credential vault free from online account sync and telemetry tracking.

### Key features
* **Completely offline:** Operates entirely locally with zero network code, cloud accounts, telemetry, or hidden auto-updaters.
* **Double encryption:** Encrypts sensitive items like seed phrases a second time under an independent layer that requires your master password to reveal.
* **Screen share protection:** Automatically hides window contents and attempts to block capture tools when screen recording or video meetings are detected.
* **Emergency recovery:** Includes a handwritten recovery key and an emergency reader tool so you can access your vault even if the main application is unavailable.
* **Portable backups:** Easily create encrypted backup copies to store on external drives or move securely to another computer.
