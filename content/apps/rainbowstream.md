### What it does in plain English
Rainbow Stream lets you read your timeline, post updates, search, and interact with social media posts directly inside your text terminal. It features built-in color themes, image rendering inside supported windows, and interactive command navigation with history tracking. You can easily keep up with online conversations without ever leaving your preferred command environment.

### Who it's for
* Command-line power users and developers who prefer working entirely within a terminal window.
* Minimalists who want a distraction-free social media experience without graphical distractions.
* Python enthusiasts looking for a customizable, lightweight tool to manage their online streams.

### Key features
* **Terminal Interface:** Browse and interact with your social stream using standard text commands and keyboard shortcuts.
* **Color Themes:** Switch between various built-in color palettes or customize your own look and feel.
* **Image Support:** View inline images directly in your terminal using supported color configurations or advanced viewing modes.
* **Interactive Navigation:** Enjoy auto-completion, command history, and quick search capabilities right from your input prompt.
* **Proxy Support:** Route your connection securely through HTTP or SOCKS proxies when needed.

### How to install (Download)
Make sure you have Python and pip installed on your system, then open your terminal and run:

```bash
sudo pip3 install rainbowstream
```

Alternatively, you can set up a virtual environment for a clean installation:

```bash
virtualenv -p /usr/bin/python3 venv
source venv/bin/activate
pip install rainbowstream
```

### Pros and Cons
* **Pros:** Lightweight, highly customizable color themes, runs entirely in the terminal, completely free and open-source.
* **Cons:** Requires familiarity with terminal commands, initial setup requires granting authorization credentials.
