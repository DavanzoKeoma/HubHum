### What it does in plain English
Hacklock is a lightweight script designed for mobile security testing and educational demonstrations on Android devices. It provides an interactive interface within a terminal environment to explore how screen lock patterns can be analyzed or simulated. Users can generate test scenarios and review lock pattern concepts easily for research and study purposes.

### Who it's for
* Security students learning about mobile device locks and vulnerability analysis
* Developers interested in understanding Android device security layers
* Hobbyists exploring command-line utilities within mobile terminal environments

### Key features
* Interactive terminal menu designed for ease of use
* Generates security test scenarios for lock patterns
* Compatible with both standard and rooted mobile environments
* Lightweight setup process with clear step-by-step instructions
