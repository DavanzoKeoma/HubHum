### What it does in plain English
Defuddle scans any web page and strips away distracting elements like advertisements, navigation menus, and footers. It isolates the primary text and images, presenting them in a simplified, distraction-free layout. You can even convert this cleaned content into a standard text format perfect for note-taking apps.

### Who it's for
*   **Researchers and Students:** People who need to save clean versions of articles for study or reference.
*   **Note-takers:** Users who want to quickly clip web content into personal knowledge management tools without formatting errors.

### Key features
*   **Smart Cleanup:** Automatically detects and removes non-essential page elements while keeping the core article intact.
*   **Markdown Support:** Converts web content into clean text files, making it easy to save and edit later.
*   **Metadata Extraction:** Gathers useful details like the author, publication date, and original source automatically.
*   **Standardized Formatting:** Ensures footnotes, math equations, and code blocks look consistent regardless of the original website's design.

### How to install (Download)
Defuddle is a tool for developers and power users. You can install it using the Node.js package manager by running the following command in your terminal:

`npm install -g defuddle`

If you prefer not to install it permanently, you can run it instantly using `npx`:

`npx defuddle parse [URL_HERE] --markdown`

### Pros and Cons
*   **Pros:** Completely free and open-source, highly customizable, and produces clean, portable text output.
*   **Cons:** Requires basic familiarity with terminal commands to use effectively, and it is still a work in progress.
