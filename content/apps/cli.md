### What it does in plain English
GitHub CLI brings all your code management tasks directly into your command line window. Instead of jumping back and forth between web browser tabs, you can open project task lists, review changes, and manage project workflows right where you write code. ### Who it's for
* Software developers who spend their entire working day inside a terminal window.
* Open-source contributors looking to review code changes and track project tasks faster.
* Engineers who want to automate their daily project routines without touching a web browser.

* Review, create, and manage code merge requests directly from your command prompt window.
