### What it does in plain English
Hive is an intelligent workspace where you give a main leader helper a big goal, and it breaks down the work into smaller tasks for a team of parallel workers. Every worker handles its specific assignment independently, stores results in a shared tracking sheet, and reports back to the leader for quality checks. You can easily oversee everything from a clean local dashboard, review final results with charts and notes, and let tasks run safely on a schedule.

### Who it's for
* **Growth and Marketing Leads:** Perfect for researching competitor product launches, gathering data across multiple channels, and compiling structured reports without manual data entry.
* **Operations and Support Managers:** Ideal for running recurring repetitive audits, tracking records, and automating multi-step daily workflows reliably.
* **Solo Creators and Small Teams:** Great for scaling up productivity by delegating routine administrative and research tasks to a coordinated digital team.

### Key features
* **Lead and Worker Structure:** Assign a primary leader agent that delegates tasks to parallel workers based on real-time needs.
* **Shared Progress Tracker:** Keep all completed outputs neatly stored in a local spreadsheet format so you can easily review, query, or audit results.
* **Flexible Model Compatibility:** Connect easily with popular online intelligence providers or run models completely offline on your own machine.
* **Safe Budget Limits:** Protect your resources with strict limits on task turns and operational steps for every single worker.
* **Browser and Tool Integration:** Allow helpers to use your standard web browser, edit files, execute local commands, and connect with external services.

### How to install (Download)
To set up the workspace on your computer, ensure you have Python and Node.js installed, then run the quickstart script from your terminal:

For macOS and Linux:
```bash
git clone https://github.com/aden-hive/hive.git
cd hive
./quickstart.sh
```

For Windows (PowerShell 5.1+):
```powershell
git clone https://github.com/aden-hive/hive.git
cd hive
.\quickstart.ps1
```

Once the quickstart finishes setting up your encrypted workspace, open your dashboard at `http://127.0.0.1:8787` or run `hive open` from your terminal folder anytime.

### Pros and Cons
* **Pros:** Highly flexible multi-agent coordination, complete local data privacy under your control, and support for both online and offline models.
* **Cons:** Requires a modern computer setup with Python and Node.js, and takes a few moments to understand how helper delegation works.
