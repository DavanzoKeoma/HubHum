### What it does in plain English
It finds pictures you search for on Google and copies them to a folder on your computer.  
You can ask it to grab hundreds of pictures at once.  
It does the work automatically so you don’t have to click each image.

### Who it's for
Anyone who needs lots of reference photos for a project, teachers gathering visual material for lessons, and hobbyists building personal image collections.

### Key features
- Save hundreds of pictures with one command.  
- Works with any search term you type.  
- Creates a folder that holds all the downloaded files.  
- Handles the web browser automatically, so you don’t have to.  
- Shows progress while it runs.

### How to install (Download)
- **Read the setup guide:** [Installation guide](https://hardikvasa.github.io/google-images-download/installation/)  
- **Get Chrome (required browser):** [Download Chrome for Windows/macOS/Linux](https://www.google.com/chrome/)  
- **Linux users:** install Chromium with `apt-get install chromium-browser` or `apt-get install google-chrome-stable`.  
- **macOS users:** install Chrome via Homebrew with `brew install --cask google-chrome`.

### Pros and Cons
* **Pros:** free forever, works on all major operating systems, no subscription needed.  
* **Cons:** requires Chrome/Chromium to be installed, must respect image copyright rules.
