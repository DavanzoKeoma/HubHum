### What it does in plain English
Tart lets you run a copy of macOS or Linux on your Apple Silicon Mac.  
It lets you try out programs or run scripts in a safe, separate environment.  
You don’t need to buy another computer to test different operating systems.

### Who it's for
* Software developers who need to check how their apps work on macOS or Linux.  
* Quality‑assurance teams that want a quick way to run tests without extra hardware.  
* Hobbyists who like to experiment with different operating systems on the same machine.

### Key features
* Create a macOS or Linux copy in minutes.  
* Run the copy side‑by‑side with your regular work.  
* Save the copy and share it with teammates easily.  
* Works smoothly with common automation tools.  
* Uses Apple’s built‑in technology for fast, near‑native speed.
