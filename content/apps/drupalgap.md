### What it does in plain English
DrupalGap is a handy development kit designed to connect custom applications directly to your Drupal website. It lets developers write code once using familiar website concepts and publish it seamlessly across different app stores, devices, and web browsers. Built entirely with standard JavaScript, it gives you complete flexibility to shape your user interface and connect data smoothly.

### Who it's for
* Web developers building companion mobile or browser applications for existing Drupal websites.
* Freelancers and agencies looking for a reliable shortcut to deliver multi-platform client apps.
* Tech hobbyists experimenting with content management system integrations and custom user interfaces.

### Key features
* Single codebase creation for web browsers, mobile devices, and popular app stores.
* Built-in tools to handle user authentication, accounts, and permission roles.
* Seamless loading and updating of website data, fields, and custom content lists.
* Compatible with standard JavaScript and CSS design software foundation of your choice.
* Uses familiar concepts like blocks, forms, and themes to speed up development.

### How to install (Download)
You can explore the live software demonstration, read documentation, and get started through the [DrupalGap Official Website](https://www.drupalgap.org).

### Pros and Cons
* **Pros:** Free and open source, uses standard JavaScript without restrictive proprietary layers, writes code once for multiple platforms.
* **Cons:** Requires existing knowledge of content management administration, advanced custom designs may need separate style libraries.
