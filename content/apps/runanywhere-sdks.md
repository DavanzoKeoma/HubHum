### What it does in plain English
Runanywhere SDKs provide a single, unified toolkit for running artificial intelligence models directly on everyday hardware without needing an internet connection. It automatically routes your requests to the best available processor on your device, ensuring maximum speed for tasks like chatting, listening, or generating images. Developers and hobbyists can easily integrate text generation, voice recognition, and image creation into mobile apps, desktop programs, and web pages using one consistent set of commands.

### Who it's for
* **Mobile and Desktop App Developers:** Looking to add lightning-fast, offline artificial intelligence features to iOS, Android, macOS, Windows, or Linux applications.
* **Privacy-Focused Creators:** Wanting to process personal notes, voice recordings, and images locally on their own devices without sending data to third-party servers.
* **Hobbyists and Experimenters:** Eager to test smart text models, speech assistants, and image generators on regular phones, laptops, and web browsers.

### Key features
* **Complete Offline Functionality:** Operates entirely on your local hardware without requiring active internet connectivity or external server calls.
* **Unified Developer Toolkit:** Connects eight different platforms and programming environments through one simple, consistent set of commands.
* **Smart Hardware Acceleration:** Automatically detects your device's chip capabilities to run tasks as quickly as possible.
* **Multi-Modal Capabilities:** Handles text chat, voice transcription, text-to-speech, document search, and image generation within a single system.
* **Cross-Platform Support:** Works seamlessly across mobile phones, desktop computers, web browsers, and server environments.
