### What it does in plain English
mkcert makes it easy to create trusted certificates for local development.  
It installs a local certificate authority automatically, so browsers accept your sites.  
You can generate certificates for any name you need, like `localhost` or `example.test`.

### Who it's for
- Web developers who run local servers and need HTTPS.  
- Local server administrators who want to avoid browser warnings.  
- Anyone who wants a quick, secure way to test sites locally.

### Key features
- Zero‑configuration setup.  
- Installs a local trusted root automatically.  
- Generates certificates for any host names you specify.  
- Works on Windows, macOS, Linux, Firefox, Chrome, and Java.  
- Simple command‑line usage.
