### What it does in plain English
Canta helps you clean up your mobile device by removing stubborn factory-installed apps and unwanted software that usually cannot be deleted. It works alongside a companion system tool to safely communicate with your phone's inner layers without needing risky device modifications. You can even manage your phone storage directly from a web browser using a cable connection if you prefer not to install another app.

### Who it's for
* Everyday smartphone owners wanting to reclaim storage space and improve battery life.
* Privacy-conscious users looking to eliminate pre-installed carrier apps and unwanted background trackers.
* People who want a clutter-free interface without performing complex device modifications.

### Key features
* Removes pre-installed system applications and user software without requiring root access.
* Integrates with safety guides to warn you before deleting essential system files.
* Works directly through a compatible web browser connection or via a dedicated mobile interface.
* Detects previously uninstalled items even if they reappear after future system updates.
* Compatible with modern Android versions running the necessary companion bridge.

### How to install (Download)
To get started, make sure you have the companion helper tool set up on your device first, then grab the installer below:
* [Download for Android (.apk)](https://github.com/samolego/Canta/releases/download/v4.1.0/androidApp-release.apk)
* Alternatively, try it directly from the [Canta Web App](https://samolego.github.io/Canta/app/) using a data cable and a Chromium-based browser.

### Pros and Cons
* **Pros:** Free forever, requires no advanced root privileges, and helps free up valuable storage space.
* **Cons:** Removing critical operating system components carelessly can cause device issues requiring a factory reset.
