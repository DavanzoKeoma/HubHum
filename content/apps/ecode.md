### What it does in plain English
ecode is a nimble code editor that opens instantly and runs smoothly on modern hardware. It helps you write, organize, and format code across dozens of programming languages without slowing down your computer. With built-in tools like file search, syntax color coding, and a terminal, it gives you a clean workspace for all your programming projects.

### Who it's for
* Programmers and web developers looking for a fast, uncluttered editor that opens large files instantly.
* Students learning to code who want a straightforward environment supporting multiple programming languages.
* Power users who appreciate a portable, customizable workspace with multi-cursor support and terminal integration.

### Key features
* Blazing fast startup time and low memory consumption powered by modern hardware acceleration.
* Syntax highlighting and smart code completion for over 100 programming languages.
* Multi-cursor editing and fast global search-and-replace across entire folders.
* Integrated terminal, Git tracking, and custom color themes.
* Session snapshots and periodic automatic backups so you never lose your work.
