### What it does in plain English
Calcure is a modern calendar and task manager that runs directly inside your computer's command terminal. It helps you keep track of daily events, organize to-do lists with subtasks and deadlines, and even check weather updates without leaving your keyboard. Because it uses simple text files stored locally, your schedule syncs easily with private cloud storage folders.

### Who it's for
* Keyboard-driven power users who spend their day inside terminal windows and want a lightning-fast schedule viewer.
* Minimalists looking for a distraction-free organizer that stays out of their way and uses very little computer memory.
* Linux, Mac, and Windows enthusiasts who enjoy customizing their workflows and appearance with configuration files.

### Key features
* Lightning-fast navigation using minimal keystrokes and optional keyboard shortcuts.
* Built-in to-do list supporting subtasks, deadlines, and countdown timers.
* Automatically displays contact birthdays and weather forecasts.
* Private event masking to hide sensitive schedule entries from casual glances.
* Fully customizable interface allowing color schemes and custom icons.

### How to install (Download)
* **Linux and Mac (Python users):** Open your terminal and run `pipx install calcure` (requires Python and pipx).
* **Arch Linux:** Install via the Arch User official project page using `yay -S calcure`.
* **Windows:** Open Windows Terminal, ensure Python is installed from the Microsoft Store, and run `pip install windows-curses calcure`, then start it with `python -m calcure`.
* **Official Documentation & Setup Guide:** [Visit Calcure Documentation](https://anufrievroman.gitbook.io/calcure)

### Pros and Cons
* **Pros:** Extremely fast, free and open-source, highly customizable, works offline with simple text files.
* **Cons:** Requires a terminal environment, command-line familiarity needed for initial setup.
