### What it does in plain English
Katana is a fast, flexible tool that walks through websites like a visitor to map out all available pages, hidden links, and forms. It can operate as a lightweight text crawler or launch an invisible browser to interact with modern, dynamic web applications. The software helps security professionals, developers, and researchers understand website structures and find every corner of a web project.

### Who it's for
* Web developers who want to verify site link structures and ensure no orphaned pages exist.
* Security auditors and penetration testers mapping out target applications.
* Researchers gathering page links and data for offline analysis.

### Key features
* Dual crawling engine supporting both fast standard HTTP requests and deep browser-rendered page analysis.
* Automated form filling and interactive clicking to explore hidden user flows.
* Smart content filtering to ignore duplicate pages or repetitive layouts.
* Knowledge base classification that categorizes endpoints and detects sensitive information.
* Flexible output formats including clean text lists and structured records.

### How to install (Download)
You can verify checksums and download release files directly from the [Official Release Checksums File](https://github.com/projectdiscovery/katana/releases/download/v1.8.0/katana-1.8.0-checksums.txt). For automated installation on systems with Go installed, run:
```console
go install github.com/projectdiscovery/katana/cmd/katana@latest
```

### Pros and Cons
* **Pros:** Extremely fast operation, handles complex JavaScript apps via headless mode, highly customizable rules.
* **Cons:** Advanced browser features require local browser dependencies, command-line interface requires comfort with terminal usage.
