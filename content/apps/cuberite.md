### What it does in plain English
Cuberite lets you run a Minecraft server on your computer or device.  
It uses very little memory and runs fast.  
You can add new features with simple scripts.

### Who it's for
- Minecraft players who want a private server.  
- Small communities looking for a lightweight host.  
- Tech hobbyists who like to tweak settings.

### Key features
- Runs on Windows, Linux, Android, and Raspberry Pi.  
- Very low memory usage.  
- Fast performance, up to 3 × faster than many other servers.  
- Supports Lua plugins for easy customization.  
- Compatible with Java Edition Minecraft clients.

* **Pros:** free forever, open source, no subscription.  
* **Cons:** Linux installation may require command‑line use; supports only Minecraft 1.8‑1.12.2 protocol versions.
