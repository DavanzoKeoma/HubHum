### What it does in plain English
Pear Desktop gives you a dedicated application window for your favorite music streaming services. It runs smoothly on your computer with a native look and feel, keeping your tunes easily accessible without cluttering your web browser tabs. You can customize the visual appearance with themes and extend functionality using community-built plugins.

### Who it's for
* Music lovers who want a dedicated desktop app instead of keeping a browser tab open for streaming audio.
* Customization enthusiasts who enjoy tailoring their player's look with themes and custom plugins.
* Users who prefer lightweight, standalone applications with native system integration.

### Key features
* **Native Desktop Feel:** Runs smoothly as a standalone application on Windows, macOS, and Linux.
* **Theme Customization:** Personalize the interface appearance effortlessly using custom CSS style files.
* **Plugin System:** Build or install plugins to add new shortcuts, visual tweaks, and extra features.
* **System Integration:** Control playback easily with native media keys and minimize to system tray options.
