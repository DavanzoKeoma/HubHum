### What it does in plain English
Get Subscribe is an automated tool that periodically gathers and updates free network subscription lists. It categorizes links into working, untested, or failed connections so users can easily find configurations for temporary testing. The service updates its lists regularly to keep up with changing web addresses and connection statuses.

### Who it's for
* Network testers and developers looking for sample configurations
* Everyday users needing temporary contingency connections for short-term tasks
* Anyone exploring alternative methods to manage network routing tools

### Key features
* Automated updates refreshing connection feeds every 12 hours
* Pre-formatted lists compatible with popular network utility apps
* Automated reachability checks filtering out broken connections
* Categorized outputs separating working paths from failed ones
* Public health reporting showing last check times and category totals

### How to install (Download)
* Access Clash configurations directly via the [Clash Subscription Link](https://blog.ermao.net/sub/clash/ermao.net)
* Access V2Ray configurations directly via the [V2Ray Subscription Link](https://blog.ermao.net/sub/v2ray/ermao.net)
* View verified working TCP connections on the [TCP Reachable List](https://blog.ermao.net/sub/reachable/clash/ermao.net)
* Check the current system status via the [Detection Report](https://www.ermao.net/sub/health.json)
* Follow setup steps for various devices on the [Android Guide](https://blog.ermao.net/article/eh8f4n86/), [Windows Guide](https://blog.ermao.net/article/0gematwc/), and [iOS Guide](https://blog.ermao.net/article/z747kgjd/)

### Pros and Cons
* **Pros:** Completely free to access, updated frequently, supports multiple configuration formats.
* **Cons:** Public links experience heavy congestion and fluctuating speeds, not suitable for production or long-term secure use.
