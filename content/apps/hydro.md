### What it does in plain English
Hydro is a clever extension for ASP.NET Core that brings modern, interactive web design directly into your traditional server-side workflow. It allows you to build stateful components that talk smoothly with the server without requiring full page refreshes. Best of all, you can achieve a modern app feel with little to no custom JavaScript or complex frontend compilation steps.

### Who it's for
* C# and .NET web developers looking to add modern interactivity to their existing projects.
* Teams wanting to build single-page style applications without managing a separate frontend software foundation.
* Developers who prefer writing server-side logic in C# instead of complex client-side scripting.

### Key features
* Extends standard ASP.NET Core View Components to make them fully reactive and stateful.
* Enables components to communicate seamlessly with the server without page reloads.
* Combines familiar Razor views with lightweight background updates and client-side handling.
* Works smoothly in both brand new projects and existing web applications.
* Requires zero separate frontend build steps or complex node tooling.

### How to install (Download)
To use Hydro in your ASP.NET Core project, add the official package via your project command line:
```console
dotnet add package Hydro
```
For complete setup guides, layout imports, and starter kits, visit the [Official Hydro Documentation Website](https://usehydro.dev).

### Pros and Cons
* **Pros:** Keeps your codebase unified in C#, eliminates complex frontend build chains, and creates smooth single-page user experiences.
* **Cons:** Requires an understanding of ASP.NET Core Razor Pages or MVC structures to set up effectively.
