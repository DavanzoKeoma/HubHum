### What it does in plain English
MacNativeGames lets you play select console games directly on modern Apple hardware by letting the game's original code run natively on Apple chips. Instead of using traditional slow emulators, it rebuilds the console's graphics commands directly into Apple's high-performance Metal graphics system. You supply your own legally owned game files and encryption keys to build an application tailored for your specific device.

### Who it's for
* Apple Silicon Mac, iPhone, and iPad owners who want to explore native performance capabilities.
* Enthusiasts who want to experience supported console games with high resolutions and fluid frame rates.
* Technical hobbyists interested in advanced graphics translation and modern hardware compatibility.

### Key features
* Direct execution of game code on Apple chips without heavy emulation overhead.
* Graphics translation built on Apple's native Metal software foundation for smooth visuals.
* Shared shader list integration to reduce stuttering during gameplay across devices.
* Support for multiple platforms including macOS, iOS, and experimental virtual reality streaming options.
