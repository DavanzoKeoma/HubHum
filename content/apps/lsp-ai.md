### What it does in plain English
LSP-AI acts as a helpful bridge that connects modern artificial intelligence to the text editors programmers use every day. It allows you to chat with AI models directly inside your code window to ask questions or brainstorm solutions. It also provides automatic code suggestions to help you write software faster without needing to switch between different programs.

### Who it's for
* Software developers who want to use AI tools within their preferred, lightweight text editors.
* Programmers looking for an open-source alternative to commercial AI coding assistants.

### Key features
* **In-Editor Chat:** Talk to AI models directly within your coding environment to get instant help.
* **Custom Actions:** Create personalized shortcuts to automate repetitive tasks like code refactoring.
* **Smart Completions:** Receive real-time code suggestions as you type, similar to popular commercial tools.
* **Universal Compatibility:** Works with any text editor that supports standard language server protocols.
* **Flexible Backend Support:** Connect to a variety of local or cloud-based AI models based on your preference.
