### What it does in plain English
This tool taps directly into the built-in artificial intelligence engine already included with modern Apple Silicon computers. It operates completely on your own device, meaning your text, files, and queries never leave your computer or travel to external servers. You can interact with it through a standard command-line interface, a local background service, or an interactive chat window.

### Who it's for
* Everyday Mac users who want free, private text assistance without signing up for online subscription services.
* Writers and researchers who need to summarize local documents, PDFs, or images securely on their own machine.
* Developers looking for a local drop-in server replacement for cloud-based artificial intelligence endpoints.

### Key features
* Operates 100 percent on-device using built-in Mac hardware acceleration with zero cloud dependency.
* Requires no API keys, paid subscriptions, or external software downloads to function.
* Includes command-line options for piping text, examining local files, reading images, and extracting text.
* Provides a local background server mode compatible with standard application programming interfaces.
* Offers interactive chat capabilities right inside your terminal window.

### How to install (Download)
To install the tool via Homebrew, open your terminal and run:
```bash
brew install apfel
```

### Pros and Cons
* **Pros:** Completely free to use, requires no internet connection, highly private, and runs locally without accounts.
* **Cons:** Limited to modern Apple Silicon computers running recent macOS versions, and processing speed depends on your specific Mac hardware.
