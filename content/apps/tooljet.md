### What it does in plain English
ToolJet lets you build custom internal apps, administrative panels, and operational dashboards without writing complex code from scratch. You can design interfaces visually using drag-and-drop components or simply describe what you need through text prompts. It connects smoothly to your existing databases, cloud storage, and business software so your team can manage data in one place.

### Who it's for
* **Operations Teams:** Build custom tracking dashboards and data management portals without waiting for engineering resources.
* **Developers:** Rapidly spin up internal tools and connect disparate APIs while retaining full control over code and cloud setup.
* **Product Managers:** Create quick proof-of-concept workflows and operational interfaces to test new business processes.

### Key features
* **Visual App Builder:** Drag and drop over 80 responsive interface elements like tables, charts, forms, and progress bars.
* **AI-Assisted Generation:** Turn natural language descriptions into fully functional pages, queries, and components instantly.
* **Extensive Data Connections:** Link securely to dozens of popular databases, cloud storage providers, and business software services.
* **Multiplayer Collaboration:** Work together with teammates on the same app layout in real time.

### How to install (Download)
You can jump right in without any setup by creating an account on [ToolJet Cloud](https://tooljet.com). If you prefer running the software on your own infrastructure, you can cloud setup it locally using Docker with the official command provided in the documentation or explore the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-fxjto27jkpqfg?sr=0-1&ref_=beagle&applicationId=AWSMPContessa) and [Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps/tooljetsolutioninc1679496832216.tooljet?tab=Overview). * **Pros:** Open-source foundation, massive collection of pre-built UI components, connects to almost any database or API.
* **Cons:** Advanced enterprise features require higher tiers, setting up custom self-hosted environments takes technical know-how.
