### What it does in plain English
ProxMenux provides a simple, menu-driven interface to help you set up and maintain your Proxmox server without needing complex commands. It includes a visual web dashboard that lets you monitor your server's health, such as memory and storage usage, from any web browser. This tool makes routine tasks like creating backups and checking system status much faster and more accessible for home server users.

### Who it's for
* Home server enthusiasts who want a more visual way to manage their Proxmox environment.
* Users who prefer guided, menu-based options over typing long commands in a terminal.

### Key features
* **Interactive Menus:** Perform common server tasks using simple, numbered lists instead of manual typing.
* **Live Web Dashboard:** Monitor your CPU, RAM, and disk usage in real-time from your phone or computer.
* **Backup & Restore:** Easily manage your server backups through a streamlined interface.
* **Secure Access:** Includes built-in login protection and support for two-factor authentication.
* **Automatic Setup:** Installs all necessary components automatically with a single command.

### How to install (Download)
To install ProxMenux, open your Proxmox server terminal and run the following command:

```bash
bash -c "$(wget -qLO - https://raw.githubusercontent.com/MacRimi/ProxMenux/main/install_proxmenux.sh)"
```

Once installed, you can launch the toolkit at any time by typing `menu` in your terminal. The web dashboard will be available at `http://<your-proxmox-ip>:8008`.

### Pros and Cons
* **Pros:** Completely free and open-source, saves significant time on server maintenance, and provides a mobile-friendly monitoring dashboard.
* **Cons:** Requires basic familiarity with accessing a server terminal to perform the initial installation.
