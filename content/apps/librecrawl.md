### What it does in plain English
LibreCrawl is a free website auditing tool that scans web pages to uncover search engine optimization insights and broken links. It explores website structures just like major search engine bots do, highlighting missing titles, slow pages, and technical errors. You can run deep site checks, render modern interactive pages, and export your findings into standard spreadsheet formats instantly.

### Who it's for
* **Website owners** who want to audit their pages for technical search errors without paying monthly software fees.
* **Freelancers and small agencies** needing a reliable, self-hosted website crawler for client projects.
* **Content creators** looking to inspect internal links, keyword frequencies, and page speed metrics.

### Key features
* **Multi-user workspace:** Supports multiple concurrent users with completely isolated scanning sessions.
* **JavaScript rendering:** Processes modern dynamic software foundation like React, Vue, and Angular correctly.
* **Issue detection:** Automatically spots missing meta descriptions, broken links, and duplicate content.
* **Speed insights integration:** Connects with performance metrics to check page speed and Core Web Vitals.
* **Flexible exports:** Save your audit reports as CSV spreadsheets, Excel workbooks, JSON, or XML files.

### How to install (Download)
To download and set up LibreCrawl on your computer, visit the [LibreCrawl Releases and Source Page](https://github.com/PhialsBasement/LibreCrawl). You can grab the source archive or clone the project, then use Python 3.11 or Docker to start your local server.

### Pros and Cons
* **Pros:** Completely free and open-source, no subscription limits, highly customizable with plugins.
* **Cons:** Large websites can take time to scan fully, setting up manual environments requires basic command-line familiarity.
