### What it does in plain English
jnv is a handy tool that lets you open and explore large structured data files directly inside your terminal screen. As you type search filters, it updates the results immediately so you can find exact data points without guessing. It features color-coded text, automatic suggestions, and collapsible sections to make sense of sprawling data files.

### Who it's for
- Software developers inspecting configuration files or server logs.
- Data analysts reviewing exported records and structured datasets.
- System administrators troubleshooting data payloads on remote servers.

### Key features
- **Live Filtering:** See query results change instantly as you type your search filters.
- **Color-Coded Viewing:** Easily read keys, strings, numbers, and brackets with clear syntax highlighting.
- **Smart Suggestions:** Get automatic autocomplete hints for keys and arrays as you type.
- **Collapsible Data Trees:** Expand or collapse sections of data to focus only on what matters.
- **Flexible Inputs:** Open local files directly or pipe data straight from other commands.

### How to install (Download)
You can install jnv easily using common terminal package managers or shell scripts:

* **Using Homebrew (macOS / Linux):**
  ```bash
  brew install jnv
  ```
* **Using Cargo (Rust ecosystem):**
  ```bash
  cargo install jnv
  ```
* **Using MacPorts:**
  ```bash
  sudo port install jnv
  ```
* **Automated Shell Installer:** Run the official script [jnv-installer.sh](https://github.com/ynqa/jnv/releases/download/v0.7.1/jnv-installer.sh) to set it up automatically.
* **Manifest & Checksums:** View details via the official [dist-manifest.json](https://github.com/ynqa/jnv/releases/download/v0.7.1/dist-manifest.json).

### Pros and Cons
* **Pros:** Fast keyboard-driven interface, built-in filter engine without extra setup, highly customizable appearance.
* **Cons:** Runs inside the terminal rather than a traditional window, requires basic familiarity with command-line tools.
