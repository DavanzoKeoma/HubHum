### What it does in plain English
Sampler brings live visual charts and graphs straight into your terminal using standard commands. Whenever you want to track dynamic metrics, database health, or network traffic without setting up heavy servers, this tool handles it effortlessly. You simply write a quick configuration file to define your favorite commands, and the program instantly draws clean visual blocks for you.

### Who it's for
* Software developers who want quick real-time metrics during local testing without installing heavy enterprise dashboards.
* System administrators who need a lightweight way to monitor remote server health and script execution states.
* Tech enthusiasts who love customizing their terminal environments with live clocks, weather widgets, and activity gauges.

### Key features
* Turn regular command line output into live trend charts, sparklines, gauges, and text boxes.
* Set up conditional triggers that play sound alerts or run specific scripts when numbers cross your custom thresholds.
* Connect securely to remote machines and databases using standard command sequences inside interactive shell sessions.
* Customize everything easily using a single, human-readable text file with full color theme support.
