### What it does in plain English
Elia brings popular large language models directly into your command-line environment for a distraction-free conversation experience. You can chat with cloud-based services like ChatGPT and Claude or run private local models using offline servers. All of your past discussions automatically save to a local database so you can easily review them later.

### Who it's for
* Developers and power users who live inside the terminal and want quick answers without opening a web browser.
* Privacy-conscious individuals running local language models offline on their own hardware.
* Fans of keyboard-driven workflows who prefer speed and efficiency over mouse navigation.

### Key features
* Fast, keyboard-centric interface designed for rapid daily interactions.
* Support for major cloud models as well as local models running via offline tools.
* Local SQLite storage to keep complete history of all past conversations securely on your device.
* Import capability to bring in past chat exports from other platforms.
* Customizable color themes and configuration options to match your terminal setup.

### How to install (Download)
To install Elia, make sure you have Python installed and use [pipx](https://github.com/pypa/pipx) by running the following command in your terminal:

```bash
pipx install --python 3.11 elia-chat
```

To launch the application once installed, simply type:

```bash
elia
```

### Pros and Cons
* **Pros:** Blazing fast, runs entirely in the terminal, supports offline local models, keeps all data locally.
* **Cons:** Requires basic familiarity with command-line tools, keybindings cannot be fully customized inside the app yet.
