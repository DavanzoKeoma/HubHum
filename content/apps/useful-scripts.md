### What it does in plain English
This project brings together a curated set of command-line tools that handle routine technical headaches with ease. It automates repetitive manual steps, such as tracking down heavy software processes or sorting through text files. Everything runs seamlessly right inside your terminal to keep your computer routine running smoothly.

### Who it's for
* Software developers and system administrators looking to speed up command-line tasks.
* Technical power users who want reliable shortcuts for troubleshooting everyday system slowdowns.

### Key features
* Instantly pinpoints heavy tasks consuming system resources.
* Eliminates duplicate entries in text files without needing manual sorting.
* Automatically copies command outputs directly to your system clipboard.
* Converts messy file paths into clean relative or absolute routes.
* Works reliably across standard terminal environments without extra bulk.

### How to install (Download)
You can set up and run the helper tools instantly using the automated installer command in your terminal:
```bash
source <(curl -fsSL https://raw.githubusercontent.com/oldratlee/useful-scripts/release-3.x/test/self-installer.sh)
```
For manual setup instructions and detailed documentation, visit the [Official official project page & Setup Guide](https://github.com/oldratlee/useful-scripts).

### Pros and Cons
* **Pros:** Free forever, open-source, lightweight, and saves time on repetitive tasks.
* **Cons:** Requires basic familiarity with command-line terminals to use effectively.
