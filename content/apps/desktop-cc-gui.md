### What it does in plain English
Desktop CC GUI brings multiple command-line artificial intelligence coding assistants into one friendly visual window. Instead of managing separate text terminals for different engines, you can pick your preferred project helper, chat naturally, and watch your code update in real time. It keeps your chat history, workspace folders, and settings neatly organized in one desktop app.

### Who it's for
* Software developers who want a unified desktop interface for experimenting with different AI coding engines.
* Freelance programmers looking to streamline bug fixes, git updates, and code explanations across multiple projects.
* Tech enthusiasts who prefer visual buttons and file trees over typing commands into a black terminal window.

### Key features
* Combines numerous coding assistants into a single visual window with live streaming responses.
* Organizes your project files with a git-aware file tree and built-in editor preview.
* Includes a real terminal dock, git management panel, and keyboard command palette.
* Persists your session history and provider channels locally on your machine.
* Offers expandable tool call viewers, code diffs, and customizable thinking stream displays.
