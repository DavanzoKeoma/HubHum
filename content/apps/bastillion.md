### What it does in plain English
Bastillion acts as a central hub that lets you manage and access your remote servers directly through a web browser. It eliminates the need for individual users to handle sensitive access keys by managing them automatically and securely on your behalf. Every action taken in the browser terminal is recorded, providing a clear audit trail for security and compliance purposes.

### Who it's for
* **System Administrators** who need to manage a fleet of servers without juggling dozens of individual access keys.
* **Security-conscious teams** that require a detailed log of all remote commands for compliance and auditing.

### Key features
* **Web-based Terminal:** Open live command-line sessions to your servers directly in your browser.
* **Command Broadcasting:** Type a command once and have it execute across multiple server sessions simultaneously.
* **Centralized Key Management:** Automatically distribute and rotate access keys so users don't have to manage them manually.
* **Full Session Auditing:** Every keystroke and output is recorded, allowing you to replay sessions for security reviews.
* **Multi-Factor Authentication:** Protect your access dashboard with standard security codes for an extra layer of safety.

### How to install (Download)
To run Bastillion, ensure you have Java 21 installed on your system. You can download the latest version below:

* [Download for Linux/Windows/macOS (bastillion-6.0.4.jar)](https://github.com/Loophole-LLC/Bastillion/releases/download/v6.0.4/bastillion-6.0.4.jar)
* [Download Migration Tool (bastillion-migrate-1.0.0.jar)](https://github.com/Loophole-LLC/Bastillion/releases/download/v6.0.4/bastillion-migrate-1.0.0.jar)

To start the application, run the following command in your terminal: `java -jar bastillion-6.0.4.jar`. Access the interface at `https://localhost:8443` in your browser.

### Pros and Cons
* **Pros:** Free for up to 8 systems, simplifies complex access management, and provides built-in audit logging.
* **Cons:** Requires Java 21 to run, and initial setup of server connections requires administrative configuration.
