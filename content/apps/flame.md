### What it does in plain English
Flame provides a central, visual home screen for all the web-based tools and bookmarks you use every day. It features a built-in editor that lets you add or remove links without needing to touch any complex configuration files. You can also customize the look with different themes and add helpful widgets like a weather display or a quick search bar.

### Who it's for
* Home server enthusiasts who want a clean way to access their various services.
* Anyone looking to replace their browser's default new tab page with a personalized, organized dashboard.

### Key features
* **Visual Dashboard:** Pin your most-used applications and websites to a single, organized screen.
* **Easy Management:** Use the built-in editor to update your links and layout directly through your browser.
* **Smart Search:** A unified search bar that lets you search your own bookmarks or use popular web search engines.
* **Customization:** Choose from 15 built-in color themes or create your own custom look.
* **Automatic Discovery:** If you use container software, Flame can automatically detect and add your running apps to the dashboard.

### How to install (Download)
Flame is designed to be run as a containerized service. You can find the official images and setup instructions on the [Docker Hub page](https://hub.docker.com/r/pawelmalak/flame). For users who prefer not to use containers, please refer to the [official installation guide](https://github.com/pawelmalak/flame/wiki/Installation-without-docker).

### Pros and Cons
* **Pros:** Completely free and open-source, highly customizable, and requires no coding knowledge to set up.
* **Cons:** Requires a basic understanding of how to host web services on your own computer or server.
