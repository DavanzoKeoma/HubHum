### What it does in plain English
Mission Control acts as a central command center for all your automated AI workers. It allows you to assign tasks, track progress, and review the results of your AI agents in one organized dashboard. By keeping everything in one place, you can easily monitor costs, catch errors, and ensure your automated projects stay on track.

### Who it's for
* **AI Enthusiasts** who run multiple automated agents and need a way to keep their work organized.
* **Project Managers** who want to oversee the output and efficiency of automated systems without checking individual tools separately.

### Key features
* **Unified Task Board:** Organize agent work through a clear pipeline from assignment to final review.
* **Activity Tracking:** Monitor live sessions, agent heartbeats, and system events in real time.
* **Cost and Usage Monitoring:** Keep an eye on how much your agents are spending and how they are performing.
* **Knowledge Management:** Browse agent memory and project files through an integrated visual interface.
* **Security Controls:** Manage access with built-in role checks, API keys, and audit logs.

### How to install (Download)
Mission Control is a web-based application designed to be hosted on your own machine or server. You can get started using the following methods:

* **Quick Start with Docker:** If you have Docker installed, simply run `docker compose up` in the project folder.
* **Local Installation:** Ensure you have Node.js 22+ and pnpm installed, then run the provided `install.sh` (Linux/macOS) or `install.ps1` (Windows) script.
* **Official Website:** Visit the [Mission Control Dashboard](https://mc.builderz.dev) for setup guides and documentation.

### Pros and Cons
* **Pros:** Centralizes fragmented AI workflows, provides a visual interface for complex agent tasks, and supports multiple popular agent runtimes.
* **Cons:** Currently in an early development stage, which means settings and features may change frequently; requires some technical setup to host locally.
