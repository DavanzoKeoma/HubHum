### What it does in plain English
LoopForge acts as a central command center for teams using AI coding assistants to build software. It allows you to create repeatable, step-by-step workflows that include automated testing and human approval stages before any code is finalized. By keeping everything in a secure, self-hosted environment, it ensures that your team's development process remains consistent, observable, and under your control.

### Who it's for
* **Software Development Teams** looking to standardize how their AI agents handle tasks like bug fixes and feature implementation.
* **Engineering Managers** who need to oversee AI-generated code changes and ensure they pass human review before being merged into a project.

### Key features
* **Repeatable Workflows:** Save successful development patterns as standard procedures to ensure every task follows the same testing and review steps.
* **Human-in-the-loop Control:** Set up approval gates that pause automated work, allowing you to review, steer, or reject changes before they are applied.
* **Versatile Agent Support:** Connects with a wide variety of popular coding assistants and tools to handle different parts of the development lifecycle.
* **Secure Sandboxing:** Runs tasks in isolated environments to keep your main systems safe while the agents work on your code.
* **Full Visibility:** Track every requirement from start to finish with detailed logs, artifact snapshots, and clear status updates for every step.

### How to install (Download)
LoopForge is designed to be self-hosted using Docker. To get started, ensure you have Git and Docker installed on your machine, then run the following commands in your terminal:

```bash
git clone https://github.com/Tencent/LoopForge.git
cd LoopForge
./start.sh
```
For detailed cloud setup instructions, including cloud hosting and security configuration, please visit the [Official Documentation](https://github.com/Tencent/LoopForge).

### Pros and Cons
* **Pros:** Complete control over your data and infrastructure, highly repeatable processes, and excellent oversight for AI-assisted work.
* **Cons:** Requires basic knowledge of Docker and server management to set up, and you must provide your own API keys for the AI models used.
