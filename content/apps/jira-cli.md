### What it does in plain English
Jira-cli brings the power of your project tracking boards directly into your computer terminal. Instead of clicking through slow web pages, you can search, create, update, and move tasks using simple keyboard commands. It gives you a clean interactive display so you can handle everyday project work instantly.

### Who it's for
* Software developers who want to update ticket statuses and review issues without leaving their coding window.
* Project managers and team leads looking for a lightning-fast way to search and filter large lists of tasks.
* Power users who prefer keyboard-driven terminal workflows over heavy web interfaces.

### Key features
* Interactive terminal interface to view, navigate, and filter issues with ease.
* Quick creation, editing, cloning, and linking of issues directly from commands.
* Support for both Jira Cloud and local on-premises server setups.
* Flexible search options using custom filters or advanced query language.
* Convenient automation support and shell completion for maximum efficiency.

### How to install (Download)
You can download official packaged binaries for Linux, macOS, and Windows directly from the [Official Releases Page](https://github.com/ankitpokhrel/jira-cli/releases). 

If you have Docker installed, you can also run it instantly with:
```sh
docker run -it --rm ghcr.io/ankitpokhrel/jira-cli:latest
```
For installation via package managers like Homebrew or Nix, please check the [Installation Guide](https://github.com/ankitpokhrel/jira-cli/wiki/Installation).

### Pros and Cons
* **Pros:** Completely free and open-source, lightning-fast keyboard navigation, works seamlessly with both cloud and local servers.
* **Cons:** Requires initial setup of a security token and basic familiarity with terminal commands.
