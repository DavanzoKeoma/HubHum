### What it does in plain English
This tool visits any website and automatically identifies the colors, fonts, spacing, and layout rules that make it look the way it does. It organizes this information into ready-to-use files that you can plug directly into your own design software or coding projects. You can even use it to compare your own work against professional sites to see how you can improve your visual consistency.

### Who it's for
*   **Web Designers** who want to quickly study the visual structure of successful websites for inspiration.
*   **Developers** who need to turn a live website's style into usable code tokens or design variables without manual measurement.

### Key features
*   **Automatic Extraction:** Pulls colors, typography, shadows, and spacing directly from a live web page.
*   **Multi-Platform Support:** Exports styles for use in web projects, mobile apps, and design software like Figma.
*   **Accessibility Checks:** Automatically scores the contrast of colors to ensure your designs meet readability standards.
*   **Consistency Grading:** Provides a report card on how well a website maintains its design rules across different pages.
*   **No Setup Required:** Works instantly via your terminal without needing to create accounts or manage complex keys.

### How to install (Download)
This tool is designed to be run via the Node.js environment. Ensure you have [Node.js (version 20 or later)](https://nodejs.org/) installed on your computer.

1. Open your terminal or command prompt.
2. Run the following command to install the tool globally:
   `npm i -g designlang`
3. Once installed, run this command once to set up the necessary browser components:
   `designlang install-browser`

### Pros and Cons
*   **Pros:** Completely free to use, no account or subscription required, and works with any public website.
*   **Cons:** Requires basic familiarity with using a terminal window; advanced features may take a short time to learn.
