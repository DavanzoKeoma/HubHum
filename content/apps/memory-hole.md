### What it does in plain English
Memory Hole lets you store common support questions and the answers that solve them.  
You can add tags to each question so similar topics stay together.  
A built‑in search lets you find the right answer in seconds.  

### Who it's for
- Customer‑service teams that handle many recurring issues.  
- Small IT help desks that need a simple place to share solutions.  
- Any group that wants a shared knowledge base of how to fix common problems.  

### Key features
- Log in with your existing company account.  
- Add tags to group similar questions.  
- Attach files such as screenshots or logs.  
- Write answers with simple formatting and see a live preview.  
- Search by words or phrases to locate answers fast.  

### How to install (Download)
- **Download the application:** [Download memory‑hole.jar](https://github.com/yogthos/memory-hole/releases/download/1.1/memory-hole.jar)  
- After downloading, double‑click the file or run it with Java (e.g., `java -jar memory-hole.jar`).  

### Pros and Cons
* **Pros:** free forever, self‑hosted, customizable, works with existing accounts.  
* **Cons:** requires Java to be installed, you need to set up a database yourself.
