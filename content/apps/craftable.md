### What it does in plain English
Craftable is a ready-made starter kit designed for developers working with the Laravel web software foundation. It provides a clean, minimalistic control center complete with user login screens, security permissions, and tools to automatically generate data tables. Instead of writing administrative screens from scratch, you can plug this toolkit into your project and immediately manage your database records.

### Who it's for
* Web developers building custom internal software or client back-offices
* Small business owners needing a simple custom content management system
* Teams looking to bootstrap new web applications with pre-built user management

### Key features
* Pre-designed, responsive administration template for a professional look
* Automated code generators to quickly create data management screens
* Built-in user security, login forms, and access control settings
* Multilingual translation manager to handle text across different languages
* Media library integration to easily attach images and files to your records

### How to install (Download)
You can explore the live preview at the [Official Craftable Demo Site](https://demo.getcraftable.com). To install the toolkit in your projects, visit the [Official Craftable Website](https://getcraftable.com) or follow the instructions in the [Official Source / Credits](https://github.com/BRACKETS-by-TRIAD/craftable).

### Pros and Cons
* **Pros:** Saves dozens of hours of repetitive coding, free and open source, clean user interface.
* **Cons:** Requires familiarity with PHP and the Laravel ecosystem to set up and customize.
