### What it does in plain English
Bagels is a quick and private expense tracker designed to run directly inside your computer's command line interface. It lets you log daily purchases, split transactions, set monthly savings budgets, and view clear spending charts without needing an active internet connection. Keeping your financial records locally at the end of the day makes building a reliable tracking habit fast, simple, and entirely private.

### Who it's for
* Privacy-conscious individuals who prefer keeping financial logs on their local device rather than sharing data with cloud services.
* Command-line power users and developers who want to manage budgets without switching away from their terminal workspace.
* Anyone looking to build a consistent end-of-day habit for monitoring money flow with minimal friction.

### Key features
* **Local Data Privacy:** Stores all your financial records and categories securely on your own device.
* **Recurring Templates:** Set up templates for regular bills or income to add repeating records instantly with simple keystrokes.
* **Detailed Insights:** Visualize your spending patterns and estimated costs with built-in graphs and category filtering.
* **Budgeting Controls:** Set up monthly limits to keep unnecessary spending in check and boost personal savings.
* **Keyboard-Driven Navigation:** Move around smoothly using quick shortcuts designed for maximum speed and efficiency.

### How to install (Download)
Bagels can be installed easily across macOS, Linux, and Windows using various package managers.

**Recommended Installation (via UV):**
* Unix / macOS: `uv tool install --python 3.13 bagels` (Requires the uv package manager from [Astral UV Installation Guide](https://docs.astral.sh/uv/getting-started/installation/))
* Windows: `winget install --id=astral-sh.uv -e` followed by `uv tool install --python 3.13 bagels`

**Alternative Package Managers:**
* Homebrew (macOS/Linux): `brew install bagels`
* Pipx (Python environments): `pipx install bagels`
* Conda: `conda install -c conda-forge bagels`

### Pros and Cons
* **Pros:** Free forever, lightweight, stores data locally for complete privacy, lightning-fast keyboard operation.
* **Cons:** Requires using a terminal window, advanced configuration options take a brief moment to learn.
