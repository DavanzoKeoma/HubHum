### What it does in plain English
Operit transforms your Android device into a capable AI workstation by connecting cloud and local language models directly to your files, terminal, and browser. It lets you automate repetitive device tasks, manage code projects, and converse with customizable AI characters right on your phone. You can run local models or plug in your preferred cloud services to handle everything from web research to file editing and workflow triggers.

### Who it's for
* Mobile developers and tech enthusiasts who want a functional terminal, code editor, and project workspace directly on their phones.
* Power users looking to automate everyday Android tasks using intelligent screen understanding and custom workflows.
* Anyone wanting a flexible, privacy-conscious AI chat companion that supports local models and rich character customization.

### Key features
* Connects to both cloud-based AI services and local model options for complete flexibility.
* Deep Android integration allows the assistant to read pages, interact with screen elements, and execute system tools safely.
* Built-in terminal and development workspace supporting multiple programming languages and environments.
* Long-term graph memory system and character card support for personalized multi-turn conversations.
* Unified marketplace to discover and install extra tool packages, workflows, and extensions.

* **Pros:** Free and open source with no forced subscriptions, supports completely offline local models, and offers deep device integration.
* **Cons:** Requires an ARM64 Android device running version 8.0 or newer, and advanced terminal or automation features require a short learning curve.
