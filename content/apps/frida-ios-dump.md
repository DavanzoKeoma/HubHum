### What it does in plain English
This tool helps you retrieve clean, unlocked application packages from modified mobile devices. It connects directly over a secure USB link to pull running software into a standard installable file format. You can list all installed programs on your device and pull any choice item with a single command.

### Who it's for
* Software developers who need to test their applications in various environments.
* Security researchers auditing mobile software behavior and architecture.
* Advanced device owners wishing to archive and back up their installed software library.

### Key features
* Connects directly over USB without complex network port forwarding.
* Packages extracted files cleanly into standard installable application formats.
* Scans and downloads resource files and support libraries in parallel for fast transfers.
* Preserves exact folder structures, user permissions, and symbolic links automatically.
* Offers command-line options for custom network ports, alternative credentials, and detailed logging.

### How to install (Download)
This project is available as open-source code from the official release page. You will need Python and Node.js installed on your computer to set up the required environment dependencies. Visit the [Official Releases Page](https://github.com/AloneMonkey/frida-ios-dump/releases) to download the source files and follow the setup instructions in the project documentation.

### Pros and Cons
* **Pros:** Free forever, no subscription required, direct USB connection support.
* **Cons:** Requires a modified jailbroken device, initial environment setup requires basic terminal knowledge.
