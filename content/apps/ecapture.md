### What it does in plain English
eCapture intercepts secure website traffic and terminal commands directly from your computer's operating system kernel. It lets you inspect encrypted data streams in plain text without modifying your browser settings or installing complex security certificates. This gives developers and system administrators an effortless way to troubleshoot network connections and audit security logs in real time.

### Who it's for
* Software developers troubleshooting secure communication between applications and servers
* Security analysts auditing encrypted network traffic for debugging and compliance
* System administrators monitoring terminal command history and database queries

### Key features
* Captures plaintext from standard secure web libraries like OpenSSL and Go TLS
* Monitors interactive shell commands entered in Bash and Zsh sessions
* Audits database queries for popular systems like MySQL, MariaDB, and PostgreSQL
* Operates without requiring a man-in-the-middle proxy or custom certificate authority
