### What it does in plain English
ESTabBarController is a flexible navigation component for mobile application developers using Swift. It replaces standard, rigid bottom menu bars with a fully customizable interface supporting rich animations, custom icons, and dynamic notification badges. Developers can easily tailor colors, sizes, and interactive hit areas to match unique design visions without altering core navigation logic.

### Who it's for
* Mobile app developers building custom user interfaces in Swift.
* UI/UX designers looking to implement animated and branded navigation elements.
* Open-source contributors seeking robust layout components for iOS projects.

### Key features
* Seamlessly drop-in replacement for standard system tab controllers.
* Smooth support for custom selection, highlight, and notification animations.
* Ability to embed vector animations using Lottie for eye-catching icon effects.
* Custom hit-test sizing allowing touch areas to extend beyond visual boundaries.
* Automatic handling of overflow items with a built-in customizable "More" menu.
