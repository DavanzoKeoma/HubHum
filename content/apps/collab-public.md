### What it does in plain English
Collaborator provides an infinite visual workspace where you can run AI agents right alongside your project files and live command line terminals. Instead of constantly hunting for lost browser tabs or switching between windows, you arrange everything side by side on a smooth pan-and-zoom canvas. All your data stays safe and secure right on your local computer hard drive without requiring any online user accounts.

### Who it's for
* Software creators and developers who work extensively with AI coding assistants.
* Writers and technical researchers who want an infinite visual board for notes, code snippets, and live terminals.
* Anyone looking to declutter their desktop by uniting all project resources into a single interactive window.

### Key features
* **Infinite Visual Canvas:** Arrange your terminals, notes, code snippets, and images anywhere you like on a zoomable workspace grid.
* **Built-in Terminals:** Run independent command line sessions that stay active right inside your visual project layout.
* **Live File Viewer:** Open and edit markdown notes, code files, and view images seamlessly alongside your canvas tiles.
* **Multiple Workspaces:** Easily switch between different local project folders without losing your open windows and layout.
* **Local Data Storage:** Keep full control of your private work since everything saves directly as lightweight files on your local drive.

### How to install (Download)
* [Download the latest release](https://github.com/collaborator-ai/collab-public/releases/latest) for your operating system.
* **macOS / Linux Command Line:** You can also install quickly via terminal using `curl -fsSL https://raw.githubusercontent.com/collaborator-ai/collab-public/main/install.sh | bash`.
* **Windows:** Use the official `.exe` setup file provided on the main release page.

### Pros and Cons
* **Pros:** Keeps all project tools in one window, works completely offline with local files, fast hot-reloading desktop experience.
* **Cons:** Early-stage project currently in active development, advanced custom terminal setups may require familiarity with local directories.
