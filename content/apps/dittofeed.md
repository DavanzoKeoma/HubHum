### What it does in plain English
Dittofeed helps you reach your customers wherever they are—by email, text, app alerts, WhatsApp, or Slack. You can set up one‑time announcements or automatic journeys that trigger when something happens. All of this is managed through a simple visual dashboard you can run on your own server.

### Who it's for
* Small business owners who want to keep customers informed.  
* Marketers looking for an easy way to run campaigns across many channels.  
* Developers who prefer to host the tool themselves for full control.

### Key features
- Visual builder to group users based on any criteria.  
- Drag‑and‑drop editor for email and message templates.  
- Send one‑off broadcasts or automated journeys that react to events.  
- Reach users on email, SMS, push notifications, WhatsApp, Slack and more.  
- Dashboard shows how each message performed so you can improve over time.

### How to install (Download)

### Pros and Cons
* **Pros:** free forever, open source, self‑hosted for full data control, works on many channels.  
* **Cons:** you need to set up your own server or cloud instance, some advanced settings may require a short learning curve.
