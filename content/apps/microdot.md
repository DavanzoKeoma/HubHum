### What it does in plain English
Microdot lets you turn a few lines of Python into a tiny website or service.  
It works on regular computers and on tiny boards like microcontrollers.  
You can run it directly without needing extra software.

### Who it's for
* Hobbyists who want a simple web page on a Raspberry Pi or similar project.  
* Students learning how web pages work with Python.  
* Developers building lightweight APIs for small devices.

### Key features
* Define web routes with straightforward Python functions.  
* Runs on both standard Python and MicroPython.  
* Extremely small code size, perfect for limited‑resource hardware.  
* Handles requests quickly without slowing down tiny devices.  
* Newer versions add easy form handling and basic login support.

### How to install (Download)
* **Project page:** [Microdot project site](https://code.miguelgrinberg.com/miguelgrinberg/microdot)  
* **Package on PyPI:** [Microdot on PyPI](https://pypi.python.org/pypi/microdot)

### Pros and Cons
* **Pros:** completely free, tiny footprint, works on microcontrollers.  
* **Cons:** fewer built‑in features than larger software foundation, requires basic Python knowledge.
