### What it does in plain English
Shell-rs combines server management, tabbed terminal windows, file browsing, and port forwarding into a single, high-performance application. It runs smoothly on your computer by leveraging modern graphics processing for its interface instead of relying on heavy browser technology. Your passwords and sensitive connection details remain strictly protected inside your operating system's secure keychain rather than plain database files.

### Who it's for
* System administrators and developers managing multiple remote Linux, macOS, or Windows servers daily.
* IT professionals looking for an alternative to traditional multi-window terminal and file transfer setups.
* Advanced users who want to give automated AI coding assistants safe, structured command execution access.

### Key features
* Unified workspace featuring server host trees, tabbed remote terminals, and dual-pane file management side by side.
* Built-in server resource monitoring, Docker container control, Kubernetes cluster inspection, and live log viewing.
* Secure credential handling that stores passwords exclusively in system keychains and never inside configuration files.
* Direct compatibility with bastion hosts and jump servers for seamless multi-hop remote connections.
* Integrated local and remote port forwarding rules with clear visual diagrams explaining traffic flow.
