### What it does in plain English
Palettum is a creative tool that lets you completely change the color palette of any image, animated GIF, or video file. You can choose whether to snap every single pixel to its nearest matching color—which is perfect for creating retro pixel-art styles—or blend the new colors softly as an artistic filter. It works right inside your web browser or via command-line tools for advanced users.

### Who it's for
* **Pixel artists** who want to quickly test different aesthetic color schemes on their digital artwork and retro animations.
* **Content creators** looking to apply unified, mood-matching color themes across video clips and image galleries.
* **Designers** experimenting with custom palettes to find unique visual styles for web and media projects.

### Key features
* **Dual coloring modes:** Switch easily between crisp pixel-art color snapping and smooth gradient filtering.
* **Multi-format support:** Apply custom palettes to static images, moving GIFs, and video files seamlessly.
* **Browser-based experience:** Try out color transformations immediately on the web without installing complex software.
* **Advanced color science:** Utilizes precise mathematical formulas for natural-looking color transitions and palette extraction.

### How to install (Download)
You can use Palettum directly online by visiting the [Official Web App](https://palettum.com). 

If you are on macOS and prefer using a package manager, you can install it via terminal:
```bash
brew tap arrowpc/palettum
brew install palettum
```
Alternatively, you can inspect precompiled checksums and release packages directly from the [Official Releases Page](https://github.com/arrowpc/palettum/releases).

### Pros and Cons
* **Pros:** Works directly in the browser, supports both images and videos, great preset aesthetic styles included.
* **Cons:** Advanced command-line usage requires familiarity with terminal tools, heavy video processing can take extra time on slower computers.
