### What it does in plain English
Roadiz is a website management platform that organizes your digital content using flexible nodes rather than rigid templates. It gives website creators the freedom to structure pages however they want, supporting multiple visual styles for a single underlying database. The clean, modern control panel makes editing text, images, and services smooth and straightforward.

### Who it's for
* Web designers looking for a flexible content management tool with independent visual themes.
* Developers building tailored websites that require adaptable database structures.
* Content teams who want a clean, distraction-free editing dashboard.

### Key features
* Polymorphic node system that adapts to any type of digital service or page layout.
* Independent theming engine allowing multiple visual designs for the same content official project page.
* Elegant and user-friendly back-office administration panel.
* Open-source code released under the permissive MIT license for personal and commercial projects.
* Extensive online documentation and developer guides to help set up projects quickly.

### How to install (Download)
* Visit the official website to explore documentation and guides: [Roadiz Website](https://www.roadiz.io)
* Review the getting started instructions in the official docs: [Roadiz Installation Guide](http://docs.roadiz.io/en/latest/developer/first-steps/installation.html)
* Set up a new project using the standard edition package: [Roadiz Standard Edition Source](https://github.com/roadiz/standard-edition)

### Pros and Cons
* **Pros:** Free and open-source under the MIT license, highly adaptable content structure, clean design.
* **Cons:** Legacy version 1.x is no longer maintained (newer versions available), requires technical familiarity with PHP environments.
