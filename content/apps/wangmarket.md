### What it does in plain English
Wangmarket is a complete cloud website builder that lets you host and manage thousands of independent websites from a single control panel. It uses flexible templates and a streamlined workflow so you can set up professional sites in under a minute without heavy technical overhead. The software runs smoothly on basic, low-cost server hardware while keeping all your website data securely under your own control.

### Who it's for
* Web design agencies looking to scale their client website operations efficiently without high server costs.
* Freelancers who want a fast, repeatable system to deliver client websites and manage custom templates.
* Small business owners seeking an independent, self-hosted web presence without recurring platform fees.

### Key features
* Multi-site management console to easily launch, freeze, or update dozens of independent websites.
* Highly optimized resource usage that allows thousands of distinct sites to run on a basic server setup.
* Flexible template system using standard HTML for unlimited design customisation.
* Built-in security and site separation tools that protect your core dashboard from malicious traffic.
* Automated daily backups and one-click site transfer options for effortless maintenance.

* **Pros:** Extremely low server resource requirements, flexible HTML templating, and complete data ownership.
* **Cons:** Advanced customisation and module development require familiarity with Java.
