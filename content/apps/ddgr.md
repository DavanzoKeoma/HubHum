### What it does in plain English
`ddgr` lets you perform web searches on DuckDuckGo directly from your command-line environment without opening a web browser. It features a clean, space-saving text interface designed for fast reading and low resource usage. You can easily view instant answers, navigate through results, and even route your searches securely over the Tor network.

### Who it's for
* Terminal power users and developers who prefer staying inside a text shell.
* Privacy-conscious individuals looking to avoid heavy web browsers for quick lookups.
* System administrators managing servers or lightweight environments without graphical user interfaces.

### Key features
* Fast and lightweight text interface optimized for minimum screen space.
* Direct support for DuckDuckGo Bangs and instant answers.
* Ability to customize the number of results shown per page.
* Seamless integration with text-based web browsers or custom url handlers.
* Privacy-focused design with default Do Not Track headers and Tor compatibility.

### How to install (Download)
You can install `ddgr` using popular package managers or directly from the official source page. Visit the [Official Releases Page](https://github.com/jarun/ddgr/releases) to download the latest stable version or check packaging instructions.

### Pros and Cons
* **Pros:** Free and open source, lightweight with minimal dependencies, excellent privacy focus.
* **Cons:** Requires familiarity with text terminals and command-line usage.
