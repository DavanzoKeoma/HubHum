### All Qualifying Software in This Topic

- **[Sherlock](/HubHum/apps/sherlock/)** — Easily discover where a specific username is registered across hundreds of online platforms and social networks in seconds. *(CLI Tool · License: Open Source (MIT))*
- **[Mole](/HubHum/apps/mole/)** — Mole is an open-source system cleaner that removes junk files, uninstalls applications completely, and monitors system performance. *(Desktop App · License: Open Source (GPL v3))*
- **[Win11Debloat](/HubHum/apps/win11debloat/)** — Remove unwanted pre-installed apps, block background tracking, and declutter your computer interface in just a few clicks. *(Desktop App · License: Open Source (MIT))*
- **[Maigret](/HubHum/apps/maigret/)** — Maigret gathers online profile information by scanning thousands of public websites using only a username. *(CLI Tool · License: Open Source (MIT))*
- **[PentAGI](/HubHum/apps/pentagi/)** — An autonomous multi-agent system that performs security testing and delivers comprehensive reports based on your plain-language goals. *(Self-Hosted Web App · License: Open Source (MIT))*
- **[Termix](/HubHum/apps/termix/)** — Termix is a flexible, self-hosted platform that lets you organize and control your remote servers, files, and connections from a single dashboard. *(Desktop App · License: Open Source (Apache 2.0))*
- **[Sophia Script for Windows](/HubHum/apps/sophia-script-for-windows/)** — An advanced PowerShell tool helps you customize, clean up, and fine-tune Windows 10 and 11 safely. *(Desktop App · License: Open Source (MIT))*
- **[BleachBit](/HubHum/apps/bleachbit/)** — BleachBit quickly cleans unwanted junk files from your computer to free up valuable storage space and protect your personal privacy. *(Desktop App · License: Open Source (GPL v3))*
- **[SophiApp](/HubHum/apps/sophiapp/)** — SophiApp is a user-friendly tool that lets you customize and optimize your Windows 10 or 11 system using safe, official methods. *(Desktop App · License: Open Source (MIT))*
