### What it does in plain English
ytfzf is a lightweight text-based utility that lets you search and watch video content directly inside your command-line interface. It pulls up interactive menus complete with thumbnails, letting you stream or download your favorite clips instantly. Because it works without requiring account sign-ins or heavy web browsers, it runs smoothly on almost any modest computer setup.

### Who it's for
* Command-line enthusiasts who prefer keeping their keyboard focused on text windows instead of switching to a browser.
* Users with older or lightweight computers who want a fast, distraction-free way to watch online videos.
* Power users looking to automate video downloads and queue up media playlists from scripts.

### Key features
* Search and stream online video content directly inside your terminal interface.
* Optional thumbnail previews displayed right alongside your text menu options.
* Keep track of your watch history, subscriptions, and search terms locally.
* Download single media files or queue up multiple videos for continuous playback.
* Easily customizable with your choice of video players, menu interfaces, and third-party plugins.

### How to install (Download)
To install ytfzf, make sure you have the required prerequisites like `jq` and `curl` installed on your system. Then, open your terminal and run the following commands:

```sh
git clone https://github.com/pystardust/ytfzf
cd ytfzf
sudo make install doc
```

You can also check if your system's package manager provides a ready-to-install package via the [Official Source / Credits](https://github.com/pystardust/ytfzf) page.

### Pros and Cons
* **Pros:** Completely free and open source, very lightweight on system resources, highly customizable.
* **Cons:** Requires familiarity with text command environments, and setup can take a few minutes if you want image thumbnails enabled.
