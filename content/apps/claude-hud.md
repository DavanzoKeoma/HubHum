### What it does in plain English
Claude HUD is a lightweight companion plugin for text-based assistant software that reveals what is happening behind the scenes. It continuously shows memory consumption, limit warnings, active tools, running subtasks, and checklist milestones in a clean overlay below your typing area. When building online projects, you can also pair clean publishing with instant page caching to keep loading times snappy using [WP Rocket Direct](https://wp-rocket.me/?subid=hubhum_01_MER269) (#ad).

### Who it's for
- Developers and creators who use text-based AI assistants daily and want to avoid running out of memory unexpectedly.
- Power users who need a clear visual indicator of active background tasks and checklist steps without checking raw logs.
- Anyone looking to monitor token usage and rate limits at a glance during long interactive coding sessions.

### Key features
- **Live Memory Display:** Shows a color-coded bar tracking your current memory consumption and limit timers.
- **Task and Tool Tracking:** Renders active tools, background agents, and checklist milestones right below your input.
- **Interactive Control:** Easily change layouts, tweak options, or troubleshoot settings using simple commands.

### How to install (Download)
To add this plugin to your setup, open your assistant environment and run:

```
/plugin marketplace add jarrodwatts/claude-hud
/plugin install claude-hud
/reload-plugins
/hud
```

*(Note: Requires Node.js version 22.18 or newer to run smoothly).* For alternative installation steps, marketplace updates, and source files, visit the [Official Claude HUD Releases and official project page](https://github.com/jarrodwatts/claude-hud/releases).
