### What it does in plain English
XPopup gives mobile app creators a complete system for showing dialogs, menus, image viewers, and bottom sheets without the usual headaches. It handles complex layout positioning, smooth gesture dragging, and smart keyboard adjustments automatically. You can choose from dozens of built-in animations or design your own custom visual styles with minimal effort.

### Who it's for
* Android application developers looking to replace rigid system dialogs with polished, modern popups.
* Mobile designers who want consistent, butter-smooth transition animations across all phone screens.
* Anyone building apps that need image zooming, bottom comment sheets, or dropdown selection menus.

### Key features
* Replaces standard dialogs, menus, bottom sheets, and spinners with unified, elegant components.
* Includes dozens of professionally crafted entrance and exit animations that follow modern design guidelines.
* Automatically cleans up resources and lifecycle listeners to prevent memory leaks and lagging.
* Adapts seamlessly to notched displays, punch-hole screens, and full-screen aspect ratios.
* Built-in photo viewer handles ultra-long images smoothly without running out of device memory.

### How to install (Download)
To add XPopup to your mobile project, include the JitPack official project page and dependency code in your build configuration as shown on the [Official GitHub Releases & Setup Page](https://github.com/junixapp/XPopup/releases). You can also scan the QR code or check out the demo preview directly from the official official project page.

### Pros and Cons
* **Pros:** Free and open source, highly customizable, smooth animations, zero memory leaks.
* **Cons:** Requires a modern minimum SDK version and basic familiarity with mobile app development tools.
