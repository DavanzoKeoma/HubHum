### What it does in plain English
reactjs101 is a step‑by‑step book that shows how to build interactive web pages using React.  
It uses simple Chinese explanations and real code samples so anyone can follow along.  
By the end, readers can create their own small apps and understand how the React ecosystem works.

### Who it's for
* Beginners who know a little HTML, CSS and JavaScript and want to start building modern web interfaces.  
* Chinese‑speaking students or hobbyists looking for a clear, example‑driven learning path.  
* Self‑learners who prefer reading a structured guide rather than watching videos.

### Key features
- Clear, illustrated explanations written in everyday Chinese.  
- Step‑by‑step code examples that you can copy and run immediately.  
- Covers core concepts such as components, state, routing, and data handling.  
- Includes extra chapters on mobile apps with React Native and on testing.  
- Provides reference tables that compare older and newer JavaScript syntax.

### How to install (Download)
- **Read online:** [reactjs101 on GitBook](https://www.gitbook.com/book/kdchang/react101/details) – the full book is available for free in the browser.  

### Pros and Cons
* **Pros:** completely free, written in Chinese, covers a wide range of React topics, includes practical projects.  
* **Cons:** only available in Chinese, no interactive exercises, assumes basic HTML/CSS/JS knowledge.
