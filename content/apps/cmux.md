### What it does in plain English
cmux is a high-performance terminal created specifically for developers who juggle multiple coding assistants at the same time. It organizes your work sessions with a clean sidebar, vertical tabs, and instant visual alerts whenever an assistant needs your attention.

### Who it's for
* Software developers who run multiple automated coding agents in parallel and need a clear overview.
* Mac power users looking for a lightning-fast terminal that supports split views and built-in browser panels.
* Engineering teams wanting to streamline multi-model workflows without messy configuration files.

### Key features
* **Visual notification rings:** Panes and tabs light up instantly so you never miss when a background coding helper needs input.
* **Vertical and horizontal splits:** Easily organize multiple directories, git statuses, and listening ports in a single view.
* **Built-in browser:** Run a companion browser pane right next to your code workspace to test web applications immediately.
* **Session restore:** Automatically reopens your exact window layout, working folders, and scroll history when launched again.
