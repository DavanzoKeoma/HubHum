### What it does in plain English
Diagon is a handy tool that converts everyday text and mathematical expressions into neat character-based drawings. Whether you need to visualize a complex formula, map out a project tree, or sketch a sequence flow, it creates clean illustrations automatically. You can use it right in your web browser, via command-line tools, or integrated directly into your favorite text editor.

### Who it's for
* Software developers creating clear documentation and code comments
* Students and teachers formatting mathematical equations for notes
* Technical writers mapping out system structures and process flows

### Key features
* Interactive web tool to preview diagrams instantly as you type
* Support for math equations, sequence diagrams, directory trees, and tables
* Command-line interface for quick terminal conversions and scripting
* Integrates directly into popular text editors and development environments
* Lightweight code that runs smoothly without heavy software installation
