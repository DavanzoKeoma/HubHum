### What it does in plain English
oMLX lets you run powerful artificial intelligence models locally on your Apple Silicon Mac without needing technical command-line tools. It features a convenient menu bar controller and web dashboard to manage multiple models, chat with documents, and process text or images. Your previous conversations stay cached efficiently in memory or on your disk so responses load instantly without recomputing every time.

### Who it's for
* Everyday computer users who want to run private AI models on their Mac without sending personal data to the cloud.
* Developers and writers looking for a fast, local alternative to commercial AI assistants that integrates smoothly with coding apps.
* Privacy-conscious individuals who need an offline-capable tool for handling sensitive documents, images, and text.

### Key features
* Managed completely from a lightweight macOS menu bar app with an intuitive web control panel.
* Supports text models, vision models for analyzing images, audio transcription, and document attachments.
* Intelligent dual-tier caching keeps frequently used context in fast memory while saving older data to your disk.
* Easy one-click setup for connecting popular coding assistants and developer workflows.
* Built-in performance testing to check generation speed and system resource usage.
