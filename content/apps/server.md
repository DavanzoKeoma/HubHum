### What it does in plain English
Gotify Server provides a private hub for sending and receiving push messages in real time. It runs on your own hardware so you retain complete control over your notifications and data. You can easily connect various applications and devices to forward alerts the moment they happen.

### Who it's for
* Home server enthusiasts wanting private notification control
* Developers needing a reliable push alert handler for apps
* Anyone tired of relying on closed third-party notification networks

### Key features
* Real-time message delivery over live web connections
* Simple web dashboard to manage users, clients, and apps
* Extensible plugin architecture for custom behaviors
* Companion mobile apps for viewing alerts on the go
* Command-line tool support for quick notification sending

### How to install (Download)
You can set up and run this service easily using Docker or by visiting the official setup guide. Get started by checking out the [Gotify Installation Guide](https://gotify.net/docs/install) and exploring the [Gotify Website](https://gotify.net).

### Pros and Cons
* **Pros:** Completely self-hosted, lightweight footprint, open-source and free, includes real-time web interface.
* **Cons:** Requires basic server setup knowledge, manual configuration needed for external access.
