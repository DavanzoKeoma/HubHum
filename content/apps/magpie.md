### What it does in plain English
Magpie takes any window or application running on your Windows desktop and enlarges it to fill your screen using sophisticated visual filters. Instead of looking stretched or blurry, older software and games receive a crisp graphical boost in real time. It operates quietly in the background, letting you enjoy high-definition scaling without modifying the original program files.

### Who it's for
* PC gamers who want to play classic or older titles in modern resolutions without visual distortion.
* Retro enthusiasts running vintage desktop tools that lack native high-resolution support.
* Everyday users looking to upscale video players or productivity windows effortlessly.

### Key features
* Applies advanced scaling filters and algorithms like Anime4K and FidelityFX FSR to any window.
* Works seamlessly in both fullscreen and custom windowed display modes.
* Features a clean, modern user interface built natively for Windows 10 and 11.
* Fully supports multi-monitor setups and various display aspect ratios.
* Includes light and dark themes to match your personal Windows desktop preference.

### How to install (Download)
You can download the latest setup files and releases directly from the [Official Releases Page](https://github.com/Blinue/Magpie/releases). Ensure your system runs Windows 10 version 1903 or newer with a DirectX 11 compatible graphics card.

### Pros and Cons
* **Pros:** Free and open-source, supports powerful custom shaders, lightweight resource usage.
* **Cons:** Requires Windows 10 or 11, some older games may need minor compatibility tweaking.
