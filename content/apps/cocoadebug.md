### What it does in plain English
CocoaDebug is a handy diagnostic companion built specifically for iOS applications. It adds a floating, interactive overlay directly onto your mobile app screen to reveal network requests, system logs, app crashes, and storage folders in real time. Developers and testers can quickly catch errors, search through console outputs, and inspect web views without needing to plug the device into a computer.

### Who it's for
* Mobile app developers building and testing software for iOS devices
* Quality assurance testers looking to catch network errors and app crashes on the fly
* Designers and project managers verifying web view performance and application behavior during live demos

### Key features
* Floating interface overlay that can be shown or hidden with a simple device shake
* Comprehensive network traffic inspection supporting JSON and protocol buffers
* Real-time search and filtering for console logs, crash reports, and system messages
* Built-in sandbox file explorer to easily preview and edit local app storage
* Support for monitoring WKWebView consoles and React Native JavaScript logs

### How to install (Download)
You can integrate this diagnostic tool into your project using package managers like CocoaPods or Carthage, or by downloading the software foundation directly. 

* [Official Integration Guide and Setup Documentation](https://github.com/CocoaDebug/CocoaDebug/wiki/Integration-Guide)
* [Download CocoaDebug software foundation (.zip)](https://raw.githubusercontent.com/CocoaDebug/CocoaDebug/master/CocoaDebug.framework.zip)

### Pros and Cons
* **Pros:** Free and open-source, displays live telemetry directly on the device screen, requires minimal setup.
* **Cons:** Must be carefully excluded from production builds before publishing to app stores, requires basic knowledge of iOS project configuration.
