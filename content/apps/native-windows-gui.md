### What it does in plain English
Native Windows GUI is a lightweight toolkit designed for software developers building native desktop programs for Microsoft Windows. It wraps around standard operating system controls to give you a simple, safe programming interface without heavy bloat. Your final programs launch instantly, use very little memory, and start up quickly on any standard computer.

### Who it's for
* Software developers who want to write fast Windows desktop applications using the Rust language.
* Programmers looking to avoid heavy user interface toolkits in favor of lightweight native controls.
* Creators who need straightforward layouts, standard buttons, dialogs, and menus without complex setup procedures.

### Key features
* Built as a lightweight wrapper over standard Windows controls for smooth performance.
* Supports common interface elements like menus, tooltips, dialog boxes, and system tray icons.
* Handles multiple threads easily so your interface stays responsive during heavy background tasks.
* Includes simple layout tools like grid and flexbox arrangements to organize screen elements.
* Low memory footprint and instant launch times on target machines.

### How to install (Download)
To use this toolkit in your project, add it to your cargo configuration file as shown on the [Official Project Page](https://gabdube.github.io/native-windows-gui/). You can also explore the source code, examples, and documentation directly from the [Official Source / Credits](https://github.com/gabdube/native-windows-gui).

### Pros and Cons
* **Pros:** Free forever under an open-source license, exceptionally lightweight, minimal memory footprint, and very fast startup times.
* **Cons:** Requires familiarity with the Rust programming language and is built specifically for Microsoft Windows desktops.
