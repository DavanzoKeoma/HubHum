### What it does in plain English
Amethyst is a handy utility for Mac users that automatically arranges and snaps open application windows into clean, grid-like layouts. Instead of manually resizing and dragging windows across your desktop, the software handles the positioning for you in the background. You can quickly cycle through different arrangements, swap windows between displays, or resize panes using simple keyboard shortcuts.

### Who it's for
* Power users and developers who rely entirely on keyboard shortcuts to navigate their desktop.
* Multitaskers juggling dozens of open applications across multiple monitors.
* Anyone who wants a tidier workspace on macOS without spending time manually snapping windows into place.

### Key features
* Automatically tiles open windows into organized grid layouts as soon as they appear.
* Offers multiple layout styles including tall columns, wide rows, full screen, and floating modes.
* Enables fast navigation and window swapping using straightforward keyboard commands.
* Supports multi-monitor setups so you can move windows between screens instantly.
* Fully customizable configuration options using a simple text settings file.

### How to install (Download)
You can download the application directly from the [Official Releases Page](https://github.com/ianyh/Amethyst/releases) or visit the [Official Website](https://ianyh.com/amethyst/). If you use Homebrew on your Mac, you can also install it via terminal using `brew install --cask amethyst`.

### Pros and Cons
* **Pros:** Free and open source forever, highly customizable layouts, robust keyboard control.
* **Cons:** Requires accessibility permissions in macOS to function properly, takes a short while to learn the keyboard shortcuts.
