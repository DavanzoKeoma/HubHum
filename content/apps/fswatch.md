### What it does in plain English
fswatch is a helpful utility that watches your files and folders and immediately alerts you whenever anything changes inside them. Instead of constantly checking your hard drive to see if a document was edited, the application lets your computer do the heavy lifting by listening directly to system notifications. It seamlessly adapts to your operating system to provide instant updates with minimal computer strain.

### Who it's for
* Software developers who want to automatically trigger tasks or tests whenever source code files are saved.
* System administrators tracking configuration file updates across servers in real time.
* Power users creating custom automation workflows for file processing and backup routines.

### Key features
* Real-time notification support leveraging native operating system monitoring subsystems.
* Recursive directory tracking to monitor entire folder trees down to any depth.
* Flexible regular expression filters to include or exclude specific file patterns.
* Customizable output formats that integrate smoothly with scripts and external automation tools.
* Low resource overhead designed to run quietly in the background without draining system memory.

### How to install (Download)
* macOS (via MacPorts): Run `port install fswatch` in your terminal.
* macOS (via Homebrew): Run `brew install fswatch` in your terminal.
* FreeBSD (via pkg): Run `pkg install fswatch-mon` in your terminal.
* Official Documentation: [Download PDF Manual (fswatch-1.22.0.pdf)](https://github.com/emcrisostomo/fswatch/releases/download/1.22.0/fswatch-1.22.0.pdf)

### Pros and Cons
* **Pros:** Free and open-source, supports multiple operating systems, highly customizable output formatting.
* **Cons:** Advanced command-line usage requires basic terminal familiarity, specific limitations apply depending on the underlying operating system watcher backend.
