### What it does in plain English
Walle solves the tedious problem of creating separate versions of an Android application for different app stores or distribution channels. Instead of rebuilding the entire project from scratch for every single store, it injects unique store identifiers directly into the signed application file in milliseconds. This makes preparing updates for dozens of marketplaces effortless and lightning-fast.

### Who it's for
* Android developers managing multi-store releases
* Mobile app growth marketers tracking download campaigns
* Quality assurance engineers verifying build variants

### Key features
* Blazing fast creation of multiple distribution packages without slow full rebuilds
* Seamless integration with project build tools for automated workflows
* Flexible command-line utility for custom scripting needs
* Support for embedding custom metadata alongside store identifiers
* Compatible with modern signature verification standards

### How to install (Download)
