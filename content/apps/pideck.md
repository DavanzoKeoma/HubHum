### What it does in plain English
PiDeck is an open-source desktop application that brings your artificial intelligence coding chats and project files together in one neat workspace. It allows you to run multiple local coding assistant sessions simultaneously without mixing up your projects. You can easily view past conversations, organize project files, and adjust your AI settings through a simple visual interface.

### Who it's for
* Developers and creators who juggle multiple local software coding projects simultaneously.
* Users who want a clean desktop window to monitor their AI assistant chat histories and project updates.
* Anyone looking for a visual way to configure and test their connection settings without editing raw code files.

### Key features
* **Multi-Project Workspaces:** Switch between different local folders easily while keeping your working environments completely separate.
* **Unified Chat Management:** Browse previous chat sessions, import conversation histories, and export your dialogues when needed.
* **Built-in Tools:** Access your file tree, review code changes, and open an integrated terminal without leaving the app.
* **Visual Settings:** Manage your preferences, model configurations, and connection testing through straightforward menus.
* **Cross-Platform Compatibility:** Run smoothly on your preferred desktop operating system with native window integration.
