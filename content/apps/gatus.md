### What it does in plain English
Gatus acts as a digital watchdog that constantly checks if your websites, servers, and online tools are running as expected. Instead of waiting for users to report errors, it proactively tests your services and notifies you the moment something goes wrong.

### Who it's for
*   **Website Owners:** People who need to know instantly if their site or online store is offline.
*   **System Administrators:** Professionals who want to monitor the health of multiple internal services from a single, easy-to-read dashboard.

### Key features
*   **Flexible Health Checks:** Monitor your services using various methods like checking website responses, connection speeds, or even domain expiration dates.
*   **Instant Alerts:** Connect the app to your favorite communication tools like Discord, Slack, or Email to receive notifications when a service fails.
*   **Visual Dashboard:** View the status of all your monitored services in a clean, dark-mode-ready interface.
*   **Automated Testing:** Use the tool to run automated checks that ensure your site's features are working exactly as they should.

### How to install (Download)
Gatus is designed to run as a lightweight service. You can get it running quickly using Docker:

*   **Using Docker:** Run the following command in your terminal:
    `docker run -p 8080:8080 --name gatus ghcr.io/twin/gatus:stable`

### Pros and Cons
*   **Pros:** Very low resource usage, highly customizable health conditions, and supports a massive list of notification services.
*   **Cons:** Requires a basic configuration file to set up your monitoring targets, which may take a few minutes to learn.
