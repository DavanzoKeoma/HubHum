### What it does in plain English
CPM.cmake acts as a helper tool that automatically fetches and organizes the extra files or libraries your project needs to function. Instead of manually downloading and tracking these items, you simply list them in your project settings and the script handles the rest. It ensures that your project always uses the correct versions of these resources, making your work more reliable and easier to share.

### Who it's for
* Software developers who want to simplify how they include external libraries in their projects.
* Students or hobbyists looking for a straightforward way to manage project dependencies without learning complex professional tools.

### Key features
* **No installation required:** Simply add the script to your project folder to start using it immediately.
* **Automatic version control:** Keeps track of specific versions of your resources to ensure your project always builds correctly.
* **Cross-platform compatibility:** Works consistently across different operating systems and computer setups.
* **Offline support:** Allows you to cache your resources so you can continue working even without an active internet connection.

### How to install (Download)
You can add this tool to your project by downloading the script directly into your project's `cmake` directory:
* [Download CPM.cmake](https://github.com/cpm-cmake/CPM.cmake/releases/download/v0.43.2/CPM.cmake)
* [Download get_cpm.cmake](https://github.com/cpm-cmake/CPM.cmake/releases/download/v0.43.2/get_cpm.cmake)

### Pros and Cons
* **Pros:** Completely free and open-source, no subscription required, and extremely lightweight.
* **Cons:** Requires a basic understanding of your project's configuration files to set up initially.
