### What it does in plain English
StatusBarUtil helps Android apps change the status bar’s color and transparency.  
It works on devices running Android 4.4 and newer.  
Developers can switch between light and dark status bar icons with a single call.

### Who it's for
- Android app developers looking for quick UI tweaks  
- UI designers who want consistent status bar styling  
- Developers maintaining legacy apps needing modern status bar support

### Key features
- Set a custom status bar color  
- Make the status bar translucent or fully transparent  
- Switch between light and dark icon modes  
- Support for DrawerLayout and swipe‑back pages  
- Easy integration with a single library

### How to install (Download)
Add the library to your project by including the dependency:  
`compile 'com.jaeger.statusbarutil:library:1.5.1'`  
Download the library artifact:  
[Download for Android (.jar)](https://t.cn/Rq746Kb)  
View the source code and documentation:  
[Official GitHub official project page](https://github.com/houzi3/StatusBarUtil)

### Pros and Cons
* **Pros:** free forever, no subscription, simple to use  
* **Cons:** requires Android API 19+, some advanced features need extra XML settings
