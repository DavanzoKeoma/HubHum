### What it does in plain English
Trail-Code creates a smart map of your project files and functions, helping coding assistants understand exactly where to find the code they need. It also keeps track of what your team has learned and decided, ensuring that agents don't repeat past mistakes or undo previous work. By providing this shared memory, it allows your tools to solve complex tasks much faster and with fewer errors.

### Who it's for
* Software developers who use AI coding assistants and want them to be more reliable.
* Engineering teams looking to reduce the time spent re-explaining project rules to their AI tools.

### Key features
* **Code Mapping:** Automatically builds a clear map of your files and how they connect, so agents stop guessing where code is located.
* **Team Memory:** Saves lessons and decisions directly into your project, so every teammate's AI agent starts with the same knowledge.
* **Smart Checks:** Warns you before you update changes if they conflict with previous team decisions.
* **Works Locally:** Keeps your project data on your machine, ensuring your code and team learnings remain private.
* **Universal Compatibility:** Works with popular coding assistants like Claude Code, Cursor, and others.

### How to install (Download)
Trail-Code is installed via the command line. Ensure you have [Node.js](https://nodejs.org) installed, then run the following command in your terminal:

`npm install -g @trailhq/trail-code`

After installation, navigate to your project folder and run `trail init` to set up the map and connect your agents.

### Pros and Cons
* **Pros:** Significantly reduces time and costs for AI tasks, keeps team knowledge synced via git, and requires no external servers.
* **Cons:** Requires a quick initial setup for each project and works best when your team updates the configuration files.
