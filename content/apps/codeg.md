### What it does in plain English
Codeg gathers all your favorite artificial intelligence programming tools into one friendly, organized desktop window instead of messy command-line screens. You can chat with multiple digital assistants at the same time, delegate tasks between them, and watch live previews of their work.

### Who it's for
* Software developers and hobbyists who use multiple artificial intelligence coding assistants and want to manage them from one central dashboard.
* Freelancers who need to organize project files, review live code changes, and automate routine tasks without juggling separate windows.

### Key features
* **One unified interface:** Combine twenty built-in assistants and custom options into a rich chat format complete with interactive buttons and live code comparisons.
* **Searchable sessions:** Easily import, search, and resume past chat histories so you never lose track of a helpful conversation.
* **Smart delegation:** Mention assistants using simple tags to hand off tasks, run them side by side, or schedule unattended background work.
* **Infinite canvas and tools:** Arrange chats, files, and notes freely on a flexible board while keeping track of token usage and project health.

* **Pros:** Brings multiple artificial intelligence coding tools together; local-first design keeps your data private; supports desktop, mobile, and server setups.
* **Cons:** Requires familiarity with coding workflows; setting up multiple distinct assistant accounts takes a few initial steps.
