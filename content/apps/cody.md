### What it does in plain English
Cody is a website content management tool built for JavaScript environments. It gives you a clean visual dashboard to organize your site layout, edit text, and manage user permissions without getting lost in complicated settings. It integrates smoothly into your existing projects to streamline daily publishing tasks.

### Who it's for
* Web designers looking for a straightforward way to manage site structures.
* Content creators who want to update pages using a visual editor.
* Developers wanting a lightweight backend system running on Node.js.

### Key features
* Visual page editor allowing non-technical users to update text and layouts.
* Tree-structured menu system for organizing pages and templates easily.
* Built-in file and user management right from your web dashboard.
* Flexible configuration options through simple files or environment settings.
