### What it does in plain English
Mem Reduct is a small tool that watches how much memory your computer is using while you work. When your system starts to slow down, it clears out unnecessary temporary files from your memory to free up space. This helps your computer stay fast and responsive without needing a restart.

### Who it's for
*   Users with older computers that have limited memory.
*   People who run multiple heavy programs at the same time and notice their system slowing down.

### Key features
*   **Real-time monitoring:** Keeps a constant eye on your memory usage with a simple display.
*   **Automatic cleaning:** Can be set to clear memory automatically when usage reaches a certain level.
*   **Lightweight design:** Uses very few system resources itself, so it won't slow you down.
*   **Customizable settings:** Allows you to choose exactly which parts of the system memory to clean.
