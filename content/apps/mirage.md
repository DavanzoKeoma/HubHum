### What it does in plain English
Mirage acts as a bridge between AI agents and the various digital tools they need to perform tasks. It creates a unified virtual workspace where an agent can access files, run commands, and use software as if everything were located on a single, local computer. This allows agents to work efficiently across different storage services, cloud platforms, and computing environments without needing complex custom setups for each one.

### Who it's for
* **Software developers** building custom AI agents that need to interact with real-world data and services.
* **Automation enthusiasts** who want to create secure, controlled environments for their digital assistants to perform repetitive tasks.

### Key features
* **Unified Workspace:** Combines multiple storage services like Google Drive, Slack, and S3 into one simple file system that agents can easily navigate.
* **Virtual Tools:** Provides "virtual" versions of common command-line tools, allowing agents to perform actions without needing the actual software installed.
* **Custom Security Profiles:** Allows you to define exactly which files, commands, and tools an agent can access, keeping your sensitive data safe.
* **Flexible Computing:** Automatically routes tasks to the most appropriate machine or environment, whether it is a local process or a remote cloud server.
* **Lightweight Design:** Uses very little memory, making it easy to run inside web browsers, mobile apps, or small edge devices.

### How to install (Download)
Mirage is a library designed for integration into your projects. You can install it using standard package managers:

* **For Python:** Use `uv add mirage-ai` to install the library and command-line tools.
* **For TypeScript:** Use `npm install @struktoai/mirage-node` for server-side projects or `@struktoai/mirage-browser` for web-based environments.
* **For the CLI:** You can run it directly using `npx @struktoai/mirage-cli` or install it globally via your preferred package manager.

For detailed setup instructions, visit the [Official Documentation](https://docs.mirage.strukto.ai).

### Pros and Cons
* **Pros:** Extremely flexible, highly secure with granular permissions, and works across almost any infrastructure.
* **Cons:** Requires some initial configuration to set up specific policies and connections for your agents.
