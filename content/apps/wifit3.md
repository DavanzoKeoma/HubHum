### What it does in plain English
wifit3 allows you to scan and audit the security of wireless networks by connecting a compatible USB Wi-Fi adapter to your computer. It works by bypassing your computer's standard software to communicate directly with the hardware, allowing for advanced network testing. The app helps you identify potential weaknesses in your own network setup and manage security data in one place.

### Who it's for
* Network administrators and security enthusiasts who need to audit their own home or office wireless environments.
* Users who want a consistent, easy-to-use tool for network analysis that works the same way on Windows, Linux, and macOS.

### Key features
* **Cross-Platform Support:** Works identically on Windows, Linux, and macOS without needing complex system changes.
* **Hardware-Focused Analysis:** Uses dedicated USB adapters to scan and monitor networks, providing detailed information about signal strength and security settings.
* **Built-in Security Tools:** Includes features to test for common network vulnerabilities, such as password recovery and connection strength checks.
* **Centralized Data Vault:** Keeps track of all your network captures, saved passwords, and security findings in a single, organized dashboard.
* **No Extra Software Needed:** Runs as a standalone program without requiring you to install additional background services or complex system drivers.
