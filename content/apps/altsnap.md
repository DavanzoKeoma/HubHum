### What it does in plain English
AltSnap is a lightweight desktop utility that lets you move and resize any open window by holding down the Alt key and clicking anywhere on it. Instead of hunting for tiny window borders or the exact title bar, you can grab and reposition windows from any spot. It is a modernized, bug-fixed continuation of the classic AltDrag tool, designed to run smoothly on Windows without tampering with your system apps.

### Who it's for
* Power users and multitaskers who juggle dozens of open windows and want faster screen organization.
* Linux converts who miss the ability to drag windows from anywhere on the screen.
* Anyone looking for a lightweight, straightforward way to speed up everyday window management.

### Key features
* **Anywhere Dragging:** Hold the Alt key and click anywhere inside a window to drag it across your screen.
* **Quick Resizing:** Easily resize windows by holding Alt and using secondary mouse clicks.
* **Transparent Dragging:** Make windows semi-transparent while you move them for better visibility of background content.
* **Advanced Controls:** Fine-tune behavior, add application blacklists, and adjust options through a simple tray menu and configuration file.
* **Zero App Injection:** Operates safely without injecting code into other applications, avoiding common security risks and architecture conflicts.
