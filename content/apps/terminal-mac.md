### What it does in plain English
This tool lets you run a fully functional macOS virtual machine on your Apple Silicon computer while viewing and controlling it directly from your terminal. It creates an isolated desktop environment with its own apps, files, and settings without touching your main computer workspace. Artificial intelligence assistants and automated tools can interact with this separate environment safely using simple commands.

### Who it's for
* Developers and power users who want a sandboxed macOS environment for testing or running automated tasks.
* AI assistant users who want to grant computer-use capabilities to helpers in a completely isolated virtual space.
* Anyone looking to run a separate copy of macOS on Apple Silicon without risking their primary operating system files.

### Key features
* Runs a real macOS guest operating system completely inside supported terminal programs like Kitty or iTerm2.
* Provides dedicated control tools for automated scripts and assistants to click, type, and capture screens safely.
* Maintains strict isolation from your host desktop, keeping your main clipboard, files, and personal applications untouched.
* Supports high-resolution Retina displays so text remains crystal clear inside your command-line window.
* Includes simple lifecycle commands to start, pause, resume, or stop your virtual machine instantly.

* **Pros:** Complete isolation from your main operating system, excellent terminal graphics performance, and seamless automation support.
* **Cons:** Requires an Apple Silicon Mac, and initial setup involves downloading a large macOS system restore image.
