### What it does in plain English
Orchard provides a smooth, native Mac interface for managing containers, virtual machines, and local artificial intelligence tools. It replaces heavy background tools with a lightweight control center built specifically to harness Apple's native system architecture. You can easily oversee running environments, start local AI models, and inspect system resources without ever touching complex terminal commands.

### Who it's for
* Software developers and engineers running local container stacks on Apple silicon Mac computers.
* AI researchers experimenting with local model servers and isolated testing sandboxes.
* System administrators who want a clean, lightning-fast desktop companion for container management.

### Key features
* Lightning-fast native design written completely in Swift for maximum performance on macOS.
* Integrated local AI model discovery and bridge configuration for testing artificial intelligence safely.
* Persistent virtual machine creation and monitoring using native system tools.
* Multi-container log viewer featuring split panes, text filtering, and color-coded streams.
* Convenient command palette for instant fuzzy searching across every active resource.

### How to install (Download)
You can install Orchard using Homebrew by running `brew install orchard` in your terminal, or you can download the application directly.
* [Download for Mac (.dmg)](https://github.com/andrew-waters/orchard/releases/download/v2.7.1/Orchard-2.7.1.dmg)

### Pros and Cons
* **Pros:** Free and open-source, built completely natively with no heavy background tools required, and signed securely for macOS.
* **Cons:** Requires a modern Mac running recent macOS versions and specific container tooling pre-installed.
