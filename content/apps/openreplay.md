### What it does in plain English
OpenReplay is a tool that records how people interact with your website so you can see exactly what they see. It helps you identify where users get stuck or encounter errors, allowing you to fix issues with full context. Because you host it yourself, all your data stays private and under your complete control.

### Who it's for
* **Product Managers** who want to see how users navigate their site to improve design and usability.
* **Support Teams** who need to see exactly what happened on a user's screen to resolve technical issues faster.

### Key features
* **Session Replay:** Watch high-fidelity recordings of user activity to spot navigation struggles or technical errors.
* **Technical Debugging:** View console logs, network activity, and performance metrics alongside recordings to find the root cause of bugs.
* **Product Analytics:** Track user journeys and conversion funnels to see where people drop off in your application.
* **Live Assistance:** Use the built-in co-browsing feature to help users in real-time without needing extra software.
* **Privacy Controls:** Automatically mask sensitive information like passwords or personal data before it is ever saved.

### How to install (Download)
OpenReplay is designed to be hosted on your own server or cloud infrastructure. You can get started by following the official cloud setup guides:
* [Official Getting Started Guide](https://docs.openreplay.com/en/getting-started/)
* [Download Desktop MCP Utility (.mcpb)](https://github.com/openreplay/openreplay/releases/download/v1.28.0/openreplay-mcp-desktop.mcpb)

### Pros and Cons
* **Pros:** Keeps all your data on your own servers, highly detailed debugging information, and excellent privacy features.
* **Cons:** Requires some technical knowledge to set up and maintain on your own infrastructure.
