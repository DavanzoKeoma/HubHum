### What it does in plain English
Procs provides an upgraded way to inspect running software and system activity on your computer. It presents information using clear colors, structured tables, and automatic formatting that makes it simple to understand what is using your hardware. You can search by names, numbers, or network ports, view tasks in a parent-child tree layout, and watch resource usage update live on your screen.

### Who it's for
* System administrators and developers who want clearer insights into active software tasks.
* Everyday power users looking for a more readable and colourful alternative to standard task lists.
* Troubleshooting technicians who need to quickly identify which background task or network port is causing trouble.

### Key features
* Human-readable and color-coded text output with automatic theme detection.
* Multi-column keyword search to find specific software tasks instantly.
* Live watch mode that updates performance data dynamically like a traditional live monitor.
* Tree view mode to visualize how tasks and background services branch out from one another.
* Extra details including active network ports, storage read and write speeds, and container names.

### Pros and Cons
* **Pros:** Free and open-source, highly customizable display options, works across multiple operating systems.
* **Cons:** Advanced filtering options require learning a few short command terms, some detailed hardware statistics require administrator permissions to view.
