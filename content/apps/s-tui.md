### What it does in plain English
s-tui allows you to watch how hard your computer is working by displaying live graphs of your processor's temperature and speed. It includes a built-in stress test that lets you see how your system handles heavy workloads or if it slows down due to overheating. Because it runs directly in your terminal, it is lightweight and does not require a complex graphical interface to function.

### Who it's for
* Computer enthusiasts who want to keep an eye on their hardware performance during intensive tasks.
* Users troubleshooting potential overheating issues or performance drops on their desktop or laptop.

### Key features
* Real-time visual graphs for temperature, frequency, and power usage.
* Built-in stress testing tool to push your processor to its limits.
* Clearly highlights when your system is slowing down due to thermal limits.
* Lightweight design that works without needing a heavy desktop environment.
* Highly customizable interface with support for saving your preferred settings.

### How to install (Download)
s-tui is available through most standard system package managers. You can install it by running the appropriate command for your system:

* **Ubuntu / Debian:** `sudo apt install s-tui`
* **Arch Linux / Manjaro:** `sudo pacman -S s-tui`
* **Fedora:** `sudo dnf install s-tui`
* **OpenSUSE:** `sudo zypper install s-tui`
* **General (via Python pip):** `pip install s-tui --user`

### Pros and Cons
* **Pros:** Completely free and open-source, very lightweight, no complex setup required, and works on older hardware like Raspberry Pi.
* **Cons:** Requires basic familiarity with terminal commands, and some advanced power-monitoring features may require administrative permissions.
