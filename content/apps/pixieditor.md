### What it does in plain English
PixiEditor is a free program that lets you draw, edit, and animate 2D images all in one place. It handles everything from detailed pixel art to smooth vector logos and short video clips. You can mix different drawing styles on the same page and save your work in many common file formats.

### Who it's for
* **Game Developers:** Create character sprites and background assets for your video games without needing multiple expensive programs.
* **Graphic Designers:** Design logos, icons, and social media graphics using both precise vector tools and freehand painting brushes.
* **Hobbyists and Students:** Learn digital art and animation techniques with an intuitive interface that is easy to pick up for beginners.

### Key features
* **Three Drawing Modes:** Switch between pixel-perfect tools, soft painting brushes, and precise vector shapes on the same canvas.
* **Animation Timeline:** Create frame-by-frame animations or use a node system to build complex procedural effects.
* **Flexible File Support:** Export your artwork as PNG, JPG, SVG, GIF, or MP4 to share it anywhere.
* **Node-Based Editing:** Customize layers and effects using a visual node graph, allowing for non-destructive editing and creative experimentation.
