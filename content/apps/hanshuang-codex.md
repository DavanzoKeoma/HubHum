### What it does in plain English
Hanshuang Codex provides a clean desktop interface to configure, inject, and manage custom prompts for various popular AI code assistants and development tools. It bundles an offline reverse-engineering toolkit complete with automated setup scripts, skill management, and easy installation or removal options. Users can organize personal memory files and synchronize custom configurations directly on their local machines.

### Who it's for
* Developers and enthusiasts who frequently work with multiple AI code assistants and need a centralized management console.
* Power users looking for an offline toolkit containing reverse-engineering manuals and auxiliary scripts.

### Key features
* Simple desktop interface for installing, uninstalling, or restoring custom AI assistant memory profiles.
* Integrated offline reverse-engineering workspace with bundled tools, manuals, and automated self-checks.
* Skill management panel to view, enable, or disable local code assistant capabilities.
* Portable application package designed for quick cloud setup and straightforward cleanup.
* Built-in support for multiple mainstream development environments and AI platforms.

* **Cons:** Requires basic familiarity with script execution environments on Windows, and documentation is primarily provided in Chinese.
