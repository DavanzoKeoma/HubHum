### What it does in plain English
Atlas acts as a control center for software teams utilizing automated coding assistants. It automatically records every session, matches agent prompts and tool calls directly to actual code changes, and organizes everything on a shared timeline. Teams can review past sessions, comment on specific lines of work, and track overall project activity in one unified workspace.

### Who it's for
* Software engineering teams managing multiple coding assistants in parallel.
* Engineering managers looking to audit AI tool usage, costs, and output quality.
* Developers wanting a unified dashboard to search past agent interactions and share context.

### Key features
* **Multi-Agent Control:** Run different coding assistants side by side in independent tabs.
* **Smart Checkpoints:** Automatically link every agent session to the exact code updates it produced.
* **Shared Team Timeline:** Review teammates' live sessions, leave comments, and collaborate in real time.
* **Usage & Cost Analytics:** Measure token consumption, active hours, and estimated costs per project.
* **On-Device Memory:** Maintain persistent knowledge notes and shared context securely on your local machine.
