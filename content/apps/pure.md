### What it does in plain English
Pure replaces cluttered, slow command line interfaces with a clean and visually pleasing layout. It displays essential information like your current folder, code tracking status, and command execution times only when needed. Everything runs smoothly in the background so your typing never lags or stutters.

### Who it's for
* Software developers and programmers who spend hours working inside the command line daily.
* Terminal power users who want a distraction-free workspace with quick visual indicators.
* Anyone looking to personalize their ZSH shell environment without dealing with heavy themes.

### Key features
* **Minimalist Design:** Displays only the most crucial details while keeping your workspace clean.
* **Code Tracking Integration:** Instantly shows your active branch and whether you have uncommitted changes or pending updates.
* **Smart Performance Indicators:** Automatically reveals how long a command took to run if it exceeds your custom time limit.
* **Asynchronous Checks:** Performs background status checks smoothly so your typing remains fast and responsive.
* **Flexible Customization:** Easily tweak colors, symbols, and extra features using simple configuration settings.

### How to install (Download)
To get started, you will need ZSH and Git installed on your system. You can install Pure using Node.js or Homebrew:

* Install via Node.js by running `npm install --global pure-prompt` in your terminal.
* Install via Homebrew by running `brew install pure` in your terminal.
* Alternatively, you can clone the official project page manually or use your favorite plugin manager such as Oh My Zsh, Prezto, or Zinit. Full configuration steps are available on the [Official Source / Credits](https://github.com/sindresorhus/pure).

### Pros and Cons
* **Pros:** Extremely fast performance, clean layout, highly customizable color and symbol options.
* **Cons:** Requires a modern version of ZSH and Git, manual configuration needed for advanced integrations.
