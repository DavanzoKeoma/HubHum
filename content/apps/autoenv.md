### What it does in plain English
Autoenv watches your terminal movements and instantly runs custom instructions whenever you step inside a specific project folder. It removes the friction of manual setup by turning on dedicated working environments and loading custom variables instantly. When you walk back out of the folder, it can even clean up after you so your workspace stays pristine.

### Who it's for
* Software creators and scriptwriters juggling multiple projects with different setup requirements.
* Power users who want to save keystrokes by automating routine terminal tasks.
* Anyone looking to keep separate project variables neatly isolated without manual switching.

### Key features
* Triggers custom environment commands automatically upon entering a directory.
* Runs clean-up or exit scripts when leaving a directory.
* Supports nested project setups and multi-level folder structures.
* Compatible with popular shell environments like Bash and Zsh.
* Easy configuration options to suit personal terminal workflows.

### How to install (Download)
You can install Autoenv quickly using your favorite package manager or automated installer. 

Install via automated script using cURL:
```sh
curl -#fLo- 'https://raw.githubusercontent.com/hyperupcall/autoenv/main/scripts/install.sh' | sh
```

Or install via Homebrew (recommended for macOS):
```sh
brew install 'autoenv'
```

For manual setup instructions and detailed shell integration steps, visit the [Official Releases and Setup Page](https://github.com/hyperupcall/autoenv/releases).

### Pros and Cons
* **Pros:** Free forever, lightweight, completely eliminates manual setup steps when switching projects.
* **Cons:** Requires a quick one-time shell configuration edit to start working.
