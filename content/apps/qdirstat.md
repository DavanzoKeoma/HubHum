### What it does in plain English
QDirStat scans your computer storage devices to show you exactly which files and folders are taking up all your room. It organizes your data into a clear traditional file list as well as a colorful visual map where bigger blocks mean larger files. When you spot something you no longer need, you can instantly send it straight to the trash or run custom cleanup actions to reclaim your storage.

### Who it's for
* Everyday computer users running low on hard drive space who want to see what is filling up their computer.
* System administrators and power users needing a fast way to track down large log files or forgotten downloads.
* Anyone who prefers clear graphical color maps over guessing where their missing gigabytes went.

### Key features
* Colorful visual storage maps that instantly highlight your largest files and folders.
* Fast file scanning that works across local drives and mounted filesystems.
* Flexible cleanup tools letting you remove unwanted files safely with a couple of clicks.
* Detailed file statistics broken down by file type, age, and size distribution.
* Independent desktop tool that runs smoothly without requiring heavy background services.

### How to install (Download)
You can download ready-made installation packages for various Linux distributions or access source code directly from the [Official Releases Page](https://github.com/shundhammer/qdirstat/releases). macOS users can also find community-maintained builds through projects like the [macOS Binaries official project page](https://github.com/jesusha123/qdirstat-macos).

### Pros and Cons
* **Pros:** Completely free and open source, fast scanning speed, highly customizable views and cleanup rules.
* **Cons:** Advanced cleanup actions require care so you do not accidentally delete important system files.
