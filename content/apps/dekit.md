### What it does in plain English
dekit helps you run, track, and manage all your background software tasks, databases, and servers in one place. It automatically handles task dependencies, restarts crashed services, and keeps everything running even after you close your main window. You can easily oversee your entire setup through a friendly visual interface or simple text commands.

### Who it's for
* Software creators and engineers managing multiple local servers or databases
* System administrators overseeing lightweight production environments
* Power users who want reliable background automation with zero hassle

### Key features
* Simple configuration file to define all project tasks and rules
* Automatic handling of service dependencies, crashes, and restarts
* Interactive visual control panel inside your command terminal
* Built-in scripting capabilities for custom workflows
* Keeps running reliably in the background after closing windows

### How to install (Download)
To install on macOS or Linux, run this command in your terminal:
```sh
curl -fsSL https://dekit.run/install.sh | sh
```
To install on Windows using PowerShell, run:
```powershell
irm https://dekit.run/install.ps1 | iex
```
You can also download the installation script directly via [Download (install.sh)](https://github.com/pvolok/dekit/releases/download/v0.10.3/install.sh) or [Download (install.ps1)](https://github.com/pvolok/dekit/releases/download/v0.10.3/install.ps1).

### Pros and Cons
* **Pros:** Free and open source, lightweight resource usage, handles crashes automatically.
* **Cons:** Requires basic familiarity with command-line environments to set up initial configurations.
