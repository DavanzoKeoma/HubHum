### What it does in plain English
ThePhish is an intelligent assistant designed to help security teams investigate suspicious emails without tedious manual labor. When a suspicious message arrives, it automatically breaks down the email headers and body to extract hidden links, web addresses, file attachments, and sender details. It then runs these clues through powerful security scanning engines to decide whether the email is safe or dangerous, notifying the user and filing reports automatically.

### Who it's for
* Cybersecurity analysts and incident responders looking to speed up email threat triage
* IT administrators responsible for maintaining corporate inbox safety and filtering out scams
* Security operations teams wanting to automate routine phishing investigation steps

### Key features
* Automated extraction of web links, IP addresses, domains, attachments, and file fingerprints
* Real-time progress monitoring dashboard through an interactive web interface
* Seamless integration with popular open-source threat intelligence and incident response platforms
* Customizable whitelisting rules to prevent false alarms on trusted internal domains
* Automated email notifications keeping users informed throughout the analysis lifecycle

### How to install (Download)
To get started, you can set up the application using Docker templates or clone the code to run it locally. Visit the [ThePhish GitHub Releases and Setup Guide](https://github.com/emalderson/ThePhish/releases) for complete installation instructions.

* **Pros:** Free and open-source, automates time-consuming repetitive triage tasks, highly customizable whitelist filters.
