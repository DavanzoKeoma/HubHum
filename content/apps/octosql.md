### What it does in plain English
OctoSQL allows you to look at information stored in many different places, such as spreadsheets or text files, as if they were all part of one organized system. You can use standard search commands to pull specific details, compare data between different files, or perform calculations across multiple sources at once. It is designed to make handling messy or disconnected data much easier for anyone who needs to find answers quickly.

### Who it's for
* Data analysts who need to quickly compare information across different file formats like CSV and JSON.
* Researchers or small business owners who want to combine data from various sources without setting up complex database software.

### Key features
* **Universal Access:** Query common file formats like CSV, JSON, and Parquet directly without needing to import them first.
* **Cross-Source Joins:** Easily link data from a local file with information from a database in a single command.
* **Flexible Output:** View your results in easy-to-read tables or export them to other formats for further work.
* **Extensible:** Use optional plugins to add support for more database types as your needs grow.
* **Smart Filtering:** The tool automatically ignores columns you don't need, making your searches faster and more efficient.

### How to install (Download)
OctoSQL is primarily used through your computer's command terminal.
* **MacOS/Linux (Homebrew):** Run `brew install cube2222/octosql/octosql` in your terminal.
* **Manual Download:** Visit the [Official Releases Page](https://github.com/cube2222/octosql/releases) to find the latest version for your specific operating system.

### Pros and Cons
* **Pros:** Completely free and open-source, very fast performance, supports many file types out of the box.
* **Cons:** Requires basic familiarity with terminal commands, documentation is geared toward technical users.
