### What it does in plain English
Gonzo is a real-time log analysis tool that brings order to messy server and application logs directly inside your command-line interface. It automatically detects log formats, organizes streams into colorful charts, and highlights errors as they happen. You can also launch an instant web view or use artificial intelligence to uncover hidden patterns and troubleshoot issues faster.

### Who it's for
* Software developers tracking application errors across local files or live cloud environments
* System administrators monitoring busy server infrastructure and Kubernetes clusters
* DevOps engineers looking for a lightweight, keyboard-friendly alternative to heavy browser dashboards

### Key features
* Live streaming from local log files, standard input, network endpoints, or Kubernetes pods
* Interactive dashboard with severity distribution charts, word frequency, and time-series views
* Built-in local web dashboard accessible via browser for richer visual analytics and heatmaps
* Smart filtering with regular expressions, keyword search, and custom log format definitions
* Artificial intelligence integration to spot anomalies, detect recurring patterns, and suggest fixes

### How to install (Download)
* **Verify checksums:** [Download (checksums.txt)](https://github.com/control-theory/gonzo/releases/download/v0.4.3/checksums.txt)
* **Using Go:** Run `go install github.com/control-theory/gonzo/cmd/gonzo@latest` in your terminal.
* **Using Homebrew (macOS/Linux):** Run `brew install gonzo` in your terminal.
* **Using Nix:** Run `nix run github:control-theory/gonzo` in your terminal.

### Pros and Cons
* **Pros:** Free and open-source, extremely fast performance, works completely offline or with local AI models.
* **Cons:** Requires familiarity with terminal usage, advanced AI features require your own model provider API keys.
