### What it does in plain English
Taskbook lets you organize your to-do lists, daily schedules, and quick notes directly inside your computer terminal. It features a simple typing style so you can create, prioritize, and check off items across multiple custom boards in seconds. All your information stays private on your machine, with safe file saving to prevent data loss and built-in archiving for deleted items.

### Who it's for
* Software developers and system administrators who live inside the terminal and want a quick way to track work.
* Power users who prefer lightweight keyboard shortcuts over heavy graphical desktop organization tools.
* Anyone who wants a private, local-first task manager that doesn't upload personal notes to external servers.

### Key features
* Organize tasks and notes into custom boards or view them in a chronological timeline.
* Set importance levels and favorite stars for items requiring immediate attention.
* Safely store information locally with secure file-saving routines to prevent corruption.
* Automatically archive deleted items with options to inspect or restore them anytime.
* Search, filter, and copy item descriptions directly to your system clipboard.

### How to install (Download)
You can set up taskbook using Node package managers. Run one of the following commands in your terminal:

* **Using Yarn:** `yarn global add taskbook`
* **Using NPM:** `npm install --global taskbook`
* **Using Snapcraft:** `snap install taskbook`

Visit the [Official Source / Credits](https://github.com/klaudiosinani/taskbook) page for further details.

### Pros and Cons
* **Pros:** Completely free and open-source, keeps data entirely private on your device, highly responsive keyboard interface.
* **Cons:** Requires a command-line interface, advanced options take a few minutes to learn.
