### What it does in plain English
This dashboard provides a clear, visual overview of your Raspberry Pi’s health, including CPU temperature, memory usage, and storage status. It runs directly in your web browser, allowing you to check on your device from your phone or computer without needing extra software. You can also perform administrative tasks like restarting or shutting down your device remotely with just a few clicks.

### Who it's for
* Hobbyists and makers who want to keep an eye on their Raspberry Pi projects.
* Home server users who need a quick way to check system status and manage power settings without using a command line.

### Key features
* **Live Hardware Monitoring:** View real-time data on CPU load, temperature, and memory usage.
* **System Overview:** Easily check your network configuration, kernel version, and connected USB devices.
* **Remote Management:** Securely reboot or shut down your device directly from the dashboard.
* **Customizable Alerts:** Set your own warning thresholds for hardware performance.
* **Mobile-Friendly Design:** A responsive interface that looks great on both desktop and mobile screens, featuring a dark mode option.

### How to install (Download)
You can set up the dashboard using the official installer script or by manual download:
* **Automatic Installer:** Run the following command in your Raspberry Pi terminal: `wget -O install.sh https://github.com/femto-code/Raspberry-Pi-Dashboard/raw/release/installer.sh && bash install.sh`
* **Manual Setup:** Download the latest files from the [Official official project page](https://github.com/femto-code/Raspberry-Pi-Dashboard) and follow the instructions provided in the README.

### Pros and Cons
* **Pros:** Completely free, lightweight, requires no complex software, and works on any device with a web browser.
* **Cons:** Requires basic knowledge of web server permissions to set up correctly; remote shutdown features should only be used on secure, private networks.
