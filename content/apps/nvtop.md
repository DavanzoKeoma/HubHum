### What it does in plain English
This tool gives you a live look at how hard your graphics hardware and accelerators are working. It displays active processes, memory usage, temperatures, and power draw right in your command window. You can easily switch between different metrics and customize your dashboard layout on the fly.

### Who it's for
* System administrators managing servers with heavy graphics or AI workloads
* Gamers and creators checking hardware temperatures and resource loads
* Developers testing GPU-accelerated applications and local machine learning tasks

### Key features
* Real-time monitoring for a wide variety of graphics hardware and accelerators
* Interactive dashboard with customizable charts and metrics
* Detailed process lists showing which applications are using your hardware
* Support for tracking memory consumption, core clocks, and fan speeds
* Simple keyboard controls to customize views and save your preferences
