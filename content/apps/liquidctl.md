### What it does in plain English
liquidctl allows you to monitor and adjust the settings of your computer's cooling hardware and internal lights. It acts as a bridge between your operating system and specialized cooling components, letting you change fan speeds or lighting colors. This tool provides a simple way to manage your hardware performance without relying on heavy, manufacturer-specific programs.

### Who it's for
* PC enthusiasts who want to customize their cooling setup and lighting effects.
* Users who prefer lightweight, efficient tools over large, resource-heavy manufacturer software.

### Key features
* Adjusts fan and pump speeds to balance cooling performance and noise levels.
* Customizes internal LED lighting colors and patterns for your hardware.
* Monitors real-time temperatures and hardware status for supported devices.
* Works across multiple operating systems, including Linux, macOS, and Windows.
* Provides a clean, text-based interface for quick and precise hardware adjustments.

### How to install (Download)
* **Linux/macOS/Windows:** This tool is primarily installed via Python's package manager. You can install it by running `pip install liquidctl` in your terminal or command prompt.
* **Linux Distributions:** Many systems include it in their official software stores (e.g., `sudo apt install liquidctl` or `sudo pacman -S liquidctl`).
* **Official Release:** You can find the latest package file here: [Download liquidctl-1.16.0-py3-none-any.whl](https://github.com/liquidctl/liquidctl/releases/download/v1.16.0/liquidctl-1.16.0-py3-none-any.whl).

### Pros and Cons
* **Pros:** Completely free and open-source, very lightweight, and supports a wide variety of popular cooling hardware.
* **Cons:** Requires using a text-based interface, which may take a moment to learn if you are used to visual buttons and sliders.
