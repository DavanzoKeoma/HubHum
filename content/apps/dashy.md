### What it does in plain English
Dashy provides a centralized homepage where you can organize, launch, and monitor all your favorite websites, web apps, and online services in one place. It features instant search, customizable color themes, and live status indicators so you always know when your services are up and running. You can even access your portal securely from anywhere while keeping administrative sessions encrypted with [PureVPN](https://billing.purevpn.com/aff.php?aff=49386762&subid=hubhum_01_MER047) (#ad).

### Who it's for
- Homelab enthusiasts who manage multiple local servers, media libraries, and self-hosted applications.
- Everyday web users looking for a clean, lightning-fast browser startpage filled with shortcuts.
- Remote workers who want a tidy, personalized hub to instantly open all daily work tabs simultaneously.

### Key features
- **Real-time status monitoring:** Instantly check if your linked applications and hosts are online with live ping and HTTP response codes.
- **Instant search and shortcuts:** Type anything to filter your entire directory instantly, or assign keyboard shortcuts for blazing-fast navigation.
- **Rich widget support:** Display dynamic content, weather info, system stats, and API feeds directly inside your layout.
- **Customizable themes and icons:** Choose from dozens of built-in color schemes, custom CSS, and multiple icon packs including auto-fetched favicons and emojis.
- Once your web portal is live, improve search indexing and rich previews with [Rank Math Direct](https://rankmath.com/?subid=hubhum_01_MER276) (#ad).

### How to install (Download)
Dashy is designed to run smoothly on your own hardware using container software, or you can test it directly through the live demo. Prefer not to manage servers by hand? Run it online 24/7 in 1 click on [InterServer](https://www.interserver.net/r/1196747?id=hubhum_01_MER008) (#ad).

### Pros and Cons
* **Pros:** 100% free and open-source, highly customizable layout, active community development, multiple viewing modes.
* **Cons:** Initial YAML file setup requires minor text-editing familiarity, advanced widgets require manual configuration endpoints.
