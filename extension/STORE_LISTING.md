## 2. Detailed Description

```text
HubHum – A Git Hub for Humans turns intimidating GitHub developer repositories into plain-English software guides with verified official download buttons.

What this extension does:
• Instant GitHub Repo Detection: Displays an active purple "HUM" badge whenever you browse a public open-source software repository on GitHub.
• Native "Humanize with HubHum" Button: Adds a clean, unobtrusive button right beside Watch / Fork / Star on GitHub pages so you can jump straight to a plain-language guide or request instant AI translation.
• Real-Time Catalog Lookup: Checks HubHum's live catalog (catalog-index.json) immediately when opening the popup. If a guide already exists, open it in one click.
• Background AI Conversion & Desktop Notifications: Click "Humanize with HubHum ⚡" to trigger automatic translation in the background. You can close the popup or switch tabs—a native desktop notification alerts you the moment the new guide is published.

Built for everyday users, creators, teachers, and teams who want trustworthy free software without decoding terminal instructions or source trees.

100% Privacy-First:
• Zero third-party tracking cookies, zero user profiling, zero personal data collection.
• HubHum is an independent open-source project and is not affiliated with GitHub, Inc.
```

## 3. Single Purpose & Permission Justifications

- **Single Purpose Description:**
  ```text
  Detects public GitHub software repositories viewed by the user, checks whether a plain-language guide already exists on HubHum, and dispatches or opens a translated HubHum software guide in one click.
  ```

- **Why `activeTab` is needed:**
  ```text
  Reads the current active tab URL only when the user visits a public GitHub repository or clicks the extension icon, to identify the owner/repository name and display its conversion status.
  ```

- **Why `storage` is needed:**
  ```text
  Uses chrome.storage.local solely on the user's device to track the progress status of background software guide conversions so the user can reopen the popup or keep the GitHub button synchronized. No personal data is stored.
  ```

- **Why `notifications` is needed:**
  ```text
  Sends a local browser notification once a requested software guide finishes building on HubHum, allowing one-click opening of the published guide.
  ```

- **Why `host_permissions` (`https://davanzokeoma.github.io/*`, `https://hubhum-api-bridge.keomadavanzo.workers.dev/*`) are needed:**
  ```text
  Queries the public static catalog index (catalog-index.json) and polls published app page readiness on GitHub Pages, and submits the public GitHub repository URL to the HubHum Worker bridge to generate a new static guide.
  ```

- **Why `content_scripts` (`https://github.com/*/*`) are needed:**
  ```text
  Injects a single lightweight "Humanize with HubHum" action button into the repository header alongside Star/Watch/Fork on public GitHub project pages.
  ```
