### What it does in plain English
Discordo lets you connect to your online chat communities directly inside your terminal window without needing heavy desktop software. It uses very little computer memory and lets you navigate messages, servers, and channels purely using your keyboard. You can log in securely using your standard credentials, a quick QR code scan, or an access token.

### Who it's for
* Power users who spend their day inside the command line and want a distraction-free chat experience.
* Owners of older or low-power computers who need a lightning-fast messaging tool that doesn't slow down their system.
* Minimalists who prefer keyboard-driven navigation over heavy graphical interfaces.

### Key features
* Ultra-lightweight design that consumes minimal system resources and memory.
* Full keyboard navigation for fast messaging, server switching, and channel browsing.
* Multiple secure login methods including password, QR code scanning, and custom tokens.
* Customizable themes and keybindings to match your preferred workflow.
* Optional support for voice channels and syntax highlighting in code blocks.

### How to install (Download)

* **FreeBSD:** `pkg install discordo`
* **Android (Termux):** `pkg install discordo`

  ```sh
  scoop bucket add vvxrtues https://github.com/vvirtues/bucket
  ```

### Pros and Cons
* **Pros:** Extremely fast and resource-efficient, completely free and open source, highly customizable keyboard controls.
* **Cons:** Advanced features like voice require a C compiler and additional system audio libraries, automated terminal clients require care to comply with platform terms of service.
