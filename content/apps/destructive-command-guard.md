### What it does in plain English
Destructive Command Guard acts as an intelligent safety layer between your terminal and AI coding assistants. When an assistant attempts to run a catastrophic operation like erasing code directories or dropping databases, the tool instantly blocks the command. It provides clear explanations and safer alternatives, protecting your work from accidental data loss.

### Who it's for
* Developers and engineers who use AI coding assistants to manage local project pages and cloud servers.
* Teams wanting automated guardrails against accidental data deletion during automated scripting tasks.
* Anyone looking to prevent unrecoverable terminal mistakes before they happen.

### Key features
* **Zero-config core protection:** Automatically blocks dangerous file deletion and history-rewriting git commands out of the box.
* **Extensive security packs:** Includes dozens of rule sets covering databases, cloud platforms, containers, and infrastructure tools.
* **Lightning-fast performance:** Written in Rust with sub-millisecond filtering speed so it never slows down your workflow.
* **Smart context detection:** Distinguishes between safe references and actual execution hazards to minimize false alarms.
* **Clear terminal feedback:** Explains precisely why a command was blocked and suggests safer ways to achieve your goal.
