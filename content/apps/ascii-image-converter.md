### What it does in plain English
This tool takes any standard photo and turns it into a picture made entirely of text characters. It can display these images in your computer's command line window with full color support. It also offers a special mode that uses braille dots to create high-resolution visual patterns.

### Who it's for
*   **Creative Coders:** People who enjoy writing code and want to add a visual flair to their command line projects.
*   **Designers:** Individuals who want to create unique text-based graphics for websites, social media, or digital art.
*   **Accessibility Enthusiasts:** Users interested in exploring how braille patterns can be used for visual representation on screens.

### Key features
*   **Multi-Format Support:** Works with common image types like JPEG, PNG, GIF, and WebP.
*   **Color Options:** Displays art in full color, grayscale, or negative (inverted) modes.
*   **Braille Mode:** Converts images into high-density braille dot patterns for sharper visuals.
*   **Customization:** Allows you to choose specific characters to represent light and dark areas.
*   **Save Options:** Can save the resulting art as a text file or a new image file.
