### What it does in plain English
Artemis transforms everyday natural language instructions into reliable automated actions on real Android devices or emulators. It allows AI coding tools and test suites to interact with mobile applications just like a human would. The software handles complex multi-step workflows, captures diagnostic logs, and achieves industry-leading success rates on standard mobile benchmark tasks.

### Who it's for
* Mobile app developers and testers wanting to automate UI testing using natural language prompts.
* AI enthusiasts integrating real device automation into coding assistants and development environments.
* Quality assurance teams looking to execute long-running exploratory and stability tests on Android.

### Key features
* **Natural Language Control**: Executes complex testing workflows and everyday tasks on Android straight from conversational prompts.
* **AI IDE Integration**: Connects seamlessly with popular development environments using standard model context protocols.
* **Multimodal Screen Perception**: Combines element hierarchies and optical character recognition with visual AI models for custom user interfaces.
* **Flexible Execution Profiles**: Offers fast reactive execution for routine tasks alongside deep reasoning loops for multi-step verification.
* **Live Web Console**: Provides real-time screen projection, interactive test dispatch, and execution replay directly in your browser.

### How to install (Download)
Clone the official project official project page and run the setup script to automatically install required system dependencies and configure your environment:

```bash
git clone https://github.com/google/artemis.git && cd artemis
./start.sh
```

For Windows PowerShell users:
```powershell
git clone https://github.com/google/artemis.git
cd artemis
.\start.bat
```

### Pros and Cons
* **Pros:** Free and open source, native AI integration, high benchmark success rate, supports both CLI and web console.
* **Cons:** Requires an Android device or emulator with USB debugging enabled, initial setup requires basic terminal usage.
