### What it does in plain English
RevokeMsgPatcher is a handy computer utility designed for Windows users who want to keep a complete, uninterrupted history of their online conversations. When someone sends a message in a supported desktop chat application and then quickly deletes or recalls it, this tool ensures the text or media stays visible on your screen instead of vanishing. It works quietly in the background by updating local application files, letting you view content exactly as it was originally received.

### Who it's for
* Everyday chat users who want to avoid missing important context when friends or colleagues delete messages.
* Power users managing multiple chat accounts on a single Windows computer who want a streamlined messaging setup.
* Anyone looking for a straightforward way to keep permanent chat archives without installing complex modifications.

### Key features
* **Message Retention:** Stops incoming chat messages from disappearing when a sender triggers an unsend or recall action.
* **Multi-Instance Support:** Allows you to run multiple chat windows simultaneously for managing separate accounts on one PC.
* **Automatic Path Detection:** Quickly locates your installed chat software folders automatically using system registry entries.
* **Lightweight Interface:** Provides a clean, straightforward window designed specifically to complete patches with a single click.

### How to install (Download)
To get started, make sure your computer runs Windows 7 or higher and has a compatible .NET software foundation installed. 

1. Close any running chat applications on your computer.
2. Download the official package directly from the [RevokeMsgPatcher Releases Page](https://github.com/huiyadanli/RevokeMsgPatcher/releases).
3. Alternatively, you can grab the direct file via the [Direct Download Link](https://github.com/huiyadanli/RevokeMsgPatcher/releases/download/2.2/RevokeMsgPatcher.v2.2.zip).
4. Run the program as an administrator, select your chat software folder, and apply the patch.

### Pros and Cons
* **Pros:** Completely free and open source; lightweight tool that runs locally without background resource drain; supports multi-instance chat options.
* **Cons:** Requires manual re-application after major chat application updates; antivirus software may occasionally flag the local file modification and require a manual exception.
