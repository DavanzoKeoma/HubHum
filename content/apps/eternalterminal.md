### What it does in plain English
Eternal Terminal is a smart remote shell designed to keep your command-line sessions alive even if your laptop goes to sleep, changes Wi-Fi networks, or drops offline. When your connection breaks, it silently pauses your session and instantly picks up right where you left off the moment you reconnect. It works alongside your existing secure shell configuration to eliminate frustrating dropouts and frozen screens.

### Who it's for
* Software developers and system administrators working remotely over unstable or mobile connections.
* Remote workers who frequently switch between home Wi-Fi, public hotspots, and office networks.
* Power users who want to keep code editors and long-running remote processes safe from sudden disconnects.

### Key features
* Automatically re-establishes dropped network connections without losing your active text or scrollback.
* Integrates seamlessly with code editors like VS Code and Cursor for rock-solid remote development windows.
* Remembers and saves your active sessions so you can easily jump right back into them after a reboot.
* Supports secure tunneling, port forwarding, and identity agent forwarding just like standard remote login tools.
* Includes script-friendly automation controls to run commands and inspect outputs programmatically.

### How to install (Download)
You can install Eternal Terminal using your operating system's package manager or setup script. Visit the [Official Site & Documentation](https://mistertea.github.io/EternalTerminal/) for tailored installation guides across macOS, Linux, FreeBSD, and Windows (via subsystem).

### Pros and Cons
* **Pros:** Keeps sessions alive through network changes, free forever, open source, integrates with popular code editors.
* **Cons:** Requires installing components on both your local machine and the remote server.
