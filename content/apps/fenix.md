### What it does in plain English
Fenix lets you instantly launch a private local website preview server right on your desktop without messing with complicated command-line setups. You can simply drag and drop your project folders to make them instantly viewable in your web browser. It helps you test your web pages locally, manage web ports automatically, and share your work effortlessly.

### Who it's for
* Web designers and frontend creators who need a quick way to preview websites locally.
* Students learning HTML, CSS, and JavaScript who want a visual tool instead of terminal commands.
* Developers looking for a straightforward local server with automatic port management.

### Key features
* **Drag-and-Drop Setup:** Drop any folder onto the app window or system tray to launch a local website immediately.
* **Automatic Port Management:** Automatically resolves port conflicts so your servers run smoothly without crashing.
* **Built-In File Browser:** Quickly inspect and navigate your project files using a clean responsive interface.
* **Custom URL Aliases:** Create pretty names and web addresses for easier testing and tunneling.
* **Light and Dark Themes:** Switch between visual themes to match your preferred desktop setup.

### How to install (Download)
You can get the latest release candidates and setup instructions directly from the [Official Fenix Website](https://preview.fenixwebserver.com).

### Pros and Cons
* **Pros:** Extremely easy to use visual interface, drag-and-drop server creation, automatic port conflict resolution.
* **Cons:** Advanced features like custom SSL certificates require careful configuration, older versions had limited auto-update capabilities.
