### What it does in plain English
LWGUI solves the common frustration of cluttered, hard-to-read material panels in video game engines by providing a clean, modular layout system. It lets artists and creators organize material settings with folding groups, custom dropdowns, gradient editors, and preset tools without writing complex custom code. By streamlining these controls, teams can tweak visual effects faster and keep their workspaces organized.

### Who it's for
- Technical artists building clean and user-friendly material controls for team members.
- Game developers and graphics programmers looking to speed up material tweaking workflows.
- Unity creators who want advanced gradient editors and preset management systems.

### Key features
- Modular drawer and decorator extension architecture for custom material inspectors.
- Powerful gradient and ramp map editing tools built right into the workflow.
- Visual editing support for attributes directly inside visual shader graphs.
- Timeline integration for recording and switching material parameter animations automatically.
- Robust preset management and metadata caching to shorten iteration cycles.

### How to install (Download)
1. Make sure your environment is compatible (Unity 2021.3 or newer recommended).
2. Open your Unity project and go to `Window > Package Manager > Add > Add package from git URL`.
3. Enter the official git URL: `https://github.com/JasonMa0012/LWGUI.git`
4. Alternatively, you can download the project package directly from the [Official GitHub Releases Page](https://github.com/JasonMa0012/LWGUI/releases).

### Pros and Cons
* **Pros:** Open-source and free to use, significantly speeds up material inspector design, includes advanced color and ramp editing tools.
* **Cons:** Requires familiarity with Unity and shader properties, advanced styling options take a little time to learn.
