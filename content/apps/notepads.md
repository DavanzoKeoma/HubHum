### What it does in plain English
Notepads is a modern text editor that gives your Windows computer a fresh, clean way to write notes and edit simple files. It features a tabbed system that lets you keep multiple documents open in one window, just like a web browser. The app is built to be incredibly fast and visually appealing, making it a great replacement for standard system tools.

### Who it's for
* Students or writers who need a distraction-free space to jot down ideas.
* Computer users who want a faster, better-looking alternative to the default system notepad.

### Key features
* **Tabbed Interface:** Keep your workspace organized by opening multiple files in a single window.
* **Modern Design:** A clean, minimalist look that fits perfectly with the latest Windows style.
* **Markdown Preview:** View your formatted text in real-time as you type.
* **Built-in Comparison Tool:** Easily see the differences between two versions of a file.
* **Fast Performance:** Designed to open instantly so you can start working without delay.

* **Pros:** Completely free and open-source, no advertisements, and very lightweight.
* **Cons:** Not designed for very large files (currently limited to 1MB) and cannot save directly into protected system folders.
