### What it does in plain English
Kubebox provides an interactive window into your container clusters, allowing you to watch activity and check system health. You can easily jump between different working environments, inspect live logs, and view resource usage charts for processor and memory. It bridges the gap between your local keyboard and remote cloud systems without requiring heavy software installations.

### Who it's for
* Cloud administrators who need a quick, text-based dashboard to check cluster health.
* Software developers troubleshooting container logs and performance metrics on the fly.
* Operations teams managing multi-environment container setups from a single lightweight utility.

### Key features
* Seamless switching between multiple configuration contexts and namespaces.
* Live streaming of container log files and real-time event tracking.
* Visual charts showing processor, memory, network, and file system usage.
* Remote shell access into running containers directly from the terminal interface.
* Support for major security login methods including single sign-on and cloud tokens.

### How to install (Download)
You can download the standalone executable directly for your operating system:
* [Download for Windows (.exe)](https://github.com/astefanutti/kubebox/releases/download/v0.10.0/kubebox-windows.exe)

Alternatively, you can run the software via container tools or cloud setup it directly inside your cluster service.

### Pros and Cons
* **Pros:** Lightweight standalone tool, supports multiple authentication methods, provides real-time resource graphs.
* **Cons:** Advanced metrics require proper cluster setup permissions, terminal interface has a learning curve for beginners.
