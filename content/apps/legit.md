### What it does in plain English
Version control tools can often feel complicated and frustrating for everyday projects. This application simplifies your daily routine by automating repetitive tasks like saving work-in-progress and switching between projects. It lets you focus on your actual goals rather than getting stuck on technical commands.

### Who it's for
* Beginners who find standard version control tools confusing to learn and remember.
* Developers who want faster, streamlined workflows without typing long sequences of commands.
* Anyone looking to save time managing project branches and updates.

### Key features
* Automatically saves your current work when switching between different project sections.
* Combines downloading updates, saving your spot, combining changes, and uploading in one simple step.
* Easily share your current project draft online or remove it from public view instantly.
* Quickly review your recent history and step backward to fix mistakes effortlessly.
* Preview what commands will run before executing them to stay completely in control.

### How to install (Download)
* [Download for Windows (.exe)](https://github.com/frostming/legit/releases/download/1.2.0/legit.exe)
* Alternatively, install via Python package manager by running `pip install legit` in your terminal.
* macOS and Linux users can also install it using Homebrew with `brew install legit`.

### Pros and Cons
* **Pros:** Free and open source, drastically reduces repetitive typing, makes branching workflows much simpler.
* **Cons:** Relies on command-line usage, automated assumptions might occasionally surprise version control veterans.
