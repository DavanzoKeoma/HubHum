### What it does in plain English
This tool helps you keep your Python codebase clean and well-structured as it grows larger. It lets you define clear boundaries between different parts of your code and checks that files only talk to allowed sections. Best of all, it runs instantly and catches accidental code tangles before they cause maintenance headaches.

### Who it's for
* Python software developers managing growing projects
* Tech leads maintaining clean architecture across teams
* Developers looking to prevent messy circular code dependencies

### Key features
* Visually map and configure project modules with a simple interactive setup guide
* Automatically check code imports against your declared rules during development or checks
* Generate clear visual dependency graphs to understand how your project connects
* Adopt incrementally by tracking only the specific folders or packages you choose
* Zero runtime impact because enforcement happens during code checking, not execution

### How to install (Download)
You can easily install this tool on your machine using the Python package manager:
```bash
pip install tach
```
For detailed guides and documentation, visit the [Official Documentation Website](https://docs.gauge.sh/).

### Pros and Cons
* **Pros:** Free and open source, zero runtime performance impact, incremental adoption.
* **Cons:** Requires a terminal to run setup commands, advanced rules take a short while to learn.
