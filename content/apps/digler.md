### What it does in plain English
Digler helps you search through storage drives and disk images to find and rescue deleted or lost files. It thoroughly scans raw storage spaces to identify missing documents, pictures, and archives even when directory details are damaged. You can choose to run the software through a straightforward desktop window or a fast command-line interface depending on what feels comfortable.

### Who it's for
* Everyday computer users trying to recover accidentally deleted photographs, documents, or memories from an old hard drive.
* IT professionals and technical hobbyists investigating storage devices or analyzing disk images for research.
* Security enthusiasts looking for a modular tool to carve specific file types out of raw storage images.

### Key features
* **Deep File Carving**: Recovers deleted files regardless of the underlying storage format even when metadata has vanished.
* **Flexible Interfaces**: Operates as both a friendly desktop application and a speedy command-line tool.
* **Detailed Reports**: Generates structured reports documenting all findings and recovered data elements.
* **Plugin Extensibility**: Supports custom file format scanners to easily expand what types of files the software can recognize.
* **Broad Storage Support**: Analyzes standard disk image files as well as direct physical storage partitions.
