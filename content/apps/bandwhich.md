### What it does in plain English
Bandwhich monitors your computer's network activity to show you exactly which programs are sending or receiving data. It displays this information in a clear, live list that updates as your internet usage changes. This helps you quickly spot background processes or applications that might be slowing down your connection.

### Who it's for
* Home users trying to figure out why their internet connection feels slow.
* People who want to keep an eye on which programs are secretly using data in the background.

### Key features
* **Real-time monitoring:** Watch network traffic as it happens on your machine.
* **Process identification:** See exactly which specific app is responsible for network activity.
* **Connection details:** View remote addresses and hostnames for your active network connections.
* **Responsive display:** The interface automatically adjusts to fit your window size, showing more or less detail as needed.

### How to install (Download)
You can download the latest pre-built versions for your operating system directly from the official releases page:
[Download from Official Releases](https://github.com/imsnif/bandwhich/releases)

*Note: On Windows, you may need to install [npcap](https://npcap.com/#download) to allow the app to monitor network traffic.*

### Pros and Cons
* **Pros:** Completely free and open-source, lightweight, and provides clear visibility into network usage.
* **Cons:** Requires administrative permissions to run because it monitors system-wide network traffic.
