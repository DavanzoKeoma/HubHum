### What it does in plain English
This tool automatically sets up everything you need to run advanced artificial intelligence image and video generators on your computer. It bundles all necessary helper files, programming tools, and helper add-ons into a single isolated folder. Through its custom desktop interface, you can easily launch the software, switch between different performance packages, and keep your workspace updated without using command-line windows.

### Who it's for
* Digital artists and creators who want to run powerful generative art tools locally on their Windows computers without complex setup procedures.
* Enthusiasts looking for a self-contained, portable setup that keeps all models and helper files neatly organized in one directory.

### Key features
* **One-Click Setup:** Automatically configures required components like Python and processing libraries without manual intervention.
* **Dedicated Desktop Manager:** Provides an intuitive window to monitor console logs, adjust performance settings, and launch your workflow.
* **Flexible Add-Ons:** Quick installation options for performance accelerators, facial enhancement tools, and model converters.
* **Version Control & Snapshots:** Easily update your software components or save and restore workspace snapshots before making major changes.
* **Portable Architecture:** Keeps your entire installation, including models and configurations, self-contained within a single folder.

### How to install (Download)
1. Go to the [Official Releases Page](https://github.com/Tavris1/ComfyUI-Easy-Install/releases) to grab the setup files.
2. Download the package directly using the [Latest Version Download Link](https://github.com/Tavris1/ComfyUI-Easy-Install/releases/latest/download/ComfyUI-Easy-Install.zip).
3. Extract the downloaded archive into a short folder path on your computer (for example, `D:\AI\`).
4. Run the setup script inside the folder to finish the installation process.

* **Pros:** Completely free and open-source, keeps all files neatly contained in one folder, includes a helpful custom desktop manager for easy control.
