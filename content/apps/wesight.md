### What it does in plain English
WeSight gives you a single visual home to manage, run, and watch powerful coding assistants right on your own computer. Instead of juggling separate terminal windows and complex settings, you can chat with multiple AI engines, inspect real-time file changes, and coordinate tasks easily. It connects your preferred intelligence providers and automated helpers into an approachable dashboard designed for everyday work.

### Who it's for
* Developers and technical creators who run local coding assistants and want a clean visual interface instead of scattered terminal commands.
* Power users looking to organize multiple intelligence models and automated tasks in one private workspace.
* Teams and individuals experimenting with local automation who want to track token usage, runtime speed, and task progress visually.

### Key features
* **Unified Agent Hub:** Run and manage various local coding agents from a single consistent window.
* **Visual Cowork Workspace:** Chat with your assistants while watching live file edits, code diffs, and tool outputs happen in real time.
* **Flexible Model Routing:** Connect official or custom intelligence providers and switch between them effortlessly.
* **Performance Dashboard:** Track runtime metrics, response speeds, token consumption, and active task durations at a glance.
* **Skill Marketplace:** Discover, install, and manage custom skills to expand what your assistants can accomplish.
