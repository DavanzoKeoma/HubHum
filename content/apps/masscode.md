### What it does in plain English
massCode brings your code snippets, research notes, API testing tools, and math calculations into a single desktop workspace. All of your information is stored locally on your hard drive as standard text files, meaning you own your data completely. You can easily sync these files across multiple computers using any file synchronization service or version control tool you prefer.

### Who it's for
* Software developers and programmers who need a fast, organized place to keep reusable code snippets.
* Technical writers and researchers looking to manage markdown notes alongside code examples and API tests.
* Anyone who wants a private, offline-first knowledge vault without being locked into a proprietary cloud service.

### Key features
* **Code Snippets:** Organize reusable code into multi-level folders with syntax highlighting for dozens of languages and built-in code formatting.
* **Markdown Notes:** Write project documentation, task lists, and personal knowledge bases right alongside your code snippets.
* **API Testing Client:** Build, test, and organize web requests and API collections directly within the application.
* **Math Notebook:** Perform quick calculations, currency conversions, and date math using a built-in calculator notebook.
* **Local-First Privacy:** Keep all data safely on your device as plain markdown files that work great with cloud sync and version control.
