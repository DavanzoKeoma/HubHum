### What it does in plain English
Pokemon-Terminal is a fun tool that decorates your computer's command window with high-quality images of over 700 different Pokemon. You can easily search for specific characters by name or index number to match your mood. It also provides the option to update your desktop wallpaper to match your chosen terminal theme.

### Who it's for
This tool is perfect for fans of the franchise who want to add a personal touch to their workspace. It is also great for users who spend a lot of time in command-line environments and want to make their daily tasks more visually engaging.

### Key features
* **Huge Library:** Choose from over 700 unique Pokemon images.
* **Smart Search:** Easily find your favorite character by name or region.
* **Flexible Display:** Set images as your terminal background or your main desktop wallpaper.
* **Slideshow Mode:** Automatically cycle through different Pokemon at set intervals.
* **Wide Compatibility:** Works with popular terminal programs on Windows, macOS, and Linux.

### How to install (Download)
To use this tool, ensure you have Python installed on your system. You can install the application using one of the following methods:

* **Using npm:** If you have Node.js installed, run `npm install --global pokemon-terminal` in your command window.
* **Using pip:** Run `pip3 install git+https://github.com/LazoCoder/Pokemon-Terminal.git` to install it directly.
* **Manual Setup:** You can clone or download the [official official project page](https://github.com/LazoCoder/Pokemon-Terminal) and run `python3 setup.py install`.

### Pros and Cons
* **Pros:** Completely free to use, supports a massive library of characters, and works across all major operating systems.
* **Cons:** Requires basic knowledge of how to use a command window, and some terminal programs may require manual transparency settings for the best look.
