### What it does in plain English
It shows you who is connected to your VPN and how much traffic is flowing.  
You can create new client certificates with a few clicks.  
All the client files you need can be downloaded as a ready‑to‑use zip package.

### Who it's for
Small business owners who need a private network for their team.  
Tech‑savvy families who share a home VPN.  
Hobbyists who want a quick way to manage a personal VPN server.

### Key features
- Live view of connected clients and server statistics.  
- One‑click creation of new client certificates.  
- Download of a complete client configuration bundle as a zip file.  
- Quick edit of the server’s configuration through the web page.  
- Simple log viewer to see recent activity.

### How to install (Download)
- **Setup file:** Download the ready‑made configuration file and follow the brief instructions to launch the VPN server and its web dashboard.  
  [Download setup file](https://raw.githubusercontent.com/adamwalach/openvpn-web-ui/master/docs/docker-compose.yml)

- **Official releases page:** For other installation options and future updates.

### Pros and Cons
* **Pros:** free forever, web‑based control, no need to edit text files manually, works with a single setup file.  
* **Cons:** still in early stage, requires the setup file to run, best suited for small‑to‑medium environments.
