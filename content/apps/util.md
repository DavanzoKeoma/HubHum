### What it does in plain English
Util is a handy package of general-purpose tools designed to make working with digital data simpler and more reliable. It helps you accurately measure time durations, handle memory storage units, and manage asynchronous tasks effortlessly.

### Who it's for
* Software creators looking for reliable, ready-made routines to handle time and math calculations.
* Developers wanting to organize object pools and manage memory space efficiently.
* Technical writers and hobbyists experimenting with custom script structures.

### Key features
* **Time calculations:** Easily measure elapsed intervals and convert durations into seconds, minutes, or milliseconds without overflow worries.
* **Storage management:** Convert bytes into kilobytes, megabytes, and larger units with straightforward commands.
* **Async operations:** Run tasks concurrently and handle results cleanly without getting blocked.
* **Object pooling:** Manage reusable items efficiently using simple or dynamic object pools.
