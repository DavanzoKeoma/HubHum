### What it does in plain English
LearnHouse provides a complete set of tools for teachers and organizations to build professional online learning experiences. It includes a flexible editor for writing lessons, features for tracking student progress, and interactive elements like quizzes and code practice. You can host it yourself to maintain full control over your educational content and student data.

### Who it's for
*   **Independent Educators:** Teachers who want to create and sell their own courses without relying on restrictive third-party platforms.
*   **Organizations and Schools:** Groups that need a private, customizable portal to manage internal training or public educational programs.

### Key features
*   **Flexible Course Editor:** A simple, block-based writing tool that makes organizing lessons intuitive.
*   **Interactive Learning:** Includes features for code practice, collaborative whiteboards, and AI-assisted study tools.
*   **Student Management:** Easily track progress, manage assignments, and issue completion certificates.
*   **Community Engagement:** Built-in discussion forums to help students connect and learn from each other.
*   **Custom Branding:** Tailor the look and feel of your learning portal to match your organization’s identity.

### How to install (Download)
LearnHouse is designed to be self-hosted. You can get started by visiting the [Official Website](https://learnhouse.app) or by using the command line tool if you are comfortable with basic server setup.

### Pros and Cons
*   **Pros:** Offers a comprehensive suite of tools in one place, supports self-hosting for data privacy, and includes modern interactive features like AI and code grading.
*   **Cons:** Requires some technical knowledge to set up and maintain your own server, and advanced business features are restricted to the enterprise version.
