### What it does in plain English
Viu allows you to view pictures and animated GIFs without leaving your command-line window. It automatically detects your terminal's capabilities to provide the best possible image quality. If your specific terminal setup does not support advanced graphics, it intelligently falls back to a block-based display mode.

### Who it's for
* Developers and system administrators who spend most of their time working in a terminal environment.
* Users who want to quickly preview images or check logs containing visual data without opening a separate image viewer.

### Key features
* **Native Graphics Support:** Works seamlessly with modern terminal emulators like iTerm and Kitty.
* **Animated GIF Support:** Play animations directly in your terminal window.
* **Flexible Display:** Automatically resizes images to fit your terminal window while maintaining the correct aspect ratio.
* **Customizable:** Offers options to set specific widths, heights, and offsets for precise image placement.
* **Transparency:** Supports transparent backgrounds for images that require them.

### How to install (Download)
* [Download for Windows (.exe)](https://github.com/atanunq/viu/releases/download/v1.6.1/viu-x86_64-pc-windows-msvc.exe)
* **MacOS:** Use Homebrew by running `brew install viu` in your terminal.
* **Arch Linux:** Install via the official official project page using `pacman -S viu`.

### Pros and Cons
* **Pros:** Extremely lightweight, fast, and requires no heavy graphical software to run.
* **Cons:** Image quality depends heavily on the specific terminal emulator you are using; some older terminals may only show basic block representations.
