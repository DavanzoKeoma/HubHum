### What it does in plain English
tvision is a toolkit that lets programmers create classic, window-based interfaces inside a standard terminal window. It handles complex tasks like mouse support, pull-down menus, and dialog boxes automatically so you don't have to code them from scratch. By updating this classic technology, it allows these text-based programs to run seamlessly on modern Windows, Linux, and Unix systems with full support for modern characters and colors.

### Who it's for
* Software developers who want to build efficient, lightweight terminal-based applications.
* Retro-computing enthusiasts looking to modernize classic interface designs for current operating systems.

### Key features
* **Cross-Platform:** Write your interface once and run it on Windows, Linux, and Unix without needing platform-specific code changes.
* **Modernized Support:** Includes full support for Unicode characters, 24-bit colors, and mouse interaction (including scroll wheels).
* **Rich Widget Library:** Comes with pre-built components like resizable windows, dialog boxes, buttons, and scroll bars.
* **Smart Terminal Handling:** Automatically manages terminal display settings, so your app looks consistent regardless of the user's setup.

### How to install (Download)
* **For Windows Users:** You can download the latest pre-built demo applications from the [GitHub Actions page](https://github.com/magiblot/tvision/actions?query=branch:master+event:push). Look for the "Artifacts" section at the bottom of a successful build page to find the `.zip` files.
* **For Linux/Unix Users:** You can build the library directly from the source code using CMake. Follow the instructions provided in the [official official project page](https://github.com/magiblot/tvision).

### Pros and Cons
* **Pros:** Extremely lightweight, works on older hardware, and provides a nostalgic yet powerful interface experience.
* **Cons:** Primarily designed for programmers; requires manual setup or building from source code, which may be challenging for non-technical users.
