### What it does in plain English
Microsandbox lets you run untrusted code, automated scripts, and AI agents inside isolated virtual machines on your local computer. It boots up in a fraction of a second, letting you test code, run browser automation, or execute tests without risking your main system. You can easily save your progress, duplicate environments, and manage standard container images with simple commands.

### Who it's for
* Software developers testing risky code, database migrations, or third-party software packages.
* AI engineers and builders running autonomous coding agents or web scrapers that require isolated execution spaces.
* DevOps professionals creating disposable continuous integration workers or secure remote automation tasks.

### Key features
* **Hardware-Level Isolation:** Keeps your host computer completely safe by running workloads inside tiny, dedicated virtual machines.
* **Instant Startup:** Boots up fresh environments in under a hundred milliseconds so you never have to wait around.
* **Standard Container Support:** Uses familiar container images directly from popular online registries without extra configuration hassle.
* **Fork and Snapshot:** Allows you to freeze a running environment, duplicate it instantly, or restore it to an exact previous state.
* **Flexible Integration:** Control sandboxes directly from your terminal using commands or embed them straight into your own software projects.

### How to install (Download)
To install the command-line interface on macOS or Linux, run:
```sh
curl -fsSL https://install.microsandbox.dev | sh
```
To install on Windows via PowerShell, run:
```powershell
irm https://install.microsandbox.dev/windows | iex
```

### Pros and Cons
* **Pros:** Blazing fast startup times, complete hardware isolation for untrusted scripts, and support for standard container images.
* **Cons:** Requires specific virtual machine support enabled in your operating system settings and is actively evolving in beta development.
