### What it does in plain English
Vector lets advanced Android users safely tweak their phone's operating system and apps in real time. It works completely in the background without permanently altering the system files or installed apps. Changes can be easily disabled or reset simply by restarting your device.

### Who it's for
* Android power users who want deep control over how their device operates.
* Privacy enthusiasts looking to fine-tune app permissions and behaviors.
* Developers testing system modifications and module compatibility across various Android versions.

### Key features
* Runs modern Android system hooks seamlessly from Android 8.1 up to recent versions.
* Operates entirely in memory so no permanent system files are touched or broken.
* Maintains compatibility with legacy and modern module standards for maximum flexibility.
* Provides a non-destructive environment where changes disappear instantly upon a reboot.

### How to install (Download)
To get started, visit the official [GitHub Releases](https://github.com/JingMatrix/Vector/releases) page to download the latest stable package, or check out [GitHub Actions](https://github.com/JingMatrix/Vector/actions/workflows/core.yml?query=branch%3Amaster) for the newest development builds. You will need a compatible root manager environment with system module support already set up on your device.

### Pros and Cons
* **Pros:** Free and open-source, non-destructive modifications, supports a wide range of Android versions.
* **Cons:** Requires an unlocked root environment with specific system setup, advanced features have a learning curve.
