### What it does in plain English
Toolong is a lightning-fast terminal tool designed to help you open, search, and monitor large log files without slowing down your computer. It automatically handles compressed archives, organizes complex web server data, and lets you view multiple logs side-by-side or combined into a single timeline. Whether you are debugging software issues or reviewing server activity, it cuts through the clutter so you can find the right information quickly.

### Who it's for
* Software developers and system administrators troubleshooting server errors in real time.
* IT support professionals examining multi-gigabyte log dumps and compressed archive files.
* Power users who prefer lightweight keyboard-driven terminal utilities over heavy desktop applications.

### Key features
* **Live Tailing:** Stream incoming log updates in real time to monitor active server events as they happen.
* **Instant Loading:** Open multi-gigabyte files as quickly as tiny text documents without waiting around.
* **Smart Merging:** Combine multiple log files into a single chronological view by auto-detecting timestamps.
* **Structured JSONL Support:** Automatically format and pretty-print complex JSON line data for effortless reading.
* **Compressed File Support:** Seamlessly open and explore compressed log archives without manual extraction.

### How to install (Download)
Toolong is best installed using a Python package runner. If you have `pipx` installed on your system, run:

```bash
pipx install toolong
```

Alternatively, you can install it using standard Python packaging:

```bash
pip install toolong
```

Once installed, simply type `tl` followed by your log file name in your terminal. Explore the official site at [Textualize Website](https://www.textualize.io/).

### Pros and Cons
* **Pros:** Extremely fast file loading, handles huge logs effortlessly, zero complex configuration required.
* **Cons:** Requires a terminal environment, command-line interface may intimidate beginners.
