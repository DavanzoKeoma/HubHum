### What it does in plain English
Slides allows you to write presentations using simple text formatting that you can display right inside your computer's terminal window. It eliminates the need for heavy, complex software by letting you navigate through your slides using basic keyboard shortcuts. You can even run code snippets or display live data directly within your presentation slides.

### Who it's for
* People who prefer working with text-based tools and want to avoid heavy presentation software.
* Technical professionals who want to demonstrate code or command-line workflows during a presentation.

### Key features
* **Markdown Support:** Write your entire presentation using standard, easy-to-read text formatting.
* **Live Updates:** The presentation automatically refreshes if you make changes to your text file while it is open.
* **Interactive Code:** Run code blocks directly within your slides to show live results to your audience.
* **Remote Access:** Share your presentation over a network connection so others can view it on their own machines.
* **Custom Styling:** Use simple configuration files to adjust the look and feel of your slides to match your preference.

### How to install (Download)
You can install Slides using your system's package manager or by downloading the latest version from the official releases page.
* **Official Releases:** [View all downloads on GitHub](https://github.com/maaslalani/slides/releases)
* **MacOS:** Run `brew install slides` in your terminal.
* **Arch Linux:** Run `yay -S slides` in your terminal.
* **Linux (Snap):** Run `sudo snap install slides` in your terminal.
* **Go Users:** Run `go install github.com/maaslalani/slides@latest`

### Pros and Cons
* **Pros:** Extremely lightweight, no heavy software bloat, perfect for technical demonstrations, and free to use.
* **Cons:** Requires basic familiarity with terminal commands and text-based file editing.
