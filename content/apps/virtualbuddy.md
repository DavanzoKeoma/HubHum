### What it does in plain English
VirtualBuddy creates a separate macOS computer inside your own Mac. You can choose any macOS version, even the newest test releases. It lets you try out software or changes without affecting your main system.

### Who it's for
* Developers who need to test apps on different macOS versions.  
* Power users who want to experiment with new macOS releases safely.  
* Students learning how macOS works.

### Key features
- Run any macOS 12 or later, including beta versions.  
- Install ARM‑based Linux distributions alongside macOS.  
- Share files and clipboard between the virtual machine and your Mac.  
- Save the state of a virtual machine and resume later.  
- Adjust virtual hardware such as memory and storage size.

### Pros and Cons
* **Pros:** free and open‑source, supports many macOS versions, easy file sharing, saves VM state.  
* **Cons:** works only on Apple Silicon Macs, requires macOS 13 or later, newest macOS betas may need extra Apple device‑support files.
