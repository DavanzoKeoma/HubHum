### What it does in plain English
Many software programs automatically scatter configuration folders and cache files directly inside your main personal user directory, creating unwanted clutter. This utility checks your personal folder for those misplaced files and provides clear instructions on how to relocate them to their proper system locations. It helps keep your primary workspace clean, organized, and compliant with modern file organization standards.

### Who it's for
* Computer users who want to keep their main personal directory clean and free of leftover configuration mess.
* Power users and developers looking to enforce clean file organization habits across their operating system.

### Key features
* Automatically scans your personal user directory for known misplaced files and folders.
* Provides clear, actionable advice on whether files can be safely moved and how to do it.
* Supports custom ignore lists so you can keep your preferred files exactly where you want them.
* Lightweight shell script design that runs quickly on standard systems.
