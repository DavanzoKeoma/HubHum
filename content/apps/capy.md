### What it does in plain English
Capy provides a simple way to design visual applications that look and feel completely native on your operating system. Instead of forcing heavy web-based technology, it translates your user interface code directly into real system controls. It enables developers to produce remarkably small software packages that launch instantly and respect accessibility settings out of the box.

### Who it's for
* Software creators looking for a streamlined approach to building native user interfaces without unnecessary bloat.
* Programmers exploring the Zig ecosystem who need a dependable way to draw windows, buttons, and text fields.
* Developers aiming to cross-compile small desktop programs from one operating system to another effortlessly.

### Key features
* **Native OS Controls:** Automatically uses the styling and behavior native to the operating system your software runs on.
* **Tiny File Sizes:** Generates extremely compact executable files under two megabytes for fast sharing and downloading.
* **Full Accessibility:** Built with screen readers and standard assistive navigation tools in mind from day one.
* **Cross-Platform Building:** Easily compile your interface for Windows, Linux, and web browsers from a single workstation.

### How to install (Download)
To start a new project with this toolkit, clone the official [Capy Template](https://github.com/capy-ui/capy-template) from GitHub and follow the setup instructions provided. For detailed documentation and guidance, visit the [Capy Documentation Page](https://capy-ui.org/docs/getting-started/installation).

### Pros and Cons
* **Pros:** Exceptionally small app sizes, native appearance, friendly syntax, and great accessibility support.
* **Cons:** Still under active development with occasional breaking changes, and requires familiarity with the Zig language.
