### What it does in plain English
XCGLogger helps software creators inspect what their applications are doing behind the scenes by printing detailed messages to the screen or a file. Instead of basic text notes, it automatically adds helpful timestamps, exact file names, and line numbers to every event. This makes tracking down unexpected behavior or testing new features much faster and simpler.

### Who it's for
* Swift developers building phone or desktop applications
* Programmers looking to replace basic print commands with structured logging
* Teams wanting organized debug outputs saved directly to files or system consoles

### Key features
* Adds automatic timestamps, function names, and line numbers to logs
* Supports saving log events to text files alongside console output
* Allows filtering messages by file name, custom tags, or developer tags
* Includes options for color-coded logs using standard formatting rules
* Runs tasks on background queues to prevent slowing down app performance
