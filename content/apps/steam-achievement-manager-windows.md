### What it does in plain English
This tool helps you organize your gaming progress by letting you unlock or reset achievements in your Steam library. It also allows you to adjust specific game statistics if the game supports it. You can do all of this through a simple window on your computer, so you never need to type code or use technical commands.

### Who it's for
* **Completionists:** Players who want to ensure they have all achievements unlocked or want to reset a game to start fresh.
* **Casual Gamers:** Users who find it tedious to manually check their progress and prefer a visual list of their games.
* **Tech-Curious Hobbyists:** People who want to experiment with their game data without learning how to use a command line.

### Key features
* **Unlock and Relock:** Easily toggle achievements on or off for supported games.
* **Edit Statistics:** Change specific game stats, such as levels or scores, where the game allows it.
* **Visual Library:** Browse your installed Steam games to see which ones have editable achievements.
* **No Coding Required:** A friendly graphical interface that anyone can use without technical training.
* **Free and Open Source:** The software is completely free, with no hidden fees or subscription costs.

### How to install (Download)
1. Go to the [Releases page](https://github.com/solv4626/steam-achievement-manager-windows/releases) to find the latest version.
2. Download the file named `Steam Achievement Manager for Windows 4.1.8.zip`.
3. Unzip the file into a folder on your computer.
4. Keep the main program file (`Steam Achievement Manager for Windows 4.1.8.exe`) and the `libvlc.dll` file in the same folder.
5. Double-click the `.exe` file to start the application.

### Pros and Cons
* **Pros:** Completely free, easy to use for non-technical people, and works directly on your computer without sending data to the cloud.
* **Cons:** It only works with games that allow achievement editing, and you must be careful not to break your game save data.
