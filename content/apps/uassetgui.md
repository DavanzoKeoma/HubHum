### What it does in plain English
UAssetGUI lets you look inside and modify the core asset files used by games built with the Unreal Engine. It gives you a direct, hands-on way to inspect internal properties and make precise adjustments without needing complex custom programming setups. Whether you are troubleshooting file structures or converting data formats, it provides a straightforward interface for deep file editing.

### Who it's for
* Game modders looking to tweak internal properties of Unreal Engine titles.
* Developers and technical artists examining compiled game data structures.
* Advanced enthusiasts converting asset files between raw formats and human-readable text.

### Key features
* Inspect and edit raw properties inside compiled Unreal Engine asset files.
* Convert asset files into structured text formats for easy reading and script modification.
* Run tasks quickly from your computer terminal using simple command-line instructions.
* Set up portable mode to store all settings locally on a USB drive or external folder.
* Maintain complete control over file configurations without relying on cloud services.
