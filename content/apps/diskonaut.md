### What it does in plain English
Diskonaut scans your computer's storage to show you exactly where your space is going. It creates a visual map of your folders, allowing you to see which items are the largest at a glance. You can then navigate through your files and remove the ones you no longer need directly within the tool.

### Who it's for
*   Users who frequently run out of storage space and need to find large, forgotten files.
*   People who prefer a visual way to manage their hard drive contents rather than digging through standard file lists.

### Key features
*   **Visual Mapping:** Displays your files as a treemap, making it easy to spot large folders.
*   **Real-time Scanning:** You can start exploring your files before the scan is even finished.
*   **Built-in Cleanup:** Allows you to delete files or folders directly to reclaim space.
*   **Session Tracking:** Keeps track of how much total space you have cleared during your current session.

### How to install (Download)
Diskonaut is designed for use in your computer's command interface. You can install it using the following methods:
*   **macOS:** Use Homebrew by typing `brew install diskonaut`.
*   **Linux (Fedora/CentOS):** Use `sudo dnf install diskonaut`.
*   **Linux (Arch):** Available via the AUR using `yay diskonaut`.
*   **FreeBSD:** Use `pkg install diskonaut`.
*   **General (All systems with Rust):** Use `cargo install diskonaut`.

### Pros and Cons
*   **Pros:** Completely free and open-source, very fast performance, and provides a clear visual overview of storage.
*   **Cons:** Requires basic familiarity with using a command-line interface to launch and navigate.
