### What it does in plain English
This tool shows you your website exactly as a screen reader presents it to a blind user. It highlights missing text labels, incorrect roles, and broken keyboard navigation in real time. This makes it much easier to fix problems before your site goes live.

### Who it's for
* Web developers who want to ensure their code is inclusive for all users.
* Designers who need to verify that visual elements have proper text alternatives.
* Quality assurance testers checking websites for compliance with accessibility standards.

### Key features
* **Screen Reader View:** Displays the page structure as interpreted by assistive technology.
* **Error Detection:** Automatically flags missing ARIA labels and misused roles.
* **Keyboard Testing:** Helps identify elements that cannot be reached or activated via keyboard.
* **Cross-Browser Support:** Available for both Chrome and Firefox browsers.

### How to install (Download)
* [Download for Chrome](https://chrome.google.com/webstore/detail/aria-devtools/dneemiigcbbgbdjlcdjjnianlikimpck?hl=en)
* [Download for Firefox](https://addons.mozilla.org/firefox/addon/aria-devtools/)

### Pros and Cons
* **Pros:** Completely free to use, simple interface, and provides immediate visual feedback on accessibility issues.
* **Cons:** Requires a browser extension to be installed, and it only checks the current page view rather than the entire site at once.
