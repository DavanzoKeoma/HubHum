### What it does in plain English
scc is a high-speed tool that scans your folders to count exactly how much code you have written. It breaks down your project by language, identifying how many lines are actual code, comments, or empty space. Beyond simple counting, it provides helpful estimates on how complex your project is and what it might cost to build based on industry standards.

### Who it's for
* **Software developers** who want to track the size and growth of their projects over time.
* **Project managers** who need a quick way to estimate the scale and potential effort required for a codebase.

### Key features
* **Blazing Fast:** Designed to process large amounts of files in seconds.
* **Detailed Reports:** Generates clear summaries in various formats like tables, CSV, or HTML.
* **Complexity Insights:** Estimates code complexity to help you identify parts of your project that might be difficult to maintain.
* **Smart Filtering:** Automatically ignores common temporary files, hidden folders, and duplicate code to keep your results accurate.
* **Cost Estimation:** Uses standard industry models to provide a rough estimate of the time and effort invested in your project.

### How to install (Download)
You can install `scc` using your system's package manager:
* **macOS (Homebrew):** `brew install scc`
* **Windows (Scoop):** `scoop install scc`
* **Windows (WinGet):** `winget install --id benboyter.scc`
* **Linux (Snap):** `sudo snap install scc`
* **Other platforms:** See the [Official Releases Page](https://github.com/boyter/scc/releases) for direct binary downloads.

### Pros and Cons
* **Pros:** Extremely fast, supports a massive range of programming languages, and offers many output formats for easy reporting.
* **Cons:** Advanced features like complexity analysis may require a brief learning curve to interpret correctly.
