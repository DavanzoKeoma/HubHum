### What it does in plain English
Tasks is a web app that lets you keep a list of things you need to do.  
It shows tasks in a clean layout and lets you add, edit, or delete them.  
You can also attach files, use markdown, and set priorities to stay organized.

### Who it's for
Busy professionals who need a quick to‑do list.  
Hobbyists who want a lightweight task manager.  
Anyone who prefers a simple web interface over complex boards.

### Key features
- Add, edit, and delete tasks easily.  
- Search tasks with highlighted results.  
- Markdown support for rich text and task lists.  
- Upload files securely with randomised names.  
- Priorities and categories to sort and group tasks.

### How to install (Download)
Run the install script:  
[Run install script (install.sh)](https://github.com/thewhitetulip/Tasks/blob/master/install.sh)  

Alternatively, clone the repo, build with Go, and run the binary:
```bash
git clone https://github.com/thewhitetulip/Tasks.git
cd Tasks
go build
./Tasks
```

### Pros and Cons
* **Pros:** free forever, no subscription, lightweight.  
* **Cons:** requires Go to build manually, no desktop app, may need terminal for manual install.
