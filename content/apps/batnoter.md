### What it does in plain English
BatNoter turns your personal GitHub account into a private, secure notebook for your thoughts and ideas. You can write notes using simple text formatting that supports images, tables, and code snippets. Everything you write is saved automatically to your own computer or server, so you always own your data.

### Who it's for
* **Students and researchers** who need a clean, distraction-free space to organize lecture notes and research findings.
* **Developers** who want to keep technical documentation, code snippets, and project ideas close to their codebase.
* **Privacy-focused users** who prefer keeping their personal notes on their own infrastructure rather than on third-party cloud services.

### Key features
* **Markdown Support:** Write notes with headings, bold text, links, and code blocks that look professional and are easy to read.
* **GitHub Integration:** Log in with your existing GitHub account to save notes directly to your private or public project pages.
* **Organized Folders:** Create nested folders to keep related notes together, making it easy to find specific topics later.
* **Live Preview:** See how your notes will look as you type, with a clean interface that switches between editing and reading modes.
* **Dark and Light Modes:** Choose the color scheme that is easiest on your eyes, whether you are working during the day or late at night.

### How to install (Download)
Since BatNoter is a web application, you can use the official hosted version immediately or set up your own private instance.

* [Visit the Official Website](https://batnoter.com)
* [View Source Code on GitHub](https://github.com/batnoter/batnoter)

### Pros and Cons
* **Pros:** Completely free to use, your data stays in your own GitHub account, and the interface is clean and fast.
* **Cons:** Requires a GitHub account to function, and setting up your own private server requires some basic technical knowledge.
