### What it does in plain English
Wavelog is a web-based digital logbook designed for amateur radio operators to track their radio contacts on the go. Users can access their personal logging database from any device with an internet connection and a web browser. It simplifies keeping track of your contacts, frequencies, and station details without needing local software installations on every device.

### Who it's for
* Radio amateurs looking for an accessible way to record contacts away from the home shack.
* Operators who want a self-hosted alternative to cloud logging services to keep complete control of their data.
* Clubs or groups wanting a shared central logbook accessible to multiple authorized members.

### Key features
* Fully web-based interface accessible from smartphones, tablets, and desktop browsers.
* Self-hosted architecture ensuring complete privacy and ownership of your contact records.
* Companion tool support for seamless connection and data transfer directly from your radio equipment.
* Multi-user capabilities with customizable permission levels.
* Active community translations supporting dozens of languages worldwide.

### How to install (Download)
You can test the system first on the [Live Demo](https://demo.wavelog.org) (Username: `demo`, Password: `demo`). 
For full installation guides and setup instructions, visit the [Wavelog Documentation](https://docs.wavelog.org/). You can install it using Docker via the [Docker guide](https://docs.wavelog.org/getting-started/installation/docker/) or on a classic Linux server following the [Linux Guide](https://docs.wavelog.org/getting-started/installation/linux/).

### Pros and Cons
* **Pros:** Free and open source forever, accessible from any web browser, keeps your data entirely private on your own server.
* **Cons:** Requires basic technical knowledge to set up a web server or Docker environment.
