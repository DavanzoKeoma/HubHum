### What it does in plain English
Argmax Open-Source SDK is a collection of high-performance tools that bring speech recognition, speaker tagging, and text-to-speech directly onto Apple hardware. Because everything runs locally on your device, your audio data never leaves your computer or phone. Developers can easily integrate these capabilities into their own applications or use the command-line tools for quick testing and local server setups.

### Who it's for
* **Mac and iOS developers** looking to embed privacy-focused voice features into their native apps without paying for cloud APIs.
* **Power users and creators** who want to experiment with local speech transcription and text generation using simple terminal commands.
* **Privacy advocates** requiring offline audio processing where voice recordings never get sent to third-party servers.

### Key features
* **WhisperKit:** Fast, accurate speech-to-text transcription powered by OpenAI Whisper models optimized for Apple hardware.
* **TTSKit:** Natural text-to-speech generation with real-time streaming playback and multiple voice options.
* **SpeakerKit:** Speaker diarization tools to automatically distinguish and label different voices in a recording.
* **Local Server Mode:** Built-in server utility allowing you to run a local audio API compatible with existing client libraries.
* **Memory-Efficient Streaming:** Stream large audio files from disk in small chunks to keep memory usage low during long recordings.

### How to install (Download)
To use the libraries in your Swift project, add the package official project page URL `https://github.com/argmaxinc/argmax-oss-swift` via Xcode or your package configuration. 

If you want to use the command-line transcription tool on macOS, you can install it easily using Homebrew:
```bash
brew install whisperkit-cli
```
You can also view the project official project page and release updates directly on the [Official Source / Credits](https://github.com/argmaxinc/argmax-oss-swift).

### Pros and Cons
* **Pros:** Completely open-source, runs entirely offline for maximum privacy, optimized specifically for Apple Silicon hardware.
* **Cons:** Requires macOS 14+ or iOS 18+ depending on the specific kit, and heavy AI models require adequate device storage.
