### What it does in plain English
eos is a specialized tool that analyzes 2D photos to map them onto 3D digital face models. It automatically calculates the shape, pose, and facial expressions of a person based on the image provided. The final result is a 3D digital file that represents the face from the original photograph.

### Who it's for
* Researchers and students working on digital face analysis or computer graphics.
* Digital artists who need a starting point for creating 3D character models from real-world photos.

### Key features
* **Automatic Fitting:** Quickly estimates head pose, face shape, and expressions from a standard 2D image.
* **Model Support:** Works with several standard industry face models, including the Surrey and Basel Face Models.
* **Texture Extraction:** Creates a flat, pose-invariant map of the face texture for use in other 3D software.
* **Python Integration:** Offers a simple way to use these features within Python scripts for easier automation.
* **Lightweight Design:** Built to be efficient and easy to include in your own custom projects.
