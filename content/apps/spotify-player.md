### What it does in plain English
This application brings your entire music streaming experience right into your command-line interface. You can search for songs, manage playlists, and stream audio directly inside a clean text-based window. It even features real-time audio visualizers, synchronized lyrics, and remote playback controls to keep your workflow uninterrupted.

### Who it's for
* Command-line power users who want a lightweight alternative to heavy desktop applications.
* Developers and minimalists who prefer staying inside the terminal while working.
* Anyone looking for a fast, resource-friendly way to enjoy music on older or low-powered computers.

### Key features
* Minimalist and fast terminal user interface with keyboard and mouse navigation.
* Integrated audio streaming and remote control support for managing playback anywhere.
* Real-time audio frequency visualizer and synchronized lyrics display.
* Customizable themes, shortcut keys, and image album art rendering.
* Script-friendly command-line tools for advanced automation and quick searches.

### How to install (Download)
You can download the checksum files and source releases directly from the [Official Releases Page](https://github.com/aome510/spotify-player/releases). 

For quick installation on various platforms, use your preferred package manager:
* **Homebrew (macOS):** Run `brew install spotify_player` in your terminal.
* **Scoop (Windows):** Run `scoop install spotify-player` in your terminal.
* **Arch Linux:** Run `pacman -S spotify-player` in your terminal.
* **FreeBSD:** Run `pkg install spotify-player` in your terminal.
