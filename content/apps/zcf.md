### What it does in plain English
ZCF lets you keep a single, easy‑to‑edit file that remembers all the AI coding helpers you use.  
It automatically downloads each helper you pick and writes the right settings for it.  
Before any change, it shows you exactly what will happen and backs up the original files.

### Who it's for
- Developers who rely on AI to write or review code.  
- Tech hobbyists experimenting with code assistants.  
- Students learning programming with AI support.

### Key features
- One simple file stores all your AI coding helper choices.  
- Automatically downloads and sets up each helper you select.  
- Saves your personal settings without overwriting comments.  
- Creates a backup before changing any file.  
- Shows a preview of every change before it is applied.

### How to install (Download)
- **Official website (setup guide):** [ZCF Docs & Download](https://zcf.ufomiao.com/)  
- **npm package (for command‑line use):** [zcf on npm](https://npmjs.com/package/zcf)

### Pros and Cons
* **Pros:** free forever, single configuration file, automatic setup, safe backups, clear preview of changes.  
* **Cons:** works best from a terminal, limited to the helpers listed in the documentation, requires an internet connection to fetch tools.
