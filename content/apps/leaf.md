### What it does in plain English
Leaf brings a comfortable, graphical-style preview experience right into your command-line interface. It renders rich Markdown text, math formulas, code snippets, and diagrams with clean formatting and live auto-reload as you type. You can also browse project file histories, search through your documents instantly, and review code changes side-by-side without leaving your terminal.

### Who it's for
* Writers and technical documentation creators who want to review documents instantly without opening heavy applications.
* Developers and system administrators who love working entirely inside the command-line terminal.
* AI workflow users who generate text files with artificial intelligence tools and want a live-updating preview screen.

### Key features
* **Live auto-reload:** Automatically updates the document view whenever the source file is saved.
* **Git diff inspection:** Explore code changes and file histories with syntax highlighting and side-by-side views.
* **Fuzzy file picker:** Quickly find and open documents using fast keyword searches.
* **Rich formatting support:** Renders tables, task lists, code syntax highlighting, math formulas, and charts.
* **Custom themes:** Personalize colors easily using simple configuration files.

### Pros and Cons
* **Pros:** Extremely fast and lightweight, works completely offline, supports live auto-reload, and offers rich text formatting inside text terminals.
* **Cons:** Requires a terminal environment to run, and Windows users may need to install the Microsoft Visual C++ runtime if not already present.
