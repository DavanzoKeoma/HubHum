### What it does in plain English
Gnirehtet lets your Android phone use the internet that your computer is connected to.  
You don’t need to root the phone or install any special software on the computer.  
It works on Windows, macOS and Linux with a simple plug‑in and a few clicks.

### Who it's for
* People who travel with a laptop and want their Android phone to stay online without a separate Wi‑Fi hotspot.  
* Users who have a stable wired or Wi‑Fi connection on their PC and want to share it with a phone that has weak or no signal.  
* Anyone who prefers a free, no‑subscription solution for internet sharing.

### Key features
* Works on Windows, macOS and Linux.  
* No root access required on the phone or the computer.  
* Shares the computer’s internet connection with any Android app that needs it.  
* Simple command‑line tool; a double‑click script is provided for Windows.  
* Supports most common internet traffic (web browsing, streaming, messaging).

### How to install (Download)
* **Windows (Rust version):** [Download for Windows (.zip)](https://github.com/Genymobile/gnirehtet/releases/download/v2.5.1/gnirehtet-rust-win64-v2.5.1.zip) – extract the files and run `gnirehtet-run.cmd` or `gnirehtet.exe`.  
* **Linux (Rust version):** [Download for Linux (.zip)](https://github.com/Genymobile/gnirehtet/releases/download/v2.5.1/gnirehtet-rust-linux64-v2.5.1.zip) – extract and run `./gnirehtet run`.  
* **macOS (Rust version – older release):** [Download for macOS (.zip)](https://github.com/Genymobile/gnirehtet/releases/download/v2.2.1/gnirehtet-rust-macos64-v2.2.1.zip) – extract and run `./gnirehtet run`.  
* **All platforms (Java version):** [Download Java version (.zip)](https://github.com/Genymobile/gnirehtet/releases/download/v2.5.1/gnirehtet-java-v2.5.1.zip) – extract and run the appropriate script for your OS.

After extracting, double‑click the provided script (Windows) or run `./gnirehtet run` from a terminal (Linux/macOS). The first run will ask the phone for permission.

### Pros and Cons
* **Pros:** completely free, no subscription, works without rooting, cross‑platform, lightweight Rust binary uses little CPU and memory.  
* **Cons:** project is no longer actively maintained, requires command‑line usage, only supports IPv4 traffic.
