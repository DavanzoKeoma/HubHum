### What it does in plain English
SteamTools (also known as Watt Toolkit) is an open-source helper application designed to make managing your digital video game library smoother across multiple devices. It helps you quickly switch between different user accounts, improve connection speeds to gaming storefronts, and manage your cloud game saves securely. The program acts as a customizable toolbox running on your computer, bringing together multiple helpful utilities under one clean interface.

### Who it's for
* PC gamers who manage multiple gaming profiles or family sharing libraries on the same computer.
* Users looking for a convenient way to keep local security tokens and verification codes organized.
* Players who want to track game download progress and organize custom artwork for their digital libraries.

### Key features
* **Account Switching:** Quickly jump between different user accounts logged into your computer without tedious password re-entry.
* **Network Acceleration:** Utilizes local routing proxies to help improve connectivity and page loading speeds when browsing game storefronts.
* **Security Code Manager:** Store and generate your multi-factor security verification codes directly in one centralized desktop place.
* **Library Organization:** Customize game cover art, monitor download progress, and manage cloud save files effortlessly.
* **Cross-Platform Support:** Available for popular desktop operating systems so you can enjoy a consistent experience wherever you play.
