### What it does in plain English
Chapar is a fast, lightweight desktop tool designed for developers and technical teams to test and debug digital interfaces like REST, gRPC, GraphQL, and WebSockets. It operates entirely on your local machine, meaning all your request histories, secure keys, and environment settings are kept strictly private as plain files. Because it is built from scratch without web browser engines, it opens instantly, uses very little memory, and requires no online user account.

### Who it's for
* Software developers and testers who need a reliable, lightning-fast application to check web services and data connections.
* Privacy-conscious engineers who prefer storing their workspace settings and credentials locally rather than syncing them to third-party cloud servers.
* Mobile and backend specialists looking for an integrated traffic inspector and proxy tool to capture requests on the fly.

### Key features
* **Multi-protocol support**: Easily handle REST queries, gRPC streaming, GraphQL schemas, and live WebSocket messaging in one unified interface.
* **Built-in traffic proxy**: Capture and inspect HTTPS traffic from local apps, mobile devices, and browsers without altering global system settings.
* **Local-first privacy**: Store all collections, environments, and cookies as plain text files on your device with sensitive values securely encrypted in your operating system keychain.
* **Automated testing workflows**: Chain requests together, execute validation rules, and run test suites directly in your terminal using the companion command-line tool.
* **Smooth native performance**: Runs directly on your hardware via a GPU-accelerated graphics layer, avoiding the heavy memory footprint of traditional browser-based tools.
