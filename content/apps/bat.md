### What it does in plain English
`bat` lets you view text files directly in your computer's command terminal with gorgeous color coding. Instead of plain boring text, it highlights programming code in vibrant colors and adds clear line numbers so you can read scripts effortlessly. It also automatically splits long files into scrollable pages and highlights recent changes made to your files. ### Who it's for
* Software developers and programmers who read logs and code files in the terminal daily.
* System administrators who inspect configuration files and scripts on servers.
* Writers and students who review Markdown or text notes directly from command prompts.

### Key features
* **Syntax Highlighting:** Automatically detects dozens of programming and markup languages to color-code your text.
* **Git Integration:** Shows small symbols next to line numbers to indicate added, modified, or removed lines.
* **Automatic Scrolling:** Long files open inside an interactive scrollable window so you never lose your place.
* **Non-Printable Characters:** Special viewing options let you reveal hidden spaces, tabs, and line endings.
