### What it does in plain English
This tool brings popular AI coding helpers like GitHub Copilot and ChatGPT directly into the Xcode app on your Mac. It suggests code as you type, answers questions about your project, and can even rewrite or fix specific parts of your code based on your instructions. It turns your standard coding window into a smart assistant that helps you write software faster and with fewer errors.

### Who it's for
*   **Mac Developers:** People who build apps for iPhone, iPad, or Mac using Apple's official development tools.
*   **Busy Coders:** Individuals who want to speed up their workflow by letting AI handle repetitive coding tasks or explain complex code snippets.
*   **Learning Programmers:** Students or new developers who want an AI tutor to help them understand how code works or suggest better ways to write it.

### Key features
*   **Real-Time Code Suggestions:** The app predicts what code you want to write next and offers it as you type, powered by GitHub Copilot or Codeium.
*   **AI Chat Assistant:** A built-in chat window lets you ask questions about your code, debug errors, or get explanations using ChatGPT technology.
*   **Natural Language Editing:** You can select a piece of code and ask the AI to improve it, fix bugs, or add comments using simple English sentences.
*   **Custom Commands:** Create your own shortcuts that automatically run specific AI tasks, such as translating text files or generating code templates.
*   **Flexible Setup:** Choose which AI service to use for suggestions and which one to use for chatting, allowing you to mix and match providers.
