### What it does in plain English
YoloSide lets you open a picture or video, press a button, and watch colored boxes appear around every object it finds.  
You don’t need to write any code—just load a model file and the app does the rest.  
All results are saved automatically so you can review them later.

### Who it's for
* Hobby photographers who want quick object highlights in their shots.  
* Small‑business owners needing a fast way to check product images.  
* Students learning computer‑vision concepts without diving into code.

### Key features
- Load any YOLOv8 `.pt` model file and start detecting instantly.  
- Real‑time display of detections with colored boxes and labels.  
- Automatic saving of results in a `run` folder.  
- Simple sliders to adjust confidence thresholds and choose image or video input.  
- Works on Windows, macOS and Linux as long as Python is installed.

### How to install (Download)
1. Install Python 3.8 or newer.  
2. Open a terminal and run:  

   ```bash
   pip install ultralytics==8.0.48
   pip install pyside6==6.4.2
   ```  

3. Download the source code from the releases page and run the program:  

   [Project releases page](https://github.com/Jai-wei/YOLOv8-PySide6-GUI/releases) → download the zip, extract, then run `python main.py`.

### Pros and Cons
* **Pros:** free forever, visual interface, works with custom YOLO models, cross‑platform.  
* **Cons:** requires a Python setup, no longer actively maintained, limited to YOLOv8 v8.0.48.
