### What it does in plain English
guijs replaces complicated text commands with a clean, easy-to-use visual dashboard for your software projects. It gives you a clear window into your code folders, letting you track tasks, manage project files, and oversee packages directly with your mouse. By bringing everything into a comfortable graphical window, it saves you time and keeps your workspace tidy.

### Who it's for
* Software creators looking for a visual alternative to text-based management tools.
* Web developers who want a faster, cleaner way to handle project files and dependencies.
* Beginners learning JavaScript who prefer clicking buttons over typing terminal commands.

### Key features
* Clean graphical interface designed specifically for modern software projects.
* Simple visual controls to handle packages and project files.
* Organized dashboard layout for tracking different workspaces.
* Lightweight desktop application built for everyday efficiency.
