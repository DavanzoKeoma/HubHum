### What it does in plain English
Claude Squad is a terminal-based command center designed for running multiple artificial intelligence coding assistants at the same time. Each task runs in its own isolated environment with dedicated file workspaces, meaning your different projects will never step on each other's toes. You can review changes, handle background tasks automatically, and easily switch between different assistants from a single screen.

### Who it's for
- Developers and tech enthusiasts juggling multiple coding tasks at once.
- Power users who experiment with different artificial intelligence coding assistants.
- Anyone who wants to run automated background assistant tasks safely without breaking their main code.

### Key features
- **Multiple Workspaces:** Keep every task completely isolated so changes never cause accidental conflicts.
- **Background Processing:** Let your helpers complete routine coding tasks automatically while you focus elsewhere.
- **Built-in Review Tools:** Inspect file changes and updates before applying them to your main project.
- **Flexible Assistant Support:** Switch easily between different artificial intelligence helpers like Claude Code, Codex, and Aider.
- **Clean Interface:** Control everything smoothly right from your terminal window.
